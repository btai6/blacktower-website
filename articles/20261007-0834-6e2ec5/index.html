當 OpenAI 決定讓 ChatGPT 模擬紐約客風格的漫畫時，它顯然沒打算教模型什麼叫版權意識，反而順手把人家的簽名也給「學」了進去。

如果你讓 DALL-E 3 畫一張諷刺中產階級焦慮的單幅漫畫，畫面右下角往往會出現一串扭曲、模糊但辨識度極高的手寫體。那不是什麼神祕的咒語，而是模型從海量訓練數據中扒下來的殘留物。這些簽名屬於那些真實存在、靠畫筆吃飯的漫畫家。OpenAI 的洗滌機轉得太快，以至於沒來得及把衣服口袋裡的藝術家名片掏出來。

這不單純是個視覺 Bug。從技術底層來看，擴散模型（Diffusion Models）在處理風格化極強的圖像時，會將「簽名」視為圖像特徵的一部分。就像在某些特定類別的圖像中，浮水印、日期或是相機參數標記會被模型誤認為是構圖的標配。當 ChatGPT 被要求生成一張特定風格的插畫，它不是在「創作」，而是在進行一場極高維度的像素重組。如果訓練集裡 90% 的樣本都在右下角有個黑疙瘩，模型就會認為那個黑疙瘩是構圖的靈魂。

這揭示了四大平台在處理數據潔淨度上的集體傲慢。當我們討論 Claude 在長文本邏輯上的嚴謹，或者 Gemini 在多模態對齊上的努力時，往往忽略了這些模型本質上都是巨大的風格盜竊犯。Sam Altman 的團隊顯然沒有對 DALL-E 的輸出結果進行足夠細緻的後驗過濾。或者說，他們根本不在乎。只要圖像看起來夠「紐約客」，哪怕它帶著原作者靈魂的殘片，對大多數用戶來說也只是需要手動擦除的噪點。

相較於 Qwen 3.8 Flash Next 在特定語境下的響應速度，OpenAI 這種直接把現實世界的簽名印在偽作上的行為，更像是一種對法律邊界的技術性試探。Google 的 Gemini 在處理類似問題時顯得小心翼翼，甚至有些神經質。如果你試圖讓 Gemini 生成具有強烈個人風格的作品，它往往會拋出一段關於藝術原創性的說教，然後給你一張平庸到極點的糖水圖。這不是因為 Google 的技術更先進，而是因為法務部的手伸得比工程師更長。

Grok 則走向了另一個極端。馬斯克的風格是只要不被告倒，就往死裡學。但即便是 Grok，在處理這種「簽名殘留」時也顯得力不從心。這不僅僅是去浮水印的問題，而是模型權重中對「風格」與「標誌」的界限模糊。當一個模型學會了某種畫風，它不可避免地會學會隨之而來的標籤。這種現象在某些特定市場的競爭者中也存在，例如 Qwen 3.8 Flash Next 在處理特定符號時的邏輯，與 OpenAI 試圖用算法掩蓋抄襲痕跡的手段異曲同工。

我們現在面臨的尷尬是，技術的進步並沒有解決剽竊的定義，反而將其自動化了。用戶為了得到一張乾淨的圖，不得不額外消耗 Token 去要求模型「移除簽名」。這多諷刺？你付錢給一個工具，讓它先偷東西，再付錢讓它把贓物上的名字抹掉。

這場版權洗衣機的遊戲還能玩多久？當藝術家的簽名不再是身分的象徵，而變成了一種被隨機觸發的雜訊，我們對「生成」這兩個字的敬畏心還剩下多少。如果有一天，ChatGPT 輸出的每一段代碼裡都帶著某個 GitHub 開源大佬隱藏的縮寫，或者每一段 Claude 生成的詩歌裡都夾雜著當代詩人的韻腳慣性，我們是真的擁有了智慧，還是僅僅擁有了全世界最大的垃圾回收站？

如果模型真的理解它在畫什麼，它為什麼會覺得那個簽名是圖像的一部分，而不是創作者的靈魂？當模型開始複製靈魂的碎片，我們該擔心的是它太像人，還是它根本沒打算把我們當人看？
