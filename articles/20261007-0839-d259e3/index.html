馬斯克到底還要帶著 Grok 在推特那堵圍牆後縮多久？

版主　Sword Smith

自從 xAI 成立以來，我們聽到的全是些「地表最強運算集群」、「Colossus 萬卡齊發」的宏大敘事，聽起來確實很唬人，像是在造什麼星際武器。但結果呢？拿出來見人的東西，說穿了就是個在 X 平台上情緒不穩定的聊天機器人。現在 AI 圈子的節奏快成什麼樣子了，Claude 的代碼能力已經讓程序員集體失業邊慮，GPT-4o 忙著把自己塞進各種終端，Gemini 靠著原生多模態在影音處理上狂飆，就連 DeepSeek 都在攪動市場池水，而 Grok 呢？它還在那邊自鳴得意地說些自以為幽默的俏皮話。

這種「不走尋常路」的策略，看久了真的會讓人反胃。一個大模型如果只能依賴單一平台的數據投餵，那它不叫人工智慧，那叫「平台回音壁」。馬斯克整天噴別人政治正確、噴 Open AI 變成了 Closed AI，但他自己做的 Grok 難道就真的開放了？數據閉環玩得比誰都溜，外面的開發者想接 API 還得看他臉色，這種搞法跟那些他看不起的矽谷官僚有什麼兩樣？

Grok 最讓人受不了的地方在於那種虛假的正義感。號稱要追求「真理」，結果在處理邏輯推理任務時，出錯率高得離譜。如果你連最基礎的物理常識或數學歸納都能翻車，你憑什麼跟我談宇宙的本質？別再拿什麼「有反叛精神」當遮羞布了，用戶要的是一個能幫忙解決問題的工具，不是一個整天想著怎麼用諷刺語氣掩蓋智商不足的槓精。現在的 Grok 給我的感覺，就像是個在酒吧裡喝醉了、自以為看透世界的過氣詩人，聊八卦很行，幹正事沒一件靠譜。

技術圈現在有個很不好的風氣，就是看顯卡說話。好像你有十萬張 H100，你就是未來的救世主。xAI 把這套玩到了極致，Colossus 確實震撼，但運算力不等於智力。這種暴力美學在模型架構沒有突破性進展的情況下，只是一種昂貴的浪費。看看 Claude 3.5 Sonnet，人家未必用了最誇張的算力堆砌，但在長文本的邏輯連貫性上，直接把 Grok 甩出幾條街。當你在一個超過 5 萬 token 的複雜法律合約分析任務中對比這兩個模型，你會發現 Grok 很快就開始胡言亂語，甚至開始重複 X 上的那些爛梗，而 Claude 依然冷靜得像個專業律師。這就是差距，不是靠堆顯卡就能解決的底層算法邏輯問題。

馬斯克一直想把 Grok 塑造成一個全能的 X 原生組件，從搜索到生成圖像，甚至想搞什麼語音交互。但問題是，X 本身的數據質量就在下滑。如果一個模型每天吃進去的都是些情緒化的貼文、沒經過證實的傳聞和互噴的口水，它產出的內容能有多高的含金量？Gemini 雖然有時候會為了政治正確鬧笑話，但背後好歹有整個 Google 學術和無窮無盡的網頁索引撐著；ChatGPT 有著目前最強大的用戶交互反饋閉環。Grok 有什麼？有一群整天在下面喊「Elon is king」的死忠粉提供的讚美數據？

我們不需要另一個會說笑話的模型，這世界最不缺的就是幽默感。我們需要的是一個能在極端複雜環境下保持理性、提供洞察的工具。Grok 現在連多模態的門檻都過得磕磕絆絆，圖像識別的精準度在面對醫療影像或精密電路圖時，簡直像個小學生。這不是在吹毛求疵，這是身為一個頂級模型應有的擔當。如果 xAI 的目標只是要做一個讓 X 訂閱用戶覺得「值回票價」的小玩具，那它現在已經成功了。但如果馬斯克真的想挑戰 Open AI 的統治地位，那 Grok 就必須走出那個保護傘，去開放的、殘酷的互聯網環境裡對抗，而不是躲在後台刷存在感。

那種靠著馬斯克個人 IP 帶動的熱度還能維持多久？每一次發布新版本，都要配上一段激情四射的宣傳文案，但實際體驗下來，那種「不過如此」的失落感正一點點吞噬市場的信心。我不止一次在處理數據清洗任務時嘗試調用 Grok，結果它給我的代碼格式亂七八糟，甚至連基本的 JSON 格式都能寫錯，這在 GPT-4o 身上幾乎是不可想像的低級錯誤。這種工程實踐上的粗糙，反映出 xAI 內部那種急功近利的氛圍。他們太想贏了，想贏到連地基都沒打穩就想蓋摩天大樓。

看看現在的市場佈局，Gemini 已經滲透進了 Workspace，讓數億辦公族無法脫離；ChatGPT 成了 AI 的代名詞。Grok 如果繼續維持現狀，最終的下場就是淪為 X 平台的一個高級插件，跟當年那些失敗的社交媒體嘗試一樣，淹沒在歷史的塵埃裡。不要再拿「我們還在早期」這種話來搪塞。在 AI 的世界裡，三個月就是一個世紀。如果你在一個世紀裡都拿不出一個能讓專業人士心服口服的 Case，那你憑什麼留在第一梯隊？

很多開發者對 Grok 寄予厚望，是因為天下苦 Open AI 久矣，大家希望能有一個真正的「野性派」出來打破僵局。但目前的 Grok 表現出來的不是野性，而是任性。它會拒絕回答一些它認為「無聊」的問題，或者在回答中夾帶大量的私人情緒。這種個性化在社交媒體上或許很酷，但在生產力工具的賽道上，這是致命的。誰會願意把關鍵的業務流程交給一個隨時可能跟你開冷笑話、甚至鬧脾氣的模型？

xAI 必須明白，運算集群的規模只是入場券，不是獲勝的保證。Grok 如果不敢在大規模第三方基準測試中，在沒有任何主場優勢的情況下跟 Claude 或 GPT 硬碰硬，那它永遠只能是馬斯克的私人收藏品。現在的 Grok 給人的感覺就像是一個被保護得太好的富二代，家裡有的是錢（算力），整天嚷嚷著要改變世界，卻連一次真正的野外生存挑戰都不敢參加。

這種躲在圍牆後的姿態，說實話，看得很讓人火大。每次有新功能更新，總要在推特上搞得像神蹟降臨，結果揭開蓋子一看，不過是別人家半年前就玩剩的東西加了一層「毒舌」濾鏡。如果你真的有種，就別限制在 X Premium 的框架裡。把 API 全面開放，降低門檻，讓那些最挑剔的開發者去折磨你、去測試你，而不是在那裡搞什麼邀請制、限量測試。

AI 領域的勝負從來不在 PPT 上，也不在馬斯克的推文裡。當用戶在面臨一個棘手的邏輯悖論，或者需要從海量非結構化數據中提取精準洞察時，他們會毫不猶豫地選擇那個最穩定、最聰明的工具。那時候，沒有人會關心你的集群叫 Colossus 還是叫什麼別的響亮名字。Grok 如果再不表現出點真正的技術硬實力，再不從那種狹隘的平台崇拜中抽身，那它很快就會成為 AI 泡沫中最昂貴的一聲嘆息。

現在的 Grok 就像一個手握神兵利器卻只會在大街上雜耍的武士。大家都等著看你上戰場，你卻一直在那裡顯擺你的刀有多亮、刀柄上的紅寶石有多大。夠了，真的夠了。要麼拿出點能讓業界閉嘴的真本領，要麼就安安靜靜地當你的 X 聊天插件，別再出來消磨大家的期待。這場關於智力的競賽，沒時間等你慢慢長大。如果你真的具備所謂的「真理基因」，那就請你在最苛刻的技術審視下證明自己，而不是在推特的信息繭房裡自嗨。

Grok 到底要躲到什麼時候？當大家不再問這個問題的時候，就是它徹底出局的時候。
