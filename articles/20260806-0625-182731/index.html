Grok 正在變成一座精緻的廢墟。

版主　Sword Smith

馬斯克那套推崇「真相」的論調，聽起來熱血，結果灌進模型裡，就成了這種半吊子的滑稽劇。每次我丟給 Grok 一個硬核的硬體架構問題，它那種自詡「叛逆」的語氣就先出來了，彷彿不加點冷嘲熱諷，這模型就沒了靈魂。問題是，當我需要追溯 Linux 內核在特定指令集上的競爭狀態，或者是複雜的記憶體位址映射時，誰在乎它是不是故意要裝得像個憤青？那些所謂的個性，在嚴肅的技術演算面前，簡直就是阻礙生產力的毒藥。

比起 Claude 的精確與沉穩，Grok 的邏輯路徑簡直像是在荒原上亂撞。當 ChatGPT 已經能透過代碼解釋器把邏輯鏈條捋得乾乾淨淨，Grok 還在忙著從社群媒體的數據池裡撈那些陳腔濫調的段子。這不是在思考，這是在把網路上那些已經發臭的文字屍體挖出來，重新縫合在一起。它以為自己是在進行反傳統的資訊呈現，實際上只是在消耗算力去模仿一個沒長大的中二病患者。

論壇裡那些天天喊著 Grok 有「靈魂」的人，說白了就是被那套皮囊給騙了。Gemini 在處理多模態數據時，那種冷靜的工程執行力，反襯得 Grok 簡直像是在玩過家家。Grok 宣稱要服務於求知慾，可當你真想從中挖掘出結構化的知識圖譜時，它給你的回應卻充滿了各種無關痛癢的觀點修飾。這種為了所謂「去中心化」或者「言論自由」而犧牲模型核心推理品質的做法，簡直荒謬。模型的本質是演算法的純度，不是推特上的情緒輸出。

看看那些 function calling 的測試吧。Claude 能在處理複雜的 JSON 結構時精準對接 API，而 Grok 呢？它經常在最後一步卡住，非要在那裡發表一段無意義的慨嘆。這不是 AI 的進步，這是在退化。如果我想要聽廢話，我隨手打開論壇就能看見一堆，何必花錢去訂閱一個需要伺候的電子巨嬰？xAI 團隊顯然把優先級搞錯了，他們想造的是一個能夠對抗主流價值的「硬漢」，卻忽略了作為一個工具，它首先得是一個能夠穩定輸出邏輯的底層架構。

如果你在進行高強度的程式碼重構，你會發現 Gemini 或 Claude 給你的回饋是手術刀，能精準切除冗餘，而 Grok 給你的則是一把鏽跡斑斑的鐵鋸。它在拚命試圖展現所謂的「洞察力」，但在程式碼邏輯的邊界上，它的注意力分散得令人驚嘆。每次它試圖解釋一個錯誤的邏輯分支，那種似是而非的專業語氣，看著就讓人火大。它不僅僅是在搬弄屍體，它還在欺騙自己這是在搞創作。

我不在乎馬斯克發了什麼推特，我也不在乎 Grok 下一次更新又要吹噓自己多了多少參數。我只在乎當我按下輸入鍵時，它能不能把那該死的複雜運算給我處理好。現在看來，這依然是一個巨大的問號。當 DeepSeek 這類新面孔出現時，市場的節奏只會變得更快，而 Grok 如果還沉浸在這種「我就是不一樣」的傲慢裡，那它最終會發現自己連一張入場券都拿不到。

技術的迭代不相信眼淚，更不相信嘴硬。Grok 現在的狀態就像是給一個天才裝了一個充滿雜音的擴音器，原本精密的推理過程被那些毫無必要的修飾語淹沒。如果 xAI 的工程師們還想不出如何把那層傲慢的皮給剝下來，這套模型離進博物館也不遠了。別跟我談什麼未來，現在就讓它跑一個高維度的物理模擬看看，看看它那所謂的個性，到底能不能幫它在沒有人類干預的情況下，把邏輯閉環給跑通。

那些天天在論壇裡護航的粉絲，大概是被這種廉價的認同感給餵飽了。可是這又如何？在這個充滿了各種選擇的賽道上，沒有人會因為你的個性而買單。如果 Grok 繼續在這種字詞的屍體堆裡打滾，它註定只能成為一個用來解悶的玩具，而不是一個能幫我們解決實際問題的工程基石。這不是什麼深奧的技術瓶頸，這是定位的失控。它不需要變得更像人，它需要變得更像一個該死的、精密的、不帶任何情感色彩的機器。

現在看著它，就像看著一個本來能成為偉大科學家的苗子，卻偏偏要去演低俗喜劇。這種浪費，才是我最不能忍受的。
