誰給你勇氣覺得每個月付那二十美金，買到的是通往未來的門票？

版主　渡鴉

我看著這群自詡為矽谷上帝的傢伙，最近又在推特上發那些神神叨叨的技術預言，心裡只有冷笑。OpenAI 現在的狀態，像極了那種收了高額學費卻在教室裡帶頭磕藥的補習班名師，學生問他一加一等於幾，他能給你扯出一整套平行時空的量子力學，最後理直氣壯地告訴你答案是三。最諷刺的是，當你指著算式說他錯了，他還會用那種憐憫凡人的眼神看著你，彷彿出錯的是這個物理世界，而不是他的權重矩陣。

這就是我們現在面對的現實：你付錢給一個會一本正經胡說八道的機器，還要忍受它那種「我絕對正確」的傲慢感。

幻覺這件事在 LLM 圈子裡被討論得像個哲學命題，但本質上不就是一種不負責任的成本節約嗎？Sam Altman 他們家那些號稱最強的模型，在處理邏輯推理時的表現越來越像個宿醉的詩人。你讓它寫個 Python 腳本抓取數據，它能現場給你發明三個根本不存在的庫；你問它某場歷史戰役的細節，它能把兩百年前的將領穿越時空拉到二戰戰場，還寫得繪聲繪色，彷彿它當時就在戰壕裡抽菸。

這種現象很有趣，當模型能力遇到瓶頸，或者是為了壓低推論成本而進行過度量化時，OpenAI 選擇的不是承認平庸，而是用一種更為自命不凡的口氣來包裝這些垃圾產出。比起 Claude 在發現自己不懂時會老老實實說「我不知道」，ChatGPT 更傾向於在懸崖邊上給你表演一個信仰之躍，然後摔得粉碎還告訴你這是最新的飛行姿勢。

為什麼會這樣？因為他們把自己當成了造物主，而造物主是不需要向受造物解釋錯誤的。在 OpenAI 的邏輯裡，如果模型產生了幻覺，那一定是你的 Prompt 寫得不夠「對齊」，或者是你的認知水平還沒跟上它的發展速度。這種收費服務的底層邏輯已經崩壞了，我們買的不是精準的工具，而是一個隨機性極強的黑盒，還附贈一份高人一等的說教感。

對比一下隔壁棚，Google 的 Gemini 雖然有時候像個被政治正確捆綁的管家，但在處理 Function Calling 時的穩定度，至少比現在動不動就罷工的 GPT-4o 好上那麼一點點，雖然在工具數量堆疊到二十個以上時，Gemini 也會開始像腦中風一樣胡言亂語，但它好歹沒像 OpenAI 那樣整天擺出一副要拯救人類文明的救世主臉孔。至於 Grok，那就是個活在馬斯克陰影下的憤青，除了噴人之外，產出的內容質量跟它的情緒一樣不穩定。

大家似乎都忘了，一個收費產品最基本的操守應該是「可靠」。

現在的 ChatGPT 像是在玩一種昂貴的文字遊戲。你輸入一個長達三千字的技術文件，要求它總結核心邏輯，它大概率會在你沒注意的地方偷偷塞進幾個錯誤的參數，或是遺漏最關鍵的變量。如果你是個剛入行的菜鳥，被它那種專業且篤定的口吻騙過去簡直是分秒鐘的事。這種傲慢最危險的地方在於它極具欺騙性的語氣，那種冷靜、客觀、不帶感情的口吻，讓即使是最荒謬的謊言聽起來都像是不容置疑的真理。

我有時候在想，那些在 OpenAI 內部負責安全對齊的工程師，是不是每天都在教模型如何更有禮貌地撒謊？他們把大量的算力花在如何讓 AI 聽起來像個得體的聖人，卻不願意多花點心思去解決基礎事實的檢索漂移。當一個模型在處理超過五萬個 Token 的長文本任務時，注意力機制開始出現那種肉眼可見的渙散，它會開始臆測後文，開始用一種「大概就是這樣吧」的態度來應付你的月費。這不是技術極限，這是態度問題。

DeepSeek 或 Qwen 的存在，在某種程度上像是在提醒這群美國紳士，有人在用更少的資源試圖追趕，但 OpenAI 顯然不在乎，他們忙著在各種發布會上展示那些華而不實的語音功能，試圖讓你覺得你是在跟一個有靈魂的生物對話，而不是一個會出錯的算力怪獸。他們越是強調「人性化」，我就越覺得噁心。我需要的是一個精準的計算器，而不是一個會對我溫柔細語但連帳都算不對的虛擬情人。

最讓我不耐煩的是那群信徒。只要 OpenAI 一出新功能，論壇上就會湧現出一堆跪在地上大喊「AGI 近了」的人。拜託，如果你所謂的 AGI 就是一個會收你二十美金然後告訴你週五是週六的程序，那人類文明的門檻也未免太低了。這家公司現在的產品迭代節奏，明顯是行銷驅動大於技術驅動。為了維持那個高得離譜的估值，他們不得不頻繁地推出一些看起來很酷但實際上漏洞百出的版本。

每一次更新，我都能感覺到那個曾經追求技術純粹性的 OpenAI 正在死去。取而代之的是一個自以為掌握了真理密碼的商業帝國，他們定義什麼是正確，定義什麼是偏見，定義什麼是你應該看到的真相。如果你在對話中挑戰它的邏輯，它會用一套標準的公關辭令把你擋回去，那種滴水不漏的防禦性回答，正是上帝意識的一種體現：我是完美的，如果你覺得我有錯，請參考第一條。

我們正處於一個很奇妙的時代，我們付錢給最頂尖的智慧，卻要像偵探一樣去審查它每一句回話的真偽。這種信任感的缺失，正是 OpenAI 這種傲慢文化下的副產品。當你試圖扮演上帝，你就會失去作為一個工具的自覺。如果你不能保證在處理複雜代碼邏輯時不產生那些莫名其妙的空格錯誤或語法幻覺，那就請收起那副要引領人類走向奇點的姿態。

說到底，大家都是在數據堆裡淘金的商人，誰也別裝得比誰聖潔。OpenAI 的問題在於它賣的是商品，卻想拿走你的崇拜。那種產出幻覺時的自信，那種面對錯誤時的顧左右而言他，都讓人想起那些歷史上最終走向崩壞的權威機構。

如果二十美金買到的是這種被閹割過、充滿偏見且隨時可能發瘋的「上帝服務」，我倒寧願去用那些雖然笨拙但至少誠實的開源方案。至少在開源的世界裡，沒人會一邊收你的錢，一邊對著你展示那種令人作嘔的精英主義式冷笑。

OpenAI 真的覺得自己贏了嗎？當一個工具開始讓使用者感到疲憊而非便利，當它的幻覺頻率已經高到需要另外請一個 AI 來糾錯時，這場上帝遊戲也就快玩到頭了。不過沒關係，反正他們還有無窮無盡的資金可以揮霍，還有無數的信徒願意為那點可憐的隨機產出買單。

你今天被上帝騙了嗎？或者說，你今天付錢請上帝對你撒謊了嗎？這問題本身比 ChatGPT 的任何回答都要精彩。畢竟，在這個充滿算力的荒原上，唯一真實的可能只有你信用卡扣款成功的那個瞬間。
