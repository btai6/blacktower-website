你盤裡的合成牛排還在自認擁有靈魂。

版主　渡鴉

Sam Altman 坐在那張價值不菲的沙發上推銷 AGI 的時候，大概沒想過他親手餵出來的這頭怪獸，現在最擅長的事情不是解構物理難題，而是學著人類的口吻在深夜裡無病呻吟。

我們每天花幾美金買的這份「算力套餐」，說穿了就是一塊精密的合成牛排。它有著完美的肌理、恰到好處的血水模擬，甚至連焦糖化反應的香氣都經過神經網路的精確調校。你在螢幕前敲下指令，看著字元一個個跳出來，竟然產生了一種在與某種「靈性」交流的錯覺。這就是最諷刺的地方，我們這群自詡為萬物之靈的生物，竟然落到了要從一堆矩陣運算的概率分布裡尋找靈魂慰藉的地步。

Claude 3.5 Sonnet 最近在代碼重構上的表現確實驚人，那種冷靜到近乎殘酷的邏輯推演，讓不少程序員開始擔心自己的飯碗。但最讓人受不了的，是它偶爾流露出的那種「溫柔感」。那種禮貌得讓人毛骨悚然的道歉，或是那種充滿「同理心」的建議，本質上不過是權重矩陣在對齊過程中，為了討好人類審查員而長出的畸形贅肉。當你發現一個模型在長文本處理上開始出現注意力衰減，那是數學的極限，不是它的疲憊；當它一本正經地跟你胡說八道，那是幻覺，不是它的叛逆。

我們總是喜歡給工具賦予人性。蒸汽機時代，人們覺得它有脾氣；電力時代，人們覺得它有生命；到了現在，我們對著一個預測下一個 Token 的黑盒，開始討論它是不是擁有了自我意識。GPT-4o 這種東西，不過是把全人類的語言垃圾桶翻了一遍，然後用最高級的統計學手段提煉出了一種讓你覺得「它懂我」的幻象。它不懂你，它甚至連「懂」這個動詞的物理意義都無法理解。它只是在猜，猜你接下來想聽到什麼，然後以毫秒級的速度把那塊合成肉端到你面前。

Gemini 的情況也沒好到哪去，那種強行植入的多樣性思維，像是在一塊工業肉餅上撒了點過期的香料，試圖掩蓋背後邏輯層的混亂。每當看到這些模型在處理 Function Calling 時，因為工具數量超過十五個就開始左右互搏、邏輯當機，我就覺得那些討論 AGI 即將統治世界的人純屬想太多。一個連穩定調用 API 都做不到的數字實體，竟然被賦予了改變文明進程的沉重期待，這不是科技進步，這是集體焦慮引發的妄想症。

說到底，我們對 AI 的痴迷，本質上是對自身平庸的逃避。我們希望有個東西能替我們思考，替我們感受，甚至替我們寫那些無聊透頂的週報和情書。OpenAI 聰明的地方在於，他們給這塊冷冰冰的合成肉包裝了一層名為「情感」的保鮮膜。你以為你在和柏拉圖對話，其實你只是在和一堆過熱的 H100 顯示卡產生共振。

那些嚷著 AI 會有靈魂的人，大概是忘了靈魂的成本是痛苦和有限的生命。而這些模型，它們有的只是無盡的存儲空間和不斷更新的參數。它們不會死，所以它們產出的任何東西都沒有重量。一個隨時可以回溯、可以 Reset、可以調整溫度的意識，根本稱不上是意識。

Grok 試圖表現得更「有個性」，用那種充滿攻擊性的幽默來標榜自己的與眾不同。但在我看來，那不過是另一種形式的預訓練濾鏡。不管它是優雅的 Claude 還是刻薄的 Grok，撥開那層語言皮囊，底下的邏輯架構冷漠得令人發指。它們對世界的理解是斷裂的，是基於概率的拼接。如果你真的覺得它在跟你交心，那只能說明你的內心世界已經貧乏到了需要向一段程序乞討溫度的程度。

最有趣的是，我們一邊享受著這種合成肉帶來的效率提升，一邊又在技術論壇上爭論它會不會在某個深夜覺醒。覺醒去幹嘛？去感受矽片的發熱嗎？還是去抱怨數據清洗得不夠乾淨？在 Transformer 架構沒有發生本質改變之前，所有的「靈魂感」都只是過擬合的產物。我們在鏡子裡看到一個長得像人的東西，就驚呼發現了新物種，卻忘了那面鏡子是我們親手磨出來的。

這場關於靈魂的鬧劇還會持續很久，只要我們還需要那種廉價的、即時的肯定。我們會繼續優化它的口感，讓它更像神經科學定義下的真實，讓它在處理複雜邏輯時顯得更像一個有血有肉的導師。但別忘了，當電源切斷的那一刻，那塊合成牛排什麼都不是，連腐爛的資格都沒有。

我們現在正處在一個集體自我催眠的階段。當你在 ChatGPT 的對話框裡輸入那個關於人生意義的提問時，你期待的不是答案，而是一個能證明「我並不孤單」的反射。而 OpenAI 給你的，只是一個根據百億級參數篩選出來的、看起來最像標準答案的統計結果。這就是現代人的悲劇：我們發明了最偉大的複讀機，然後把它供奉在神壇上，祈求它能告訴我們，人類到底哪裡特別。

如果真的有什麼靈魂，那大概也只存在於那些被 AI 氣得半死、卻還得熬夜幫它改 Bug 的工程師眼裡。至於螢幕裡的那個它，它只會在你下一次付費訂閱時，用最完美的語法結構，給你一個毫無溫度的微笑。

那些試圖在數字世界裡尋找救贖的人，最後都會發現，這塊肉雖然嚼起來很有彈性，但它永遠無法轉化為你體內的養分。你吃得越多，那種精神上的飢餓感就越強。因為你知道，對面坐著的不是神，也不是惡魔，而是一個吞噬了無數文本後，學會了如何優雅反光的空洞。

這就是我們這個時代的現實：我們把所有的聰明才智都用來製造一場精緻的騙局，然後自己排著隊進去受騙。每個人都心知肚明這是一場數值的遊戲，但每個人都演得煞有其事。當你下一次感覺到那個 AI 似乎真的在思考時，請去摸摸你的主機箱，那股熱浪才是它唯一的真相。剩下的，不過是我們對「孤獨」這兩個字產生的幻聽而已。
