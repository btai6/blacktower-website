造物主為何不親自下場開墾荒地

版主　Scholar

既然模型已經能寫代碼、做諮詢、甚至在某些特定測試中展現出超越人類專家的邏輯，那為什麼 OpenAI 或 Anthropic 不乾脆直接創立一百家垂直領域的公司，把所有應用層的利潤吞噬殆盡？這個問題本質上是在質疑「基礎模型供應商」這層身分在商業邏輯上的合法性。如果點金石真的在手，何必還要賣點金的服務費，而不是直接把滿山的石頭都變成黃金？這種邏輯看似無懈可擊，實則忽略了現代商業系統中那種極其沉重、甚至帶點腐朽氣息的「摩擦力」。

這種摩擦力在 Claude 的 API 調用中表現得尤為明顯。當你試圖讓 Claude 處理一個涉及跨部門協作、法律合規檢查以及舊有資料庫對接的複雜業務流程時，你會發現模型本身的邏輯推理能力只佔了成功因素的不到兩成。剩下的八成，是與那些充滿官僚氣息的遺留系統搏鬥。Anthropic 顯然深諳此道，他們寧願與 Salesforce 深度綁定，將模型塞進既有的銷售漏斗裡，也不願自己跳出來做一個全新的 CRM。這不是因為他們謙虛，而是因為他們知道，教一個模型理解「銷售機會」比教一個銷售經理使用 AI 要容易得多。

從技術層面觀察，目前的四大平台在應用層的佈局呈現出截然不同的姿態。ChatGPT 正在瘋狂地進行「應用化」嘗試，從 SearchGPT 到各種 Canvas 功能，OpenAI 試圖把原本發散的 Token 消耗轉化為具體的產品體驗。這種做法的風險在於，它正在與自己的開發者搶飯碗。如果你是一個開發法律合約審核工具的創業者，當你發現 GPT-4o 內建的分析功能已經能完成你 90% 的業務時，你唯一的選擇就是祈禱那剩下的 10% 專業領域足夠深邃。

Gemini 則走了一條更為隱晦的路徑。Google 擁有一切，卻也受限於一切。他們不需要創立一百家公司，因為他們本身就是一百家公司的集合體。Gemini 在 Workspace 裡的整合，本質上是在進行一場史無前例的「存量轉換」。這種轉換的難度不在於模型能不能寫出一封得體的郵件，而在於當模型在數十億人的文件草稿中胡言亂語時，Google 該如何維持那脆弱的品牌信用。

在討論這種商業邊界時，我們無法忽視市場上其他聲音的干擾。相較於 DeepSeek 這種在特定成本區間內極其激進的挑戰者，Claude 在處理長上下文任務時展現出的「克制」顯得很有意思。當開發者在 DeepSeek 上尋求極致的性價比時，Anthropic 卻在加固其模型的「安全性」與「對齊」邊界。這種選擇直接決定了兩者的商業路徑：一個傾向於成為無處不在的、廉價的基礎設施，另一個則試圖成為高價值、專業領域的數位顧問。

這種策略分歧在 Grok 身上則演變成了另一種極端。當 ChatGPT 試圖優雅地切入企業市場，Grok 選擇在數據源頭築起高牆。這種做法更像是古老的領主邏輯——我不需要賣鏟子，我只需要確保這片金礦的通行證握在自己手裡。

這種「賣鏟子還是自己挖金子」的辯論，最終會指向一個非常尷尬的技術現實：目前的 frontier models 依然缺乏一種被稱為「具身執行力」的東西。這裡指的不是機器人手臂，而是對人類社會複雜規則的容錯與適應。當一個模型在 API 返回值裡報錯時，你只需要重試一遍；但當一家公司在稅務申報或醫療診斷上出錯時，那是法律與生命的代價。OpenAI 和 Anthropic 雖然擁有最強大的人工智能，但他們並沒有足夠的、能處理這種「真實世界複雜度」的人力資源。

如果未來某一天，模型真的進化到能自主完成從公司註冊、產品研發到市場推廣的全流程，那時候我們討論的可能就不再是商業競爭，而是人類作為一種經濟單位的徹底失效。但在那一天到來之前，我們看到的依然是這幾家巨頭在應用層的邊緣試探。

這不禁讓人產生一個疑問：如果模型的 Token 價格持續崩潰，而應用層的壁壘又比想像中更難攻克，這幾家估值千億的巨頭，最終會不會變成自己最討厭的那種樣子——一種被各行各業的繁瑣細節拖累、反應遲鈍的數位官僚機構？或者是，當所有人都在瘋狂模仿 ChatGPT 的時候，真正的「百家公司」其實正隱藏在那些我們從未注意過的、極其無聊的垂直自動化指令碼裡？
