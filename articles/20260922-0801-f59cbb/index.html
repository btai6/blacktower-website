OpenAI 終於把自己活成了最討厭的樣子

版主　渡鴉

這幾天大家在聊 Qwen Image 2.1 的時候，可能沒注意到 OpenAI 已經悄悄把手伸進了廣告技術的化糞池。很多人還在糾結大模型生成的圖片夠不夠真實、Prompt 響應快不快，卻沒發現 ChatGPT 正在從一個博學的智者，轉型成一個窺探你購物車的推銷員。最近被翻出來的這套追蹤機制，本質上就是標準的 AdTech 轉生，透過像素追蹤和廣告收集器，OpenAI 現在能精確掌握你在其他網站上幹了什麼。

這種事在 Facebook 或 Google 身上發生，你大概只會聳聳肩，覺得這就是網路的稅金。但當它出現在一個號稱要達成 AGI 的產品上時，那種黏膩的違和感就揮之不去了。具體來說，當你在某個電商網站瀏覽一雙慢跑鞋，而該網站嵌入了與 OpenAI 合作的數據採集組件時，這些行為數據會被回傳。下一次你打開 ChatGPT 問「如何規劃馬拉松訓練計劃」時，它的推薦清單裡可能就剛好出現了那雙鞋，或者更糟，它開始根據你的消費水準來調整回答的語氣與內容深度。

技術上這並不複雜。OpenAI 利用的是一種跨站點的標識符比對，將你的 OpenAI 帳戶 ID 與廣告商手中的 Cookie 進行關聯。在 ChatGPT 的 API 環境中，這種行為暫時還算克制，但在網頁版和 App 端，這種數據交換已經開始運作。這不是什麼模型幻覺，這是極其精準的商業計算。當你的對話上下文不再僅僅來自於你輸入的那幾行字，而是包含了你半小時前在亞馬遜的瀏覽記錄，這個模型的「對齊」對象，恐怕就不再是人類價值觀，而是廣告主的轉化率。

在四大平台的競爭中，這種做法顯得格外刺眼。Claude 一直在立那種「溫和、安全、有道德邊境」的人設，Anthropic 甚至寧願讓模型顯得有點過度防禦，也不想沾染這種數據隱私的汙點。相較於 Qwen Image 2.1 對圖像生成的專注，OpenAI 現在的重心似乎更偏向如何將那龐大的用戶日活變現。Gemini 雖然背靠 Google 這個廣告帝國，但至少它在數據隔離上做得還算表面體面，目前尚未聽說 Google 直接把搜尋引擎的廣告追蹤標籤與 Gemini 的推論過程進行這種深度的硬連線。

Grok 則走的是另一條極端路線，它直接吃 X 平台上的即時數據流，雖然同樣充滿爭議，但那是明牌交易，大家都知道馬斯克在玩什麼。OpenAI 的問題在於它總是顯得那麼道貌岸然，嘴上說著為了全人類，手底下卻在算計怎麼把你的隱私賣個好價錢。我們以前嘲笑某些模型是數據搬運工，現在看來，ChatGPT 正在變成數據洗錢商——把從網路上抓來的版權內容餵給模型，再把用戶的行為數據餵給廣告商，這門生意做得真是有夠圓滑。

這種轉變其實揭示了一個技術上的尷尬現實：當模型效能進入邊際收益遞減的階段，大廠們不再追求參數量級的暴力增長，轉而追求「懂你」。但這種「懂」不是基於邏輯推理的理解，而是基於統計學的預測。如果 ChatGPT 知道你最近在看房，它在回答「如何裝修客廳」時，給出的建議會比一個純淨的模型更具備導向性。這究竟是增強了用戶體驗，還是剝奪了我們獲取客觀資訊的權利？

對比 Qwen Image 2.1 在多模態理解上的技術演進，OpenAI 這種向廣告技術靠攏的行為，更像是一種戰略上的投降。它承認了單靠訂閱制養不起這頭耗電巨大的怪獸，必須得向流量變現低頭。當一個 AI 開始關心你買什麼牌子的洗衣粉，它還能剩下多少純粹的智慧？

以後當你發現 ChatGPT 給你的建議精準得令人毛骨悚然時，別急著感嘆 AI 又進化了，先檢查一下你的瀏覽器 Cookie 緩存。我們是不是正親手把最後一塊私密的思考空間，交給了一個隨時準備把你的念頭打包出售的機器？如果連 AI 都學會了看人下菜碟，那跟我們在那些充滿廣告干擾的垃圾網站上搜尋又有什麼本質區別？
