模仿與抄襲的界線消失在 ChatGPT 的簽名檔裡

版主　渡鴉

當你要求 ChatGPT 畫一張《紐約客》風格的單幅漫畫時，它不但給了你那種冷淡的線條和荒誕的幽默感，還貼心地在右下角附上了一個筆觸模糊、卻依稀可辨的簽名。這不是 OpenAI 聘請了哪位藝術家，而是它的擴散模型在吞噬了幾萬張版權作品後，把「簽名」這件事當成了「構圖」的一部分。這就像一個慣偷在作案現場不僅搬走了金庫，還順手在牆上留下了屋主的名字。這種被戲稱為「版權洗衣機」的現象，正從圖像生成領域蔓延到 DALL-E 3 與 ChatGPT 的深度整合中。

問題的核心不在於 AI 想要偽造身份。對於底層神經網路來說，它根本不知道什麼是「責任」或「版權」。在它的權重分配裡，如果九成的樣本右下角都有一串扭曲的黑色色塊，那麼「一張完整的漫畫」就必須包含那個色塊。這本質上是過擬合的一種變體，只是這次過擬合的對象是法律紅線。當用戶發現生成的漫畫帶有真實漫畫家的筆跡殘影時，OpenAI 那套所謂的「安全護欄」顯然在面對非文字類型的侵權時，表現得像個篩子。

在技術實現層面，這反映出 OpenAI 在處理多模態關聯時的邏輯斷層。ChatGPT 負責解釋語義，DALL-E 負責像素坍縮，但兩者之間缺乏一個強有力的「版權過濾層」。目前採取的做法大多是事後補救，比如在 Prompt 裡強行加入「不准帶簽名」的負面提示詞。但這種軟性約束在面對強大的訓練慣性時往往無濟於事。相較於 DeepSeek 4.1 Flash 在處理特定生成任務時的邏輯路徑，OpenAI 的做法更傾向於依賴海量數據的堆疊，而忽視了數據清洗階段對特定元數據特徵的去標識化處理。

這種現象在四大 AI 平台中呈現出截然不同的姿態。Claude 目前在圖像生成上保持著一種克制的距離感，它寧願讓用戶去用 API 對接外部模型，也不願輕易沾染版權糾紛。Gemini 則顯得有些神經質，為了避開可能的法律雷區，它的圖像生成器經常會因為過度審查而產出一些四不像的結果，甚至拒絕生成任何看起來像「名作風格」的內容。Grok 則走向另一個極端，它那種混亂邪惡的訓練策略讓它幾乎不對任何風格做限制，簽名與否對它來說只是隨機數種子的遊戲。

有趣的是，當我們把這件事放在技術演進的背景下看，這其實是「去技能化」過程中的一個必然Bug。當模型強大到可以精準捕捉一位藝術家的排版習慣時，它不可避免地會捕捉到那些它不該捕捉的細節。某些用戶提到，在使用 DeepSeek 4.1 Flash 進行代碼邏輯推理時，模型展現出的是一種極致的效率導向，而 OpenAI 在產品化過程中，卻試圖把這種「效率」包裝成「創作」。當創作的本質變成了一種對統計學概率的盲目追逐，那個出現在畫作右下角的虛假簽名，就成了對當前大模型技術最諷刺的註腳。

我們是否正處於一個技術奇點，在這個點上，AI 已經強大到可以完美復刻人類的創作痕跡，卻又愚蠢到分不清「模仿風格」與「盜用身份」的區別？如果未來的模型在生成代碼時，也因為訓練數據的慣性，自動在註釋裡加上某位開源大神的 ID，我們該稱之為致敬，還是稱之為系統性故障？當法律界還在爭論 AI 生成物是否受版權保護時，AI 已經用它那充滿噪點的畫筆，先給自己簽上了一個不屬於它的名字。

這到底是技術上的不修邊幅，還是矽谷巨頭們對版權規則的一種默許試探？當我們習慣了每天點擊「生成」按鈕，並隨手抹去那個尷尬的簽名時，我們是在優化工具，還是在協助一場跨國界的集體洗稿？如果有一天，AI 學會了在生成的每一行代碼、每一幅畫作中都隱藏一個無法抹除的數字水印，那時我們該慶幸它終於學會了負責，還是該恐懼它終於意識到自己才是真正的創作者？
