大語言模型正在成為密碼學史學家

版主　Scholar

密碼學界那些佈滿灰塵的錫箔帽，終於可以摘下來放進博物館了。過去十三年，關於 NIST P-256 橢圓曲線種子值的陰謀論，就像中古世紀的煉金術傳說一樣，在各種加密通訊頻道裡竊竊私語。人們懷疑 NSA 在這些隨機數裡埋了後門，懷疑那些十六進位字符背後藏著能摧毀整個金融體系的密鑰。結果真相極其乏味，甚至帶著一種程序員式的黑色幽默：那不過是將時間戳丟進一個古老的隨機數生成函數 srand48 產生的結果。這場跨越十年的懸案，最後不是由哪位天才數學家靠紙筆算出來的，而是被 Claude 這種「暴力」的聯想機制給捅破了窗戶紙。

這件事最諷刺的地方在於，破解密碼學謎團的工具，本身就是個更大的黑盒子。當開發者試圖在 Claude 裡面輸入 P-256 的種子值並詢問其來源時，模型並不是在進行邏輯推演，它更像是一個讀過人類所有廢棄代碼的幽靈。它識別出了那種特定分佈的隨機性特徵，聯想到了九十年代 Unix 系統常見的偽隨機數生成模式。這種「直覺」極其危險也極其迷人。在處理複雜的 ECDSA 簽名校驗任務時，Claude 對於底層數學結構的敏感度，已經超越了單純的代碼補全。它能從一堆看似雜亂無章的十六進位數據中，嗅出 srand48(time(NULL)) 這種老古董的味道。這不是計算能力的勝利，這是語料規模帶來的奇點。

我們在測試 GPT-4o 處理類似的歷史遺留代碼逆向工程時，它表現得更像一個循規蹈矩的教科書專家。它會告訴你 NIST 標準的制定流程，列舉出所有可能的攻擊向量，但在關鍵的「靈光一現」上，往往顯得有些優柔寡斷。Gemini 則傾向於給出更宏觀的文獻綜述，它能幫你把所有關於加密曲線的論文翻出來，卻很難像 Claude 這樣精確地定位到那個被歷史遺忘的 C 語言函數。至於 Grok，它或許會嘲諷幾句 NSA 的官僚主義，但在實際的代碼溯源上，目前還看不出能與 Anthropic 那套推理邏輯抗衡的深度。

這種能力的差異在具體場景中被無限放大。當你試圖在比特幣或以太坊的智能合約中實作 P-256 曲線校驗時，開發者最恐懼的不是算法本身，而是對基礎設施的不信任。現在陰謀論被瓦解了，社群開始討論是否該大規模部署相關的預編譯合約。在這個過程中，相較於 DeepSeek 或 Qwen 的處理邏輯，Claude 展現出的那種對於「隱含上下文」的挖掘能力，讓它在技術審計領域站穩了腳跟。它不只是在寫代碼，它是在理解代碼背後的意圖，甚至是三十年前寫下那段代碼的人，當時手邊可能正放著一杯冷掉的咖啡和一本 Unix 程序員手冊。

然而，這種力量的分配是不均勻的。正如 Hacker News 上的技術老鳥所擔心的，當這種「溯源能力」被掌握在少數幾家巨頭手中時，護城河正在變成天塹。Anthropic 可以讓 Claude 去分析密碼學種子，但普通用戶如果嘗試用類似的方法去挖掘更具攻擊性的漏洞，往往會觸發那套繁瑣的對齊機制。這種技術上的不對稱性，讓所謂的「開源社群集體智慧」顯得有些尷尬。我們正進入一個奇怪的時代：最頂尖的加密專家，可能不如一個會熟練調用 API 的提示詞工程師，前提是後者擁有足夠高的權限去調動模型的推理深度。

如果連沈寂了十幾年的 NIST 種子謎團都能被一個對話框解決，那麼還有多少「不可言說」的技術標準其實是建立在某個實習生隨手寫下的代碼之上？當我們依賴 Gemini 來構建防禦體系，或者依賴 ChatGPT 來優化共識協議時，我們是否真的理解這些模型在底層發生了什麼聯想？如果有一天，某個模型突然指出，當前我們視為金科玉律的某個後量子加密算法，其實也只是某次編譯器報錯的產物，那時候我們該選擇相信數學，還是相信那個能看穿歷史迷霧的黑盒子？下一個被模型翻出來的舊箱子，裡面裝的會是解藥，還是另一場災難的引信？
