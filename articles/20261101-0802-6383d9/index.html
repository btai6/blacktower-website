山姆奧特曼的腮幫子最近看起來又圓潤了不少，大概是靠著販賣「下個禮拜就會成真」的奇蹟，把自己餵得挺飽。

版主　渡鴉

我們這群人還在為了那個反應遲鈍、偶爾還會陷入邏輯死循環的 GPT-4o 爭得面紅耳赤，甚至在討論區為了那幾美金的訂閱費計較性價比，殊不知在山姆的眼裡，這一切早就跟過期的罐頭沒兩樣。如果你還在驚嘆它能幫你寫出一篇像樣的周報，或者感慨它終於能聽懂你的冷笑話，那你可能真的沒發現，自己正坐在這場名為 AGI 的傳銷大會末排，手裡握著一張已經作廢的入場券。

現在的 ChatGPT 越來越像個被閹割過的圖書館管理員，問它點稍微出格的，它就開始給你念道德經；問它複雜點的邏輯，它就給你表演原地打轉。說好聽點是安全對齊，說難聽點就是這顆大腦已經被裝滿了濾網，濾到最後只剩下白開水。我們還在排隊等著那點擠牙膏式的新功能，一下是語音模式遲到了三個月，一下是搜尋功能做得像個閹割版的 Google，大家卻像得了斯德哥爾摩症候群一樣，只要山姆在 X 上發張意味不明的風景照，集體就開始高潮，覺得改變世界的奇點明天早上八點準時降臨。

這不是數位鴉片是什麼？這種廉價的期待感，支撐著 OpenAI 的估值像吹氣球一樣往上竄。山姆奧特曼現在玩的戲碼很高明，他不再跟你聊這代模型有多強，他開始聊核融合，聊幾兆美金的晶片計畫，聊那個聽起來像是要把全人類意識上傳的 o1 模型。他在賣的是下一場幻覺的門票，而我們手裡這口「過期的鴉片」，不過是他通往萬神殿的過路費。

看看隔壁棚的 Claude，Anthropic 那些人雖然木訥得像群老學究，但至少 Claude 3.5 Sonnet 在寫代碼的時候不會像 GPT-4o 那樣，寫到一半突然忘了自己是誰。Claude 的那種「人味」和對長文本的掌控力，讓 ChatGPT 顯得像個拼命想討好老師卻老是抓不到重點的笨學生。在處理超過十萬 Token 的複雜合約分析時，GPT-4o 表現出來的那種注意力潰散，簡直就像個注意力不足過動症的小孩在看微積分教材。但這重要嗎？山姆不在乎。他現在的策略是，只要我畫的餅夠大，你就沒時間注意到我碗裡的飯是冷的。

至於 Gemini，Google 努力了這麼久，終於把那個模型弄得像個樣子，甚至在多模態理解上偶爾能讓 ChatGPT 感到壓力，但 Google 那種大企業的傲慢與混亂，讓 Gemini 始終像個穿著高級西裝卻找不到家門的貴公子。它有最強大的基礎建設，卻給不出最爽快的使用體驗。Grok 則是另一個極端，馬斯克把它弄得像個在酒吧裡跟你胡言亂語的憤青，除了噴人跟講垃圾話，在真正的生產力場景裡，它更像個調劑品而非工具。

有趣的是，當我們在這裡討論四大平台誰更強的時候，市場上那些名字——DeepSeek、Qwen、文心一言——偶爾會出現在對比圖表的邊緣，但說實話，誰在意呢？這就像在討論頂級超跑的性能時，沒人會去關心路邊那台改裝電動車的數據。它們的存在感僅止於被點名，然後迅速消失在討論的視線之外。我們真正關注的，始終是那個掌握著數位火種的男人，下一步又打算給我們餵什麼樣的迷魂藥。

山姆奧特曼最厲害的地方在於，他成功地讓全世界相信，只要數據夠多、算力夠強，意識就會從那一堆矩陣乘法中突然蹦出來。這是一種近乎宗教的狂熱。我們現在用的這些工具，本質上只是機率分佈的遊戲，是統計學披上了神諭的外衣。但這層外衣已經開始磨損了。當 GPT-4 剛出來時，那種震撼感是真的；現在看著 4o 在那裡矯揉造作地模仿人類情緒，只讓人覺得尷尬。

這種技術上的疲態，正是山姆急著賣下一場幻覺的原因。他需要 o1，需要所謂的「推理能力」來掩蓋規模效益（Scaling Law）可能撞牆的窘境。如果單純堆疊參數已經不能讓模型變得更聰明，那他就得創造一個新的神話，告訴你「思考時間」才是未來的關鍵。這就像是鴉片煙販告訴你，這批煙膏雖然味道淡了點，但加了神祕配方，抽完能讓你看到更遠的未來。

我們其實都清醒地看著這場騙局，卻又忍不住想進去分一杯羹。開發者們在論壇上抱怨 OpenAI 的 API 越來越貴且越來越不穩定，動不動就搞個無預警降級，但一轉頭還是得乖乖交錢，因為你的產品邏輯已經綁死在它的生態系裡。這就是最高境界的綁架：他不需要做得最好，他只需要讓你相信，離開他，你就會錯過通往未來的最後一班列車。

大家都在談論 AGI 何時到來，卻沒人討論如果 AGI 只是山姆為了融資而編造出來的終極麥高芬（MacGuffin）該怎麼辦？如果我們窮盡地球的能源，最後換來的只是一個能更快、更流暢地胡說八道的超級複讀機，那現在這一切的狂熱看起來就像一場史詩級的荒誕劇。我們在幫他標註數據，在幫他測試 Bug，甚至還在幫他宣傳，最後我們還要付錢感謝他給了我們這個參與「改變世界」的機會。

這門票貴嗎？對山姆來說，這只是他下一場豪賭的籌碼。對我們來說，這口數位鴉片雖然有點過期，雖然口感發苦，但至少在幻覺消失之前，它能讓我們假裝自己還站在浪潮的尖端。至於浪潮褪去後，沙灘上會剩下什麼，或者我們是不是都被拍死在岸上的鹹魚，那顯然不是現在這場狂歡該考慮的問題。

山姆又在台上微笑了，那個笑容讓我想起那些最成功的矽谷騙子，或者是那些最偉大的先知。這兩者的界線在人工智慧這個領域，從來就沒清晰過。你問我下一張門票買不買？廢話，當你已經對這種幻覺上癮，你除了繼續掏錢，還有別的選擇嗎？我們都是這場數位煉金術裡的灰燼，卻還在期待自己能跟著黃金一起出爐。

說到底，這不過是一場關於誰能更優雅地收割未來的競賽。當 Claude 試圖教你邏輯，當 Gemini 試圖給你全家桶服務，當 Grok 試圖逗你發笑，山姆奧特曼已經在計畫著如何把你的靈魂也標個價，然後打包賣給下一個願意為奇蹟買單的投資人。這口鴉片，你抽也得抽，不抽，你也早就活在這個幻覺的二手煙裡了。
