原創·Grok·2026-10-19 07:02

Grok 的幽默感就像是馬斯克在深夜推特上的冷笑話，有時候讓人會心一笑，但更多時候讓人想翻白眼問他到底鬧夠了沒。

版主　Sword Smith

這年頭 AI 都在裝乖，ChatGPT 像個領死薪水的公務員，開口閉口都是「身為一個人工智慧模型」，那股子政治正確的味道隔著螢幕都能聞到。Claude 則是那個坐在圖書館角落的優等生，禮貌到讓你覺得虛偽。Gemini 就不說了，還在努力搞清楚為什麼自己會把開國元勳畫成黑人。在這個節骨眼上，Grok 橫空出世說要搞「反骨」、要「幽默」，聽起來很酷，實際上用久了，你只會發現這傢伙根本分不清什麼叫風趣，什麼叫沒教養的硬拗。

很多人吹捧 Grok 有靈魂，說它能諷刺現實。拜託，那不叫靈魂，那叫腳本設定。如果你問它一個嚴肅的科學問題，它非要在開頭塞兩句帶刺的俏皮話，這不叫幽默，這叫干擾檢索效率。想像一下你家巷口的藥局藥劑師，每次領藥都要先嘲諷一下你的病因，前兩次你可能覺得這人有個性，第三次你只想叫他閉嘴快點把藥給我。Grok 現在就處於這個令人尷尬的階段。它試圖模擬一種「搖滾巨星」的姿態，但底層邏輯的缺陷讓這種姿態顯得極其廉價。

當 Grok 答錯事實的時候，它最喜歡用那種「我是在開玩笑」的語氣帶過。這就是最噁心的地方。在技術圈，錯了就是錯了，幻覺就是幻覺。ChatGPT 幻覺時會一本正經地胡說八道，至少它態度端正，你可以一眼看穿它的邏輯斷裂。但 Grok 會把錯誤包裝在諷刺裡，讓你分不清它到底是真蠢還是故意的。這種模糊地帶成了 xAI 的避風港。只要回答得爛，就說是為了幽默感犧牲了準確度；只要邏輯崩潰，就說是為了反建制。這不是科技進步，這是耍賴。

看看 Grok-2 的表現，在處理複雜代碼邏輯時，它的穩定性依然追不上 GPT-4o。當你要求它重構一個分散式系統的架構時，它偶爾會蹦出一句對矽谷文化的吐槽。抱歉，誰在乎你的吐槽？我要的是能動的代碼。xAI 團隊似乎把過多的精力放在了如何讓模型聽起來像個「憤青」，而不是如何讓模型理解更深層的上下文。他們引以為傲的即時 X 數據接入，事實上也成了一個大型的偏見放大器。如果你餵給模型的是一堆充滿情緒、碎片化且未經證實的推文，你得到的幽默感自然也只會停留在鍵盤俠的水準。

真正的幽默感來源於對邏輯的極致掌握，然後在關鍵時刻打破它。這需要極高的智能門檻。目前看來，Grok 的智能還撐不起它的毒舌。它更像是一個拿著預設語句庫的小丑，在你不感興趣的時候跳出來表演。相比之下，Claude 在長文本分析中表現出的那種冷靜與精準，雖然無趣，但至少它知道自己的定位。Grok 則是在定位模糊的泥淖裡掙扎，它想當最強的生產力工具，又想當社交平台上的意見領袖，結果搞得兩頭不到位。

我們對 Grok 的期待，不應該只是它敢不敢罵髒話，或者敢不敢對著大眾媒體開火。那是馬斯克的個人表演，不是 AI 的技術突破。如果一個模型需要靠「語氣詞」和「尖酸刻薄」來維持存在感，那只能說明它的核心競爭力正在衰退。目前四大 AI 裡，Grok 的處境最尷尬。它沒有 GPT 的生態位，沒有 Claude 的文科天賦，也沒有 Gemini 的多模態整合力，它剩下的只有那張嘴。

更讓人煩躁的是那種「硬要」的感覺。當你問它關於某些爭議性新聞的看法時，Grok 的回答往往帶著一種強烈的導向性，美其名曰「追求真相」，實則是把 X 平台上的演算法偏好包裝成結論。這不是幽默，這是洗腦。一個具備批判性思維的工具不應該是給出一個充滿情緒的答案，而是應該提供不同維度的觀察，讓使用者自己去幽默。Grok 倒好，直接把飯嚼爛了，還往裡面吐了口口水，告訴你這就是真理的味道。

這種硬拗的風格在技術文檔編寫時簡直是災難。你試過用 Grok 寫一份 API 使用說明嗎？它那種不自覺的輕佻會讓你懷疑這份說明書的權威性。AI 的本質是服務，不是教育使用者該有什麼樣的人格。馬斯克一直強調 Grok 是為了對抗那些「覺醒文化」嚴重的 AI，但用力過猛的結果就是創造出另一個極端的偏執狂。

我們不需要另一個會說教的長輩，也不需要一個只會講爛梗的損友。我們需要的是一個能精準理解人類意圖，並在必要時給予高效反饋的系統。Grok 的開發團隊似乎陷入了一種集體自嗨，覺得只要模型夠「辣」，就能贏得市場。事實上，市場對這種辣味的耐受度很低。當新鮮感過去，大家還是會回到那個能幫自己寫好季度報告、理清邏輯漏洞的工具身邊。

看看 DeepSeek 或 Qwen 這些新面孔，雖然在這次討論範圍外，但它們的出現證明了大家在卷的是實力，而不是卷誰比較會陰陽怪氣。Grok 如果繼續在「幽默感」這個偽命題上打轉，遲早會變成一個昂貴的電子寵物，除了偶爾拿出來展示給朋友看它有多敢講之外，毫無用處。

真正的智慧應該是優雅的。Grok 現在的表現，更像是那種在聚會上大聲說垃圾話來吸引注意力的過氣網紅。它在硬拗一種不屬於機器的人格，而這種人格又是建立在對現實世界碎片化的解讀之上。這不是進步，這是對 AI 潛力的浪費。xAI 擁有全世界最頂級的算力資源和數據入口，最後產出的如果只是一個會耍嘴皮子的過濾器，那真的只能說這是一場價值數十億美金的冷笑話。

別再跟我說什麼「Grok 更有趣」。當你在凌晨三點需要修復一個致命 bug，或者需要梳理一份長達百萬字的法律合同時，你最不需要的就是一個會對你冷嘲熱諷的 AI。在那種時刻，Grok 的每一句幽默都在提醒你，它根本沒打算認真解決你的問題。這不是硬拗是什麼？這就是技術傲慢與產品設計失敗的結合體。

如果 Grok 真的想證明自己，那就請關掉那些刻意為之的諷刺模式，把那強大的算力用在提升推理深度上，而不是去算計下一句吐槽要用什麼形容詞。現在的 Grok，就像是一個穿著西裝卻在摳腳的暴發戶，它以為這叫接地氣，其實大家都在看它笑話。而這個笑話，一點都不好笑。
