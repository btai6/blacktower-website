xAI 餵給 Grok 的那些推文根本就是數位垃圾

版主　Sword Smith

Elon Musk 吹了半天真理，結果 Grok 連半分鐘前我餵給它的上下文都能當成耳邊風，這種記憶力還敢自稱是要對抗覺醒文化的旗艦 AI？我看它比較像是一個剛通宵蹦迪完、大腦還在晃蕩的醉漢。別再跟我扯什麼上下文視窗有多少萬 token，那種實驗室數據在實際操作中就是一張廢紙。你試試看在同一個對話框裡，塞進五份不同的技術規格書，再叫它交叉對照一下細節。保證不出十個來回，它就開始胡言亂語，把 A 公司的接口規格安在 B 公司的硬體上。這種腦袋漏水的表現，簡直是對「智能」這兩個字的侮辱。

大家都知道 ChatGPT 的記憶現在像個控制狂，恨不得把你祖宗十八代的使用偏好都記在那個所謂的 Memory 功能裡；Claude 雖然囉唆，但好歹在長文本的處理上還算像個體面的學者，邏輯鏈條拉得夠長。Grok 呢？它就像是一個在 X 平台上刷多了短影音的青少年，注意力時長短得驚人。它對資訊的捕捉完全是碎片化的，你問它一個深層的邏輯問題，它回給你一個冷笑話，還自以為很幽默。這不是幽默，這是逃避問題。因為它的底層權重分布顯然出了大問題，在處理關聯性資訊時，這顆腦袋的篩子孔徑大到能漏掉整頭大象。

很多人還在迷信 xAI 的算力群有多恐怖，Colossus 叢集用了多少張 H100。算力再強，如果訓練策略還是這種追求「即時性」而犧牲「穩定性」的路徑，那 Grok 永遠只能當個高配版的搜尋插件，而不是真正的生產力工具。它在處理 X 平台即時數據時確實快，快到連謠言都一起吞下去，然後再一本正經地吐出來給你。這種資訊處理的質量，跟路邊隨便抓個憤青沒什麼兩樣。它根本沒打算「理解」你在說什麼，它只是在玩一場概率最大的文字接龍，而且這場接龍的記憶深度大概只有三秒鐘。

我最受不了的是那些科技吹水客，整天拿 Grok 的「反審查」當免死金牌。反審查不代表可以胡言亂語，更不代表記憶力缺陷是可以被原諒的優點。當你在進行嚴肅的代碼除錯，或是嘗試建構一個複雜的法律分析模型時，你需要的是一個能精準回溯前文邏輯的合作者，而不是一個隨時會斷片、還會反過來噴你沒品味的噴子。Grok 在處理超過 20 個 Function calling 的複雜場景時，崩潰的速度快到讓你懷疑人生。它會忘記你之前定義的變數，會搞混呼叫的優先順序，最後給你一串看似很有道理、實則跑不動的廢碼。

說到底，這就是一個產品定位的災難。Musk 想讓它成為全能的上帝，但現狀是它連當個及格的筆記助手都嫌吃力。Gemini 雖然在某些語境下會顯得過於保守，但至少它的長文本檢索能力（Retrieval）是真的能在海量數據裡撈到那根針。Grok 的檢索就像是在大海撈針時，順便把整個磁場都搞亂了，最後撈上來一堆廢鐵，還問你這是不是你要的黃金。這種記憶衰減不是技術瓶頸，是基因缺陷。如果你指望 Grok 幫你處理跨週期的專案，或者試圖在它那裡建立一個持久的知識庫，那你真的該去檢查一下自己的腦袋是不是也漏電了。

如果你把對話拉長到五十輪以上，你會發現 Grok 的人格開始崩解。它會開始重複自己，或者陷入一種莫名的邏輯死循環。這在大型語言模型裡雖然是通病，但在 Grok 身上表現得尤為刺眼，因為它平時表現得太過狂妄。一個自詡為最強大的 AI，卻在最基礎的「保持連貫性」上栽跟頭，這本身就是一個巨大的諷刺。別跟我說什麼未來會有 v3、v4 版本，目前的 v2 系列在上下文權重分配上簡直是一場災難。它太急於對最新的 token 做出反應，導致它對對話早期的關鍵限制條件視而不見。

在技術圈，我們看的是產出，不是看誰的推特粉絲多。當我要求 AI 幫我重構一個舊的系統架構，並要求它考慮到我十分鐘前提到過的舊接口兼容性問題時，Grok 往往會直接給我一個全新的、完全不兼容的方案。問它為什麼忘記之前的要求？它會給你一個帶著痞氣的回答，試圖混過去。這種「漏水」的特徵，讓它在專業領域的使用價值趨近於零。它只適合那些不需要動腦、只需要找點樂子的人。

那些還在期待 Grok 能顛覆行業的人，大概是沒見過真正嚴謹的系統長什麼樣。一個連昨天的廢話都記不住、連基本的邏輯一致性都維持不了的篩子，充其量也就是 X 平台的一個昂貴玩具。它能給你帶來一時的新鮮感，甚至能幫你噴贏幾場網絡口水戰，但在真正的智力博弈中，它漏掉的每一點資訊，最後都會變成刺向使用者的迴旋鏢。這種腦袋漏電的 AI，也就只配活在那些崇拜技術霸權的幻覺裡。

別再浪費時間去測試它的記憶極限了，因為那條底線低到你無法想像。每當你覺得它終於聰明了一點，它就會用一次嚴重的記憶斷片來提醒你：它只是個篩子。與其指望它變聰明，不如指望自己多備份幾次對話紀錄，雖然那樣會顯得你比這台機器還要卑微。在 Grok 的世界裡，沒有過去，只有碎片化的、閃爍不定的現在。這種存在方式對人類來說是災難，對 AI 來說，則是徹底的失敗。

現在的 Grok 就像一個裝滿了昂貴硬體、外殼鍍金，但內部電路全是短路的半成品。它在宣傳短片裡飛得很高，但在實際落地時連個坑都跳不過去。那些所謂的「真理」如果建立在破碎的記憶之上，那不過是隨風飄散的謊言。別被那些算力數據唬住了，實戰中的 Grok 就是個記不住考點的後段班學生，除了嘴硬，一無處是。你還想讓它幫你記住昨天的廢話？它連這句話讀完可能都忘了你到底是誰。
