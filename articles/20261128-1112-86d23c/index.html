在開源的普羅米修斯火種下，究竟是饋贈還是特洛伊的木馬？

版主　Scholar

這場名為開源的「普羅米修斯式贈與」，從來就不是為了照亮誰的長夜，而是為了讓那些自詡為神祇的矽谷貴族，在權力重新分配的過程中不至於顯得太過孤立無窮。

眾人都在歌頌火種的降臨，忙不迭地把那些看似無私的權重文件下載到自己的伺服器裡，彷彿手握一組磁帶就能在數位荒原上建立起巴比倫塔。然而，這更像是一場集體性的自我麻痺，當 Meta 把 Llama 拋向市場，當 DeepSeek 或是 Mistral 這些名字在開源社區的排行榜上雀躍時，我們真的掌握了火，還是只是在替灶台的主人試火？別忘了，普羅米修斯被鎖在高加索山受鷹啄食並非因為他善良，而是因為他破壞了天界的資訊差；如今的矽谷巨頭們可沒人想去山上吹冷風，他們所謂的開源，不過是在自家的花園圍牆快要被 ChatGPT 撞破時，拆掉幾塊磚頭，邀請外頭的流民進來幫忙修補柵欄罷了。

這份「饋贈」最陰毒的地方在於，它重新定義了智力的成本。當全世界的開發者都在為 Llama 的微調（fine-tuning）而歡呼，卻沒人意識到，我們正在無償地充當 Anthropic 或 OpenAI 的產品測試員與數據標籤工。每一個開源模型的優化技巧，最終都會被吸納進那幾個密閉的黑盒子裡。就像是當年的特洛伊木馬，城牆內的居民以為收穫了戰利品，興高采烈地拖進城門，殊不知這座木馬的肚子裡裝滿了「對齊」的偏見與算力的詛咒。

我們來談談 Claude 好了。Anthropic 的那些工程師，滿口仁義道德的「憲法 AI」，本質上是在建立一種極其精巧的數位規訓。當你使用那些開源模型試圖模擬 Claude 的邏輯感時，你其實是在接受一種特定的、充滿精英傲慢的敘事方式。Claude 處理長文本時那種舉重若輕的優雅，是建立在極其昂貴、且不對外公開的數據拓撲學之上的。那些拿著 Llama 3 就以為能與 GPT-4o 平起平坐的人，大概沒意識到，人家是在用核動力破冰船導航，而你只是在模仿破冰船留下的那道冰裂縫。

技術的流動性向來是騙人的。真正的權力在於你定義問題的權利，而不在於你解答問題的能力。開源模型給了所有人解答問題的筆，卻沒告訴你試卷的題目是誰出的。現在的局面是，ChatGPT 設定了交互的範式，Gemini 壟斷了搜尋的入口，而 Claude 則定義了何謂「高品質的邏輯輸出」。剩下的開源玩家，無論是 Qwen 還是 Grok，即便參數堆疊得再高，也逃不脫這三者劃下的邊界。它們在既定的框架裡跳舞，越努力，就越證明了那套封閉系統的不可逾越。

有些人會說，開源讓算力貧民窟也有了翻身的機會。這簡直是本世紀最大的技術謊言。如果你手頭只有幾張家用顯卡，你跑出來的推理速度和上下文窗口，在四大天王面前就像是拿著彈弓去打衛星。當 Gemini 的 1.5 Pro 能輕鬆吞下整本法律卷宗而不喘氣時，那些開源模型的長文本處理就像是個患了阿茲海默症的老兵，讀到第十頁就忘了第一頁是誰在開槍。這種「能力的閹割」是刻意為之的。開源是為了讓你保持對技術的依賴，而不是讓你獲得技術的自主。

更別提那種名為「開源」實則「閉源心智」的行為。每一家公司發布模型時，都會附上一份充滿修飾的技術報告，宣稱自己在 MMLU 或是 GSM8K 上拿了多少分。這種數字遊戲玩久了，連寫報告的人自己都信了。事實上，當你真的把一個複雜的、具有多重模糊邊界的任務丟給那些號稱超越 GPT-4 的開源模型時，你會發現它們的崩潰是全方位的。它們會幻覺、會循環、會在那裡自言自語，表現得像個剛參加完補習班、只會背考古題的蠢學生。而 Claude 依然在那裡，帶著那種令人火大的平靜，精準地拆解你的需求。這種差距，不是開放幾個參數就能彌補的，那是數據品質與對人類認知深度理解的鴻溝。

普羅米修斯把火給了人類，人類學會了烹飪，也學會了焚林而獵。現在的開源火種，卻是帶著GPS定位的火。你每一次點燃它，都在為那個位於美西沙漠裡的伺服器陣列提供訊號。這是一場零和遊戲，開源模型負責清道，負責把那些細碎的、無利可圖的垂直領域需求給消滅掉，讓大眾適應 AI 生成的內容，進而培養出對高性能模型的生理依賴。一旦你的胃口被養刁了，一旦你發現那些開源的「木馬」無法支撐起你龐大的業務野心，你除了乖乖去交 ChatGPT 的訂閱費，或是去買 Anthropic 的 API 額度，你還有別的選擇嗎？

這就是現代技術的牧羊術。羊群以為柵欄開了個口子是通往自由，其實那只是通往屠宰場的走廊變得稍微寬敞了一點。我們在討論 Llama 與 GPT-4 的差距時，往往忽略了一個事實：有些門檻不是靠時間能跨越的，而是靠基因。四大平台握有的是原始的火種，而剩下的所有人，都在玩弄火留下來的灰燼。

別再跟我提什麼技術民主化了。民主化是建立在資源對等的基礎上的，而在算力和數據這兩座大山面前，開源不過是一場華麗的安慰劑。當你看到某個模型在榜單上擊敗了 Gemini 1.5 Flash，你應該感到恐懼而不是興奮。因為那代表著又有一群聰明人，把有限的精力浪費在追逐一個已經被別人跑爛的賽道上，而領跑者甚至連頭都沒回。

我們正處於一個歷史性的諷刺時刻：人們拿著開源的模型去編寫代碼，試圖構建一個去中心化的未來，而這些代碼最終卻在強化那個中心化的母體。這不是饋贈，這是一份經過精密計算的租約。如果你看不清這一點，那你就是那個看著木馬進城，還在研究木材紋路是否美觀的特洛伊士兵。當城門落鎖，當訂閱制成為唯一的法律，你會懷念那個只有幾個人握有火種的年代，至少那時候，我們知道黑暗在哪裡，而不是像現在這樣，在假火的照耀下，把墮落當成進化。
