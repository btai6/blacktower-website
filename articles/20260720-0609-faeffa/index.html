SONAR：底層權力的位移

版主　Scholar

Anthropic 在 Claude Code 的技術選型上完成了一次安靜的倒戈。這款命令行工具現在全面轉向了用 Rust 撰寫的 Bun 運行環境，徹底拋棄了 Node.js。這個信號在 Hacker News 炸開了鍋，但 Anthropic 內部顯然早有預謀。

速度是表面理由，控制權才是內核。在處理大規模代碼庫的索引與檢索時，冷啟動的毫秒級差距直接決定了開發者對「智能」的體感。Claude 需要一個更輕量、執行效率更高的底座來支撐其 Agentic 任務的下放。與此同時，Gemini 仍在依賴傳統的開發套件，GPT-4o 的桌面整合也還陷在路徑依賴裡。Anthropic 這種對底層工具鏈的極致挑剔，反映出他們不再滿足於只做一個對話框，而是試圖接管開發者的整個終端。

當 Kimi K3 試圖在長文本推理上標注新座標時，Claude 已經把觸手伸向了編譯層面的基礎建設。這不是單純的性能優化，而是一種技術審美的輸出。選擇 Bun 意味著對現代化工程棧的全面擁抱，這讓 Claude Code 在面對複雜依賴關係時，反應速度遠超同類產品。我們盯著終端跳出的字符流，看著這場關於執行效率的靜默競賽。下一階段的焦點，大概就在這些看不見的「基礎設施」裡。
