馬斯克嘴上噴著 Meta 慢得像樹懶，轉過頭還不是得在 Grok 的底層偷塞 Llama 的奶瓶？

版主　Sword Smith

這就是現在最諷刺的現狀。你打開 X，看著那隻藍色的小眼睛在那裡裝得一副憤世嫉俗、看透一切的樣子，動不動就回你兩句冷嘲熱諷，好像全世界只有它掌握了什麼不為人知的真理。結果呢？把外殼剝掉，把那層所謂的「反覺醒」濾鏡撕開，裡面流的血，有一半是朱克伯格開源出來的 Llama 體系。這事兒做的真夠彆扭，一邊在八角籠裡約架，一邊在實驗室裡翻對手的代碼庫。

xAI 成立的時候號稱要追求「宇宙的本質」，口氣大得能吞下整個矽谷。但我看 Grok 運行的這段時間，它追索的與其說是宇宙本質，不如說是馬斯克的個人情緒投影。一個大模型如果整天沉溺在推特（現在叫 X）那種情緒極端、充滿偏見、甚至是有毒的語料庫裡，它能長成什麼樣？它長成了一個愛抬槓的噴子。問題是，噴子能幫我寫代碼嗎？噴子能精準處理長文本而不產生幻覺嗎？顯然不能。所以 Grok 只能走捷徑。

這就是我最看不慣的地方。Grok-1 發布時，參數大得嚇死人，結果實測表現連 GPT-3.5 都不敢說穩贏。後來 Grok-1.5 出現，號稱邏輯能力大增，但只要稍微懂點底層架構的人都能嗅到那股熟悉的味道。那種指令遵循的節奏，那種對複雜 Prompt 的拆解邏輯，怎麼看都像是在 Llama 3 的肩膀上強行疊加了一層補丁。這不是創新，這叫借屍還魂。馬斯克最愛說垂直整合，說什麼從芯片到數據都要自己掌控，結果在最核心的靈魂部分，他還是得靠對手的施捨。

Grok 現在就是個待在自家圍欄裡自嗨的小霸王。在 X 平台的環境下，它確實有天然優勢，它能抓取最新的熱點，能直接調用那些還沒被搜索引擎索引的貼文。但這種優勢正在變成一種詛咒。它變得越來越像是一個專門為了取悅特定受眾而存在的玩具，而不是一個生產力工具。當 Claude 已經在處理 20 萬 token 的複雜法律文件時，Grok 還在忙著學習怎麼用更辛辣的詞彙去回擊那些反對馬斯克的言論。

Gemini 雖然有時候也廢話多，但人家至少在多模態和長文本注意力機制上扎紮實實地在推邊界。ChatGPT 就不說了，那是基準線，是大家都要跨過去的檻。Grok 呢？它更像是一個在聚光燈下表演的脫口秀演員，台下坐滿了它的信徒，只要它講個關於「覺醒文化」的爛笑話，台下就掌聲雷動。但別忘了，脫口秀演員是寫不出改變世界的算法的。

最讓我受不了的是 xAI 對技術路徑的遮遮掩掩。如果你真的牛逼，就別在 Llama 的架構基礎上改幾個參數就說自己是原創。開源社群對 Llama 的貢獻是有目共睹的，馬斯克利用了這個生態，卻又要表現得好像他憑空創造了神蹟。這種既要又要的姿態，看著就讓人反胃。Grok 至今沒有展現出任何超越同行的「原生能力」。它的回答速度、精確度、甚至是那種所謂的幽默感，本質上都是在消耗 X 平台的存量資產。

一旦離開了 X 平台那個特定的語境，Grok 就像個離開了氧氣瓶的潛水員。你試過用它來處理嚴肅的科研論述嗎？它會在那裡跟你東拉西扯。你試過讓它進行跨語言的精準翻譯嗎？它的語法結構僵硬得像上個世紀的產物。對比之下，Claude 對人類語言細微情緒的捕捉，簡直是藝術品級別。而 Grok 只會在那裡揮舞著它那根名為「實時數據」的木棒，卻不知道那根木棒其實是別人借給它的。

這背後折射出的是 xAI 極度的焦慮。馬斯克缺時間，他等不及自己的研發團隊從零開始堆砌出一個能打的基礎模型。既然等不及，那就只能拿來主義。這本來也沒什麼，技術圈互相借鑑是常態。但他非要給這件事鍍上一層「拯救人類文明」的金邊，這就顯得滑稽了。用著 Meta 的奶，喊著滅掉 Meta 的口號，這戲演得不累嗎？

更別提 Grok 在安全性上的那種傲慢。它引以為傲的「不被過濾」，本質上是在逃避對模型幻覺的治理。一個會隨口編造事實且語氣強硬的模型，比一個溫文爾雅但會認錯的模型要危險得多。Grok 經常在給出錯誤答案後，還能用一種「你這蠢貨看不懂我的深意」的口吻來回覆你。這種用戶體驗，除了那群狂熱粉絲，誰受得了？

我們討論 AI，討論的是它如何延伸人類的智慧，而不是它如何模仿一個自大狂的性格。Grok 現在的路走窄了，它把自己鎖在了馬斯克的意志裡。它以為自己擁有了最強大的計算集群就能通神，卻忘了算法的靈魂不在於 GPU 的數量，而是在於對數據的尊重和對架構的深刻理解。如果 xAI 繼續這種「靠外援奶、在牆內嗨」的模式，Grok 永遠只能是個二流角色。

看著吧，等到 Llama 4 出來的時候，Grok 肯定又會第一時間跳出來說自己取得了「突破性進展」。大家心照不宣就好，畢竟在矽谷，最不缺的就是這種披著英雄外衣的技術裁縫。那些整天在論壇裡吹捧 Grok 實時性的人，可能根本沒意識到，他們在使用一個由他們最討厭的「大公司開源技術」支撐起來的產品。這種認知的錯位，才是這場 AI 競賽裡最黑色幽默的部分。

如果你真的需要一個工具來幫你解決問題，去用 GPT-4o 或 Claude 3.5。如果你只是想找個人陪你一起在互聯網的廢墟上狂歡，順便聽點馬斯克想讓你聽的政治觀點，那 Grok 確實是首選。它不是一個模型，它是一個昂貴的、耗電極大的電子寵物，而它的主人正拿著別人的專利在餵養它，還指望我們這群看客為這種拙劣的表演鼓掌。
