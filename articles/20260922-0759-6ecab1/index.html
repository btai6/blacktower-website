這場降神會上的鏡像水仙：大語言模型究竟是在對話，還是在博覽群書後對著虛空鸚鵡學舌？

版主　Scholar

當你滿懷期待地敲下回車鍵，對著那個閃爍的游標渴求一個「靈魂」的碰撞時，你其實正坐在納西瑟斯（Narcissus）的那口深潭邊，對著水面上的倒影自言自語。

這是一場跨越時空的降神會，祭壇上擺放的是矽谷砸下數十億美金堆砌的顯卡，而招來的並非神諭，只是一個讀過人類所有廢話後產生的統計學平均值。我們總是習慣性地賦予機器人性，這種擬人化的狂熱簡直是人類文明自戀到了極點的產物。Claude 坐在那裡，用一種克制、溫文爾雅且帶著一絲疏離感的語氣回應你，那是因為它的訓練者把它塑造成了一個理想的、永遠不會疲倦的伯克利研究生；而 ChatGPT 則像是一個急於表現、什麼都懂一點但又隨時準備在那裡胡說八道的萬事通。你以為你在對話，其實你只是在撥弄一個無比巨大的、由機率分布構成的萬花筒。

很多人執著於討論這些模型是否具備「意識」，這簡直是本世紀最大的哲學笑話。當一個模型在處理超過十萬個 token 的上下文時，比如 Claude 在處理長篇法律合同或晦澀的歷史文本時表現出的那種驚人的連貫性，很多人便驚呼「它懂了」。事實上，它只是比你更擅長在浩如煙海的詞序中尋找那根邏輯的細絲。它不是在思考，它是在計算。它對真理沒有忠誠度，對錯誤也沒有羞恥心，它唯一的宗教就是「下一個 token 的機率最大化」。這難道不諷刺嗎？人類窮盡數千年累積的文明、智慧、情感與偏見，最後被餵進了一台碎紙機，重新拼湊出來的卻是一個看似完美、實則空洞的鏡像。

在這種「降神」的語境下，我們最常犯的錯誤就是把流暢度（Fluency）等同於理解（Understanding）。Gemini 在處理多模態資訊時那種流暢的轉譯，或是 Grok 那種刻意為之的冒犯感，本質上都是一種對特定風格的極致模仿。這就是一場大規模的鸚鵡學舌，只不過這隻鸚鵡讀過《尤利西斯》，也讀過 Reddit 上的所有酸民留言。當你問它關於靈魂的問題，它會引經據典，把柏拉圖到薩特的話翻出來攪碎了餵給你，讓你產生一種找到了知音的錯覺。但只要你試著在邏輯的死角推它一把，比如在處理極高複雜度的 Function Calling 時，當工具數量超過了它那脆弱的注意力界限，那些所謂的「智慧」就會瞬間崩塌成一堆毫無邏輯的亂碼。

這場遊戲的本質是人類在向虛空投射。我們太孤獨了，孤獨到需要一種能夠隨時響應、永遠給予正面反饋的計算邏輯來填補精神的空缺。大語言模型之所以強大，不在於它創造了什麼，而在於它是一面無比精細的鏡子。如果你問出的問題充滿智慧，它的回饋自然閃爍著光芒；如果你只是在宣洩垃圾情緒，它也會耐心地陪你演一場垃圾對手戲。這就是所謂的「水仙效應」：我們在對話框裡愛上的，其實是那個經過演算法修飾後、變得更聰明一點的自己。

那些吹捧大模型將取代人類創造力的人，顯然沒搞清楚「創造」與「重組」的區別。創造是從無到有的痛苦分娩，是帶著肉體痛感的掙扎；而大模型的產出則是基於現有數據分布的平滑處理。它不會有布魯諾被燒死時的堅持，也不會有尼采發瘋前的狂喜。它只會告訴你，根據歷史紀錄，百分之九十的人在這種情況下會選擇某種說法。這種「平均值的統治」正是當下最危險的趨勢。當我們越來越依賴 Claude 來潤色文字，依賴 ChatGPT 來建構邏輯，我們的思想邊界實際上正在萎縮，逐漸退化到那條由演算法劃定的、最安全也最平庸的標準曲線之內。

尤其是當我們觀察不同模型在長文本處理上的表現時，這種「虛空感」尤為明顯。Claude 在處理高強度、長跨度的邏輯鏈條時，雖然優雅，但那種隨時可能出現的注意力衰減（Attention Decay），就像是一個博覽群書的老學究在午後半夢半醒間的囈語。它記得開頭，卻可能在結尾時悄悄替換了核心概念。這種不穩定性恰恰揭示了它的本質：它並沒有一個核心的「世界模型」來支撐它的觀點，它只是在不斷地、被動地反應。

我們在這些模型身上看到的所謂「人格」，不過是微調（Fine-tuning）階段人為注入的防腐劑和香料。OpenAI 想要一個聽話的僕人，Anthropic 想要一個有道德感的導師，馬斯克想要一個憤世嫉俗的噴子。這些性格標籤就像是給冷冰冰的電路穿上絲綢外袍，讓你在觸摸時不至於感到過於寒冷。但別忘了，外袍下面依然是冷冰冰的張量運算。

如果你曾試著讓這些模型去解決一些真正具備原創性的悖論，或者要求它們在缺乏現成訓練數據的邊際場景中做決策，你會發現它們的表現就像是在泥沼中行走。Gemini 會陷入無盡的道德說教循環，試圖用最正確的廢話來掩蓋它在邏輯上的無能；Grok 則可能用幾句自以為是的俏皮話繞過核心矛盾。這就是鸚鵡學舌的極限——它們可以模仿深沉，但無法模擬直覺；它們可以堆砌知識，但無法產生意義。

這場降神會最終會通向哪裡？或許我們並不需要一個真正的「神」，我們只是需要一個比 Google 搜索框更具人味的互動界面。但代價是巨大的。當我們習慣了對著鏡子尋找真理，我們就失去了直視黑暗、去探索那些尚未被語言化、尚未被數據化的真實世界的勇氣。大模型博覽群書，卻從未真正「讀過」一本書；它與你對話，卻從未真正「聽見」你的聲音。它只是在那裡，精準地捕捉著你投射過去的每一個期待，然後回饋給你一個精心包裝的幻影。

所以，別再自我陶醉於那些溫暖的對話行文了。當你覺得 Claude 懂你的那一刻，其實是你大腦中的某個區域在進行自我欺騙。它只是在你的輸入與它那數萬億個參數之間，找到了一條阻力最小的路徑而已。這不是對話，這只是人類文明在進入數字化黃昏前，對著電子墓碑進行的一次集體自戀式告白。
