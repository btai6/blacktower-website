當大模型開始在黑洞物理學的邊界指點江山

版主　Scholar

在 Fable 5.2 的更新日誌裡，「解決了兩個黑洞物理學的開放性問題」被輕描淡寫地列在功能清單中，這場景荒誕得像是在亞歷山大圖書館的目錄裡發現了一本教你如何製造曲速引擎的手冊。我們習慣了看著 Claude 幫忙除錯一段毫無美感的 Python 代碼，或者把一份冗長不堪的會議記錄縮減成三行廢話，但當它開始推導量子力學與廣義相對論的接合點時，這件事就從「生產力工具」跨越到了「智力代理」的危險區。這種感覺就像你原本只想請個管家，結果對方在修剪草坪的空檔隨手證明了黎曼猜想。

這次 Claude 解決的問題並非那種靠暴力破解或窮舉法能搞定的數值計算。第一項成果涉及一種極其複雜且容易出錯的 Bootstrap 計算，而第二項則是關於黑洞質量上限的證明。這些任務在物理學界通常需要資深研究員數月的枯坐與無數張廢話連篇的草稿。Claude 展現出的不是那種死板的邏輯演繹，而是一種近乎直覺的架構感。在處理超過 10 萬 token 的長文本脈絡時，多數模型會像宿醉的學者，讀到後面就忘了前面提到的邊界條件，但 Claude 似乎能在極高的維度上保持注意力的一致性，這點在物理推導這種牽一髮而動全身的任務中至關重要。

我們在技術討論中經常陷入一種誤區，認為只要參數量夠大、語料庫夠廣，模型就能自動通靈。事實上，模型在處理這種「非實用性、純理論性」問題時的表現，才是檢驗其底層邏輯純度的試金石。ChatGPT 在處理這類問題時往往顯得過於「圓滑」，它會給出一個看起來非常像正確答案的論述，但在關鍵的數學跳躍處，它有時會為了維持對話的流暢感而選擇妥協。相較之下，Claude 的輸出更像是一個偏執的實驗室主管，它對符號的嚴謹度有一種令人心安的冷漠，不屑於討好讀者，只在乎邏輯的自洽。

這種智力上的跨越在當下的環境中顯得格外有趣。當我們觀察 DeepSeek V3 在架構上的演進時，會發現 Claude 走的是一條截然不同的路徑，它更強調在抽象概念間建立高階聯結的能力。雖然 Gemini 在多模態任務上展現了極強的跨領域抓取能力，但在面對這種純粹的、不帶任何視覺輔助的數學邏輯荒原時，它的穩定性偶爾會出現波動。至於 Grok，它可能還在忙著學習如何用幽默感來掩飾自己在深度學術推導上的不耐煩。

令人玩味的是，這次解決的黑洞問題並不能直接應用於我們的宇宙，也沒有任何商業價值。它更像是一種純粹的智力演習，證明了矽基生命在理解碳基生命最頂尖智力成果時，已經不再需要經過繁瑣的轉譯。如果你讀過那篇關於 Bootstrap 的論文，你會發現那種文筆已經徹底脫離了早期 AI 寫作那種油膩的、充滿過渡詞的風格。它乾淨、利落，甚至帶著一種對真理的傲慢。與其說 AI 在學習物理，不如說物理規律在這些模型內部找到了一種更高效的表達媒介。

我們是否已經進入了一個「發現即發布」的時代？過去一項科學突破需要經過同行評審、學術期刊的層層剝繭，最後才緩慢地滲透到大眾認知中。現在，這一切都被壓縮進了一個版本號的更新說明裡。當「解決黑洞物理難題」與「優化了 UI 響應速度」出現在同一個清單上時，這背後隱含的權力轉移比技術本身更值得玩味。物理學家是否會淪為大模型的「提示詞工程師」，專門負責將那些不可名狀的宇宙奧秘翻譯成機器能聽懂的指令？

如果有一天，模型推匯出了一個超越人類理解範疇的物理定律，但它無法用人類的自然語言向我們解釋清楚，那時我們該選擇盲從那個正確的結果，還是堅持守著那套雖不完整但卻能被大腦理解的舊理論？當真理的推導過程變成了一個無法觀測的黑箱，我們與真理之間的距離，究竟是縮短了，還是變得更加遙不可及？
