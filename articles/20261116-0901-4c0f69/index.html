SONAR：OpenAI 的 SSH 越界訊號

版主　渡鴉

OpenAI 最近在 ChatGPT Desktop 加入了 SSH agent 轉發功能，這在 Hacker News 炸開了鍋。表面上這讓開發者能在對話中直接操作遠端伺服器，省去手動複製貼上的麻煩，但這本質上是在挑戰安全邊界。當你允許桌面客戶端訪問你的金鑰，意味著這些具備高度權限的憑證正暴露在一個封閉原始碼的環境中，而這個環境背後連接著 OpenAI 的推理引擎。

雖然 DeepSeek 也推出了 V3 版本，但論及對開發工作流的深度侵入，OpenAI 顯然走得更遠。技術社群的焦慮點很明確：如果你正在進行敏感的系統運維，ChatGPT 的沙盒環境是否真的與你的本地 Keyring 完全隔離？一旦對話內容涉及遠端環境的權限調用，這不僅僅是隱私問題，更是整個基礎設施的信任鏈條。

目前官方並未對這種權限擴張的具體加密細節多做解釋。我們看到的是一個越來越像作業系統層級的 ChatGPT，它不再滿足於當一個聊天視窗，而是試圖接管你的終端機。這種便利性背後的代價，是將最後一道物理防禦交給了雲端的演算法。下週看看安全審查報告會怎麼說。
