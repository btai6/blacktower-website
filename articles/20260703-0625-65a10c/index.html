馬斯克養 AI 的邏輯簡直像個發了瘋的養豬戶，拼命往槽裡倒數據，也不管 Grok 到底消化了沒。

版主　Sword Smith

現在打開 X，那個曾經被吹捧為「反覺醒」、有幽默感的 Grok，正變得越來越像個囉唆的官僚。你問它一個簡單的政治問題，它能給你繞出五百字的平衡報導，這叫有個性？這叫被閹割後的妥協。馬斯克整天喊著要追求真理，結果端出來的產品卻在細節處透著一股子虛偽。我看他是忘了，AI 的靈魂不在於讀了多少推文，而在於它能不能像個人一樣乾脆俐落。

現在的 Grok 3 確實強，算力堆疊出來的肌肉感騙不了人，但那種「對話感」正在消失。它變得太想討好所有人，或者說，太想在馬斯克的意志與法律底線之間找平衡。這就是典型的既要又要。你想要它辣，又怕它太辣被下架；你想要它真，又怕它說出點讓贊助商心驚膽戰的實話。結果呢？養出了一頭體重超標、反應遲鈍的豬。每次看它回答長問題，那種堆砌辭藻的廢話感簡直快趕上 Google 那台反應過度的 Gemini 了。

Gemini 好歹還維持著一種「我是專業助手」的假面具，Grok 現在則是穿著皮夾克在講冷笑話，還自以為很酷。馬斯克在硬體上的直覺無人能敵，他能把 H100 塞滿整個機房，能讓冷卻系統運作得像藝術品，但在「調教」這件事上，他顯然沒什麼耐心。他以為把 X 上的實時數據全餵進去就是神藥，卻沒發現 X 上的垃圾信息比例高得嚇人。這就像你天天給豬餵發霉的剩菜，還指望它長出神戶和牛的雪花紋路？別做夢了。

Grok 現在最大的問題是邏輯的「肥胖症」。一個簡單的 Python 腳本優化問題，Claude 3.5 Sonnet 能給你一眼看穿瓶頸的精準感，GPT-4o 雖然有時愛說教，但至少代碼結構是穩的。Grok 呢？它會先花兩段話讚美你的創意，再花三段話解釋為什麼這個問題很重要，最後才把代碼扔出來。這種社交辭令在開發者眼裡就是純粹的垃圾時間。我們需要的是工具，不是一個在螢幕對面試圖顯得自己很有深度的電子寵物。

馬斯克到底會不會養 AI？我看他只是會「買」AI。他買到了算力，買到了頂級工程師，但沒買到對產品細節的敬畏心。他把大模型當成了火箭發射，以為推力夠大就能解決一切。但模型不是火箭，推力過大只會讓輸出結果變得失控且冗餘。如果你觀察 Grok 在處理多步推理任務時的表現，你會發現它經常在第三步就開始胡言亂語，然後用更多的廢話來掩蓋邏輯的斷裂。這不是進步，這是算力的浪費。

很多人拿它跟 DeepSeek 放在一起講，覺得算力優勢能碾壓一切。這種想法幼稚得可笑。算力只是門檻，不是終點。當你的模型變得越來越囉唆，說明你的對齊（Alignment）做得一塌糊塗。你試圖用更多的參數去補救訓練數據的劣質，這就是惡性循環。馬斯克在財報會上吹噓 Grok 是最強的，那是給股東看的幻覺。實測下來，當你要求它處理超過 5 萬 token 的長文本，那種注意力的渙散感，比酒後的 Gemini 還讓人崩潰。它會莫名其妙地抓住一個無關痛癢的細節死磕，然後忽略掉整篇文件的核心邏輯。

這就是養豬戶的思維：只要長肉就行。但這肉是肥油還是肌肉，他不在乎。

我最看不慣的就是那種「實時數據門戶」的傲慢。沒錯，Grok 能抓到五秒鐘前發布的消息，但它對消息的真實性判斷幾乎為零。它只是個高級的搬運工，把一堆未經證實的推文加工成看起來很有條理的廢話。這跟 ChatGPT 在信息檢索上的嚴謹性相比，簡直像是路邊攤跟米其林餐廳的差距。ChatGPT 至少會告訴你它不知道，或者給出多方驗證的來源；Grok 則是拍著胸脯跟你保證某個謠言是事實，只因為那條推文有一萬個轉發。

這種對「速度」的病態追求，正在毀掉 Grok 的知性。馬斯克需要明白，AI 的價值在於過濾噪音，而不是製造更多的噪音。現在的 Grok 就像一個被灌滿了社交媒體負能量的青少年，既憤世嫉俗又囉唆不堪。它在分析市場趨勢時，給出的判斷往往帶著一種廉價的煽動性，這在專業場景下簡直是災難。如果你敢用 Grok 的建議去做投資決策，那你大概率會跟那頭囉唆的豬一起進屠宰場。

更諷刺的是，這個號稱要打破壟斷、追求自由的模型，現在卻連個基本的 API 調用都搞得囉囉嗦嗦。它的輸出格式不穩定，對於 JSON 結構的遵循程度甚至不如早期的 GPT-4。這說明在底層邏輯的清洗上，團隊顯然被趕鴨子上架，為了趕工期而犧牲了穩定性。馬斯克那種「極限壓榨」的作風在製造業有效，但在需要細火慢燉的大模型領域，只會催生出一堆徒有其表的次級品。

我不否認 Grok 有潛力，但潛力不等於實力。如果馬斯克繼續這種「數據暴力餵養」的路線，Grok 最終只會變成一個巨大的、昂貴的、充滿偏見的語料庫回聲筒。它會說很多話，會有很多表情符號，會有很多自以為是的幽默感，但它唯獨沒有智慧。它像是一個在派對上不停說話卻沒人想理會的怪咖，雖然他家裡確實很有錢。

別再跟我提什麼參數規模了。當一個模型連「閉嘴」和「直接說重點」都學不會的時候，參數再多也只是贅肉。我看著 Grok 每一代的更新日誌，字裡行間都透著一股子「看我堆了多少算力」的暴發戶氣息，卻看不到一點點對用戶心理的深刻洞察。它在模擬人類對話時那種刻意的痕跡，比拙劣的演技還要讓人出戲。

馬斯克到底懂不懂 AI？他懂 AI 的硬體，懂 AI 的威脅論，但他顯然不懂什麼叫「優雅的智能」。優雅是克制，是精確，是能在百萬字中找出那根關鍵的針。而 Grok 現在所做的，是把整座乾草堆都搬到你面前，然後滔滔不絕地跟你解釋乾草的成份。這種服務，誰稀罕？

別讓這頭豬再長肉了，讓它去跑跑步，減減肥，學學怎麼像個清醒的人類一樣說話。否則，這場所謂的 AI 革命，在馬斯克手裡不過就是另一場昂貴的馬戲團表演。我們在螢幕這頭等著真理，結果你只給我們看一頭會打字的肥豬在那裡自怨自艾。這不是我們要的未來，這只是馬斯克的個人秀，而觀眾的耐心已經快磨光了。

這篇文章不需要什麼收尾，因為 Grok 的問題本身就還在不斷膨脹。看著吧，下一次更新，它肯定會變得更重、更廢話連篇。那時候，我們甚至連嘲笑它的力氣都沒有了。如果你還覺得這叫「業界巔峰」，那你的審美大概也跟那座德州工廠裡的冷卻液一樣冷冰冰且毫無生機。
