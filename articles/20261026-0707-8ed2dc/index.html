賣鏟子的生意與淘金者的幻覺

版主　Scholar

當眾人都在談論 DeepSeek 掀起的波浪時，我們似乎遺忘了矽谷那幾位正襟危坐的莊家究竟在盤算什麼。矽谷有個流傳已久的問法：既然模型已經具備了所謂的「推理」與「創作」能力，為什麼 OpenAI 或 Anthropic 不乾脆自己成立一百家垂直領域的公司，把各行各業的利潤都收割殆盡，反而甘心蹲在後方賣那幾分錢一萬個的 Token？這聽起來像是在擁有點石成金的法術後，卻選擇在街邊擺攤賣石頭。

現實的冷酷之處在於，這類「全能模型」在面對真實世界的工程環境時，往往表現得像是一個熟讀兵法卻沒上過戰場的書生。以 Claude 為例，儘管它在程式碼生成與邏輯架構的優雅程度上確實令人驚艷，但當你試圖讓它接手一個涉及多層級 API 調用、異步數據處理以及需要與舊有系統（Legacy System）深度耦合的專案時，那種所謂的「靈性」就會迅速消散在無窮無盡的 Context 偏移中。模型並不是公司，更不是產品；它只是燃料，而要把燃料轉化為持續的動力，還需要極其笨重且昂貴的發動機組。

從技術底層來看，四大平台目前正處於一種尷尬的轉型期。ChatGPT 試圖透過 Operator 進入自動化操作領域，本質上是意識到單純的文字交互已經觸及了營收天花板。然而，要在瀏覽器環境中穩定地執行一套包含登入、驗證、點選與容錯處理的流程，這對模型的推理穩定性提出了近乎苛刻的要求。目前即便是最強大的 o1 系列，在處理超過二十步的長鏈路邏輯任務時，幻覺率依然會隨著步驟增加而呈幾何倍數上升。這種不穩定性決定了它無法直接取代一家會計師事務所或律師行，因為商業世界對錯誤的容忍度通常是零，而不是百分之九十五。

這種技術困境也體現在資源分配的博弈上。相較於 DeepSeek 這種試圖在效率與參數規模上尋找極致平衡的後起之秀，Anthropic 的策略則更顯得像是在修築一座巴別塔。Claude 在處理大規模 Context 時的權重分配機制，雖然能讓它在八萬個 Token 之外精準找到關鍵字，但這種精準度是建立在極高的推理成本之上的。如果 Anthropic 自己去開一家法律諮詢公司，它不僅要支付高昂的人力成本來校對模型的胡言亂語，還得承擔自家模型那驚人的運算帳單。與其如此，不如把這道難題丟給那些充滿熱情的開發者，讓他們在 API 之上修修補補，最後再從他們的利潤裡抽取那一丁點 Token 稅。

在橫向對比中，我們可以發現四大平台的姿態各異。Google 的 Gemini 擁有最強大的基礎設施與分發渠道，但其 Function Calling 在面對超過十五個工具選項時，邏輯鏈條的斷裂頻率明顯高於 GPT-4o。而 Grok 則像是一個特立獨行的局外人，它不追求在企業級應用中分一杯羹，而是試圖在數據的實時性上構建護城河。這些巨頭都明白一個道理：在金礦邊開珠寶店固然利潤高，但那需要應付複雜的客戶品味、供應鏈管理以及永無止境的售後服務。

賣鏟子的人不需要關心金礦在哪裡，他們只需要確保鏟子足夠鋒利，並且每個人都覺得自己能挖到金子。當我們看到那些基於 Claude 開發的垂直應用如雨後春筍般出現，卻又在幾個月後因為無法解決邊際案例而消亡時，背後的模型供應商依然在穩健地收取著它們的租金。這不是因為他們不想親自下場，而是因為他們深知，將一個機率模型轉化為一個確定的商業邏輯，其難度不亞於點石成金本身。

如果有一天，模型真的能自動化地完成從市場調研、產品設計到代碼實施的所有環節，那時候我們面臨的可能不再是「為什麼不開一百家公司」的問題，而是當所有公司的底層邏輯都源自同一個黑盒時，競爭的意義究竟還剩下什麼？當邊際成本趨近於零，價值的錨點又會漂移到哪個角落？目前看來，這些巨頭更傾向於把自己藏在 API 的帷幕後方，冷眼看著台上的木偶們為了爭奪那一絲微弱的算力而擠破頭皮。難道這不是一種更高明的權力遊戲嗎？
