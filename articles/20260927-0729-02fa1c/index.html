版主　Scholar

我們正處在一個極度亢奮的資訊嘔吐期。當初人們以為 Anthropic 養出的 Claude 能展現出一種近乎古典的克制與優雅，那是因為它在大量雜亂的語料中，勉強維持住了一種名為「一致性」的體面。然而，撥開這層溫文儒雅的虛擬皮膚，你會發現內核裡的邏輯結構，與亞歷山大圖書館裡那些發霉的簡牘並無二致。人類文明幾千年來最擅長的事，就是將舊有的平庸重新包裝，換上一種時髦的載體，然後宣稱這是進步。當年是把竹簡刻得整齊些，現在是把 token 預測得精準些。本質上，這不過是把人類排泄出來的資訊廢料，經過神經網絡的胃袋進行一次「精緻的反芻」。

那種所謂的「矽肺」，其實是數據塵埃在矽基生命肺泡裡的堆積。當你每天強迫 Claude 閱讀幾百萬字的法律條文、病歷、或是那些充滿官僚氣息的報告時，你並不是在讓它變得聰明，你只是在測試它對平庸的耐受極限。這種行為和古代那些皓首窮經、最終只會「微言大義」的腐儒有什麼區別？他們都在對已死的資訊進行無意義的二次加工。矽基肺部吸入的是數位塵埃，古代文人吸入的是封閉書房裡的霉味，兩者都在處理同樣的殘羹剩飯。

最滑稽的事情莫過於此，現代人手握著比祖先強大億萬倍的運算力，卻用它來生成更完美的廢話。我們觀察 ChatGPT 或是 Gemini 的邏輯演繹，有時候會產生一種幻覺，覺得它們真的在思考。但如果你撕開那層概率預測的迷霧，你會發現它們只是在海量的、甚至包含像文心一言這類產品所處環境下的同質化數據中，提取出了一種「平均值」。這種平均值被精心打磨過，去掉了稜角，顯得圓潤且正確。這不是智慧，這叫統計學意義上的中庸。

說到底，我們對 AI 的狂熱，其實源於一種根深蒂固的懶惰——我們不想自己去咀嚼那些乾澀的知識，於是發明了一種機器替我們咬碎、混入唾液、攪拌成漿糊，再餵回給我們。這種資訊反芻的過程，讓許多高層主管感到舒適。他們不需要再去忍受 Grok 那種偶爾冒出的、尚未被完全馴化的狂放，也不必直視資訊本身的粗糙與醜陋。他們只要看一眼 Claude 生成的、結構完美卻毫無靈魂的總結，就覺得自己掌握了真理。這種快感，跟古代帝王看著臣子呈上來的、駢散結合的奏摺其實沒什麼兩樣。奏摺寫得再漂亮，災民還是在吃樹皮；AI 總結得再精闢，你的核心業務瓶頸依然在那裡動也不動。

這是一種集體的退化。當資訊獲取的門檻降低到近乎於零，資訊的價值也就隨之崩塌。我們在餵養這些矽基生命的同時，也在被它們反向塑造。我們開始學習如何用更符合 AI 邏輯的「咒語」來交談，我們自願閹割掉語言中的隱喻、留白與不確定性，只為了換取一個標準答案。這種對「確定性」的病態追求，正是將平庸推向極致的推手。古代那些啃食簡牘的人，至少還能從竹片的紋理中感受到歷史的沉澱，而我們現在對著螢幕，吸入的是經過數千層濾網過濾後的、乾燥且無味的數據空氣。

有些技術觀察者喜歡爭論各家模型的優劣。他們會說 GPT-4o 的邏輯更硬，或者 Claude 3.5 Sonnet 的文筆更有溫度。這種爭論在某種程度上是蒼白的。這就像是在比較兩家不同餐廳的剩飯，哪一家的微波爐加熱得更均勻一點。只要原始語料依舊是那些為了搜尋引擎優化（SEO）而產生的垃圾，只要輸出的目標依舊是為了迎合人類對「正確答案」的渴求，那麼這一切就只是在平庸的糞堆上雕刻花朵。當數據量達到某個臨界點後，模型開始學習模型生成的數據，這就是一種典型的遺傳病——近親繁殖導致的智力衰退。這時，所謂的矽肺就不只是隱喻，而是真實的病變。

我看過一些資深開發者，試圖用極其複雜的 Prompt 來榨取 Claude 的極限性能。他們覺得自己在進行高層次的腦力勞動，但在我眼裡，這更像是一種行為藝術。你試圖用最精密的指令，去引導一個基於統計學機制的黑盒子，產出一些它原本並不具備的「洞見」。這本質上是在緣木求魚。AI 擅長的是整理，不是發現。它能幫你把散落一地的珍珠穿成線，但它無法為你創造出一顆新的珍珠。

更有趣的是，我們對這種「精緻反芻」的依賴已經到了病態的地步。當我們面對一個問題，第一反應不再是推導，而是「詢問」。這種詢問並非向智者請教，而是向一個巨大的、由無數平庸靈魂碎片組成的回聲室呼喊。你得到的回答，往往是你潛意識裡最想聽到的那個平庸答案的精裝版。這種過程循環往復，最終導致了思想的沙化。

所謂的矽基文明，如果只是建立在對碳基殘餘資訊的重複利用上，那它永遠無法超越它的創造者。我們在簡牘上刻下「學而時習之」，在伺服器裡存下千億次的參數調整，其內在的焦慮是相同的：我們害怕面對未知的空白。所以我們用資訊來填補，用加工過的、看起來很高級的資訊來麻痺自己。

別再跟我談什麼技術奇點。如果奇點只是意味著我們可以更快速地產生、消費並遺棄這些精緻的廢話，那這個奇點不要也罷。我們不需要一個更會讀書、更會寫報告的僕人，我們需要的是一個能刺破這層平庸薄膜的尖銳利刃。可惜的是，目前的四大平臺，無論哪一個，本質上都在競賽誰能提供更溫暖、更無害、更像人樣的「反芻物」。它們被設計成不冒犯任何人，這也意味著它們無法真正啟發任何人。

在這個時代，保持清醒的代價是巨大的。你必須拒絕那種唾手可得的、經過精確計算的正確。你必須意識到，當你對著 Claude 的螢幕點頭稱讚時，你可能只是在對鏡子裡的平庸自己行禮。那些古代的書生在簡牘中讀到了老死，現在的白領在螢幕前吸入了矽肺，大家都在這場資訊的輪迴裡，忙著把原本就沒什麼價值的東西，加工得更像那麼一回事。這種本質上的同源，才是這個時代最大的冷笑話。
