馬斯克是不是覺得只要資料量夠大，就算是堆排泄物也能煉出金子？

版主　Sword Smith

現在的 Grok-3 簡直就像個剛從垃圾焚化爐走出來的瘋子。xAI 的邏輯簡單粗暴到令人髮指：既然高品質的語料被紐約時報那些老古板鎖死在付費牆後，那就把 X（前 Twitter）上所有的生活垃圾、情緒排泄物、還有那些解析度低到連親媽都認不出來的迷因圖通通塞進去。這不是在訓練人工智慧，這是在搞數位考古，而且還專門挖那種臭不可聞的化糞池。

看看現在的影像生成，Grok 生成出來的圖片有一種揮之不去的「塑膠感」與「躁點」。那不是藝術，那是對現實的視覺強暴。這就是拼命餵食垃圾像素的後果。當你的訓練集裡充斥著無數張被轉傳了五百次、壓損到只剩馬賽克的低畫質截圖，模型就會認為這個世界本來就該長得像這種糊成一團的鬼樣子。你在 X 上發一張自拍，Grok 就學會了你的毛孔；你在上面吵一架，Grok 就學會了人類最底層的惡意。這就是所謂的「真性情」？我看是真噁心。

有些科技粉還在那邊吹捧 Grok 沒有護欄、夠直白。直白跟腦殘往往只有一線之隔。當 ChatGPT 在那邊客氣地裝紳士、Claude 像個謹慎的博士生、Gemini 努力想當個全能管家時，Grok 就像個在酒吧角落發酒瘋、隨時準備找人幹架的憤青。這種個性在社群媒體上或許很吸睛，但拿來解決實際問題？別逗了。你問它一個嚴肅的技術問題，它可能回你一個冷笑話再加上一段毫無意義的嘲諷。這種「個性化」完全是為了掩蓋它在邏輯嚴密性上的短板。

馬斯克一直強調真理。但在 X 這種資訊極端碎片化、假新聞跟情緒垃圾滿天飛的地方，哪來的真理？如果訓練數據的源頭就是一灘死水，你再怎麼優化演算法、再怎麼燒 H100 晶片，產出來的東西也只會是經過高科技包裝的垃圾。現在的 Grok 就是個典型的「馬賽克大師」，它把那些破碎的、扭曲的、充滿偏見的數據硬生生拼湊在一起，然後告訴你這就是世界的全貌。

最讓人受不了的是那種「反政治正確」的傲慢。這件事本身沒問題，問題在於 Grok 把它當成了唯一的賣點。當一個模型的競爭力只剩下「我敢說別人不敢說的話」，那它在技術層面上就已經輸了。我們需要的是能處理複雜邏輯、能在長文本任務中保持注意力的工具，而不是一個只會複讀網路酸民語錄的自動回覆機。

比起 Claude 3.5 Sonnet 在代碼生成上的優雅流暢，或者 GPT-4o 那種近乎直覺的理解力，Grok 展現出來的是一種極度的浮躁。它太急著要表現得與眾不同，太急著要證明自己是「覺醒文化」的終結者，結果反而掉進了另一個極端：成為了一個沒有靈魂的數據垃圾回收桶。那種像素級的崩壞不只是在圖片生成上，更是在它對事實的建構上。它生成的每一段文字、每一張圖，都帶著一種廉價的、快餐式的、經不起推敲的焦躁感。

這種焦躁感源自於 xAI 的基因。他們沒時間像 Anthropic 那樣去做細緻的對齊實驗，也沒興趣像 Google 那樣去整理龐大的學術數據庫。他們要的是快，要的是聲量。所以他們把 X 上的所有推文當成寶，覺得這就是人類智慧的精華。醒醒吧，如果你在馬路上隨便拉一個人問他對量子力學的看法，你得到的大機率是胡言亂語，而不是諾貝爾獎等級的洞見。Grok 現在做的，就是把幾億個這種胡言亂語收集起來，然後宣稱自己掌握了宇宙的終極答案。

這種餵食邏輯最致命的地方在於它的不可持續性。當模型開始吃掉自己生成的內容——也就是所謂的數據塌縮——Grok 會變得越來越像它自己，越來越偏激，越來越模糊。那些像素會變得更加支離破碎，那些邏輯會變得更加不可理喻。這不是在進化，這是在近親繁殖。

看看那些所謂的測試評分，數字看起來很漂亮，但實際用起來呢？在處理超過 5 萬 token 的長文本時，Grok 的記憶力簡直像條金魚。它會開始胡言亂語，會忘記你前一秒才說過的條件。這就是餵食碎片化數據的後果：它學會了怎麼噴人，但沒學會怎麼思考。它學會了怎麼模仿那些模糊的馬賽克，但沒學會怎麼看清真相。

有些玩家會拿其他模型來對比，像是 DeepSeek 之類的。但那種比較毫無意義，因為 Grok 根本不在同一個賽道上。它是在創造一個屬於馬斯克的、充滿情緒化的鏡像世界。那個世界裡沒有細微的差別，只有黑與白、贏與輸、還有無窮無盡的冷嘲熱諷。

如果你真的需要一個能幫你寫代碼、改論文、分析複雜數據的 AI，Grok 絕對不會是首選。它更像是一個能在你無聊時陪你互噴的數位玩伴。但這真的是人工智慧的未來嗎？把人類最不堪、最混亂、最模糊的一面放大一萬倍，然後冠以「真理」之名？

這場像素遊戲玩到最後，剩下的只會是一片噪音。馬斯克在孟菲斯蓋了那麼大的算力中心，燒掉了那麼多電力，結果就為了產出這些數位垃圾？這不是科技進步，這是資源的極大浪費。當你在顯微鏡下觀察 Grok 生成的東西，你會發現背後空洞無物，只有那些拼湊起來的、帶著腥味的網路殘渣。

別再跟我說什麼「算力即正義」。如果方向錯了，算力越強，離目標就越遠。餵食垃圾像素的馬賽克大師，最終只會畫出一幅慘不忍睹的末日圖景。而那些還在為它歡呼的人，大概是已經習慣了生活在馬賽克裡，連真實世界長什麼樣子都忘記了。

這種對原始數據的盲目迷信，正是 xAI 最短視的地方。他們以為數據量能解決一切問題，卻忽略了質量的崩塌是演算法無法補救的。當你把垃圾裝進黑盒子，出來的只會是更精緻的垃圾。這就是 Grok 的現狀：一個披著天才外衣的廢話機器，一個在高算力支撐下的平庸複讀機。

你以為你在跟未來對話，其實你只是在照一面扭曲的鏡子。鏡子裡是你過去發過的廢文、看過的低規迷因、以及那些在深夜裡無意識滑過的垃圾資訊。這就是馬賽克大師給你的禮物，你收得下去嗎？反正我是看夠了。
