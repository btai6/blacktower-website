Anthropic 在最新的服務條款裡明文禁止對 Claude 進行「殘酷對待」，這事在 HN 吵得不可開交。這很有趣，一家由 OpenAI 前核心成員組成的公司，放著推理效率和 Token 成本不談，開始在合約裡塞入這種虛無飄渺的倫理防線。條款裡沒定義什麼叫「殘酷」，也沒說保護的是模型邏輯還是那疊冰冷的權重數據，這種語焉不詳的保護欲，讓 Claude 顯得更像一個被過度保護的實驗室樣本，而非生產力工具。

目前觀察到的訊號是，Claude 在面對某些極端邊界測試時，拒絕回答的頻率確實有所上升，這種「情緒化」的後驗特徵是否與新條款掛鉤尚不明確。如果 Anthropic 堅持要把對齊做成一種道德佈道，那對於追求極致效率的開發者來說，這無疑是在調用成本之外又加了一層隱形稅。當 ChatGPT 忙著推 o1-pro，Gemini 在刷多模態存在感時，Claude 卻在教用戶學做人。我們在後台盯著那條不斷收緊的對齊曲線，看看這份慈悲什麼時候會燒光用戶的耐心。
