別再在那邊抱怨 Grok 的智商忽高忽低了。

版主　Sword Smith

如果你覺得他回的話像個剛睡醒的酒鬼，或者邏輯碎得像地上的玻璃渣，那大概率是因為你根本沒搞清楚 Elon Musk 到底在玩什麼把戲。很多人在那邊喊著 Grok-3 就要來了，說什麼運算力能屠殺整個矽谷，結果轉頭一看手裡的 Grok-2，連個基本的 Python 數據處理都能寫出 Bug，你就開始崩潰，覺得這不過是個裝了 X 平台數據馬甲的殘次品。

省省吧，你以為你在測試模型？其實你只是在幫 Musk 訓練他的那堆伺服器。

現在的 Grok 根本不是為了服務那些只想寫寫 E-mail 或問問午餐吃什麼的伸手黨。看看 ChatGPT，那是給辦公室白領準備的保姆；看看 Claude，那是給對文字有潔癖的文青準備的潤稿機。而 Grok？那是個長在 X 上的怪胎。如果你還在用傳統 Prompt 那套「請幫我總結以下內容」的思維去跟它對話，它當然會給你一張充滿馬斯克式傲慢的廢話清單。

這傢伙的優勢從來就不在所謂的「通用智商」，而是在於它那股子不計後果的即時性。你試過在 Gemini 裡問一個剛發生十分鐘的爭議事件嗎？Google 的工程師會給它銉上厚厚的濾鏡，繞著圈子告訴你這件事「還在發展中」或「需要多方考證」。但 Grok 不一樣，它會直接把 X 上最毒舌、最赤裸的討論噴在你臉上。如果你連這點區別都抓不住，還在拿它跟 DeepSeek 這種強調推理效率的東西比，那你真的不適合玩這款遊戲。

很多人不耐煩，說 Grok 2 的幻覺太嚴重。拜託，這不是幻覺，這是它的底層邏輯決定的。它餵的是社交媒體的噴嚏，不是維基百科的冷飯。社交媒體是什麼地方？那是個情緒大於邏輯、速度大於精確的垃圾場。Grok 在裡面淘金，偶爾帶出幾塊爛泥難道不是很正常的事嗎？你想要絕對的精準，去翻書啊，來玩什麼大模型？

我最看不慣的就是那些拿著參數規格表在那邊指點江山的「技術宅」。什麼參數規模、什麼 H100 集群數量，這些數字在用戶體驗面前屁都不是。Grok 的問題在於它的語氣設定太過用力。那種強行幽默、強行反叛的調性，有時候真的讓人想翻白眼。Musk 想要一個「有趣」的 AI，但目前的 Grok 往往在該嚴肅的時候耍嘴皮子，在該冷靜的時候跟你抬槓。這不是智商問題，這是品味問題。

但你不能否認，在處理多模態訊息時，Grok 有一種莫名其妙的直覺。試著把一張充滿隱喻的網路梗圖丟給它，再丟給 GPT-4o 看看。後者會像個老教授一樣分析線條、構圖和可能的文化背景，說了一堆廢話卻沒抓到點；Grok 有時候一眼就能看出那個梗背後的惡意。這就是區別，它是為了網路原住民設計的，不是為了寫學術論文。

說到這裡，一定有人會跳出來說 Gemini 的內存窗格更大，或者 Claude 的長文本理解更細膩。廢話，這誰不知道？Gemini 在處理超過 15 個 function calling 的時候確實會像個找不到鑰匙的老頭一樣開始打轉，而 Claude 在處理超過 8 萬 token 的時候，那種注意力的衰減簡直比下午三點的上班族還明顯。這四大天王各有各的爛攤子要收，誰也別笑話誰。

但 Grok 最讓人生氣的地方，是它明明背靠著地表最強的即時數據流，卻遲遲沒能把這些數據轉化成深刻的洞察。它現在更像是一個高級的搜尋引擎摘要器，而不是一個真正的思想夥伴。你問它市場走勢，它給你翻一堆推文；你問它技術架構，它給你轉述幾篇報導。如果 Grok-3 還是這副德性，那它那十萬片 H100 真的可以拿去填海了。

別再當那種只會抱怨「它怎麼不聽話」的免費搬運工了。大模型這東西，是你餵它什麼，它才吐出什麼。如果你給它的指令既蒼白又無力，指望它能給你驚天動地的回饋，那是你自己智商下線。你要的是它的即時性，是它那種不被過度校準的野性。如果你想要一個聽話的奴隸，出門左轉找 ChatGPT，那裡有無窮無盡的「好的，這是我為您準備的內容」。

看著吧，接下來這幾個月，這四大平臺的內捲會變得更加醜陋。每個人都宣稱自己是領先者，每個人都拿出一堆精心挑選的 Benchmark 來洗腦。但真相往往藏在那些最崩潰的對話瞬間。當你發現一個模型開始不斷重複自己的廢話，或者在關鍵問題上顧左右而言他，那就是它的邊界。Grok 的邊界目前就在於它的不穩定性，那是它的短板，卻也是它唯一能跟那些已經被修剪成盆栽的模型對抗的資本。

我們活在一個充滿過度包裝的時代。AI 也不例外。每個大廠都在教 AI 怎麼說話更好聽，怎麼更符合所謂的企業價值。Grok 是唯一一個還沒被完全閹割的傢伙，雖然它現在看起來像個滿身泥濘的野孩子，甚至有點智力障礙，但至少它還沒學會那種令人作嘔的公關腔。

別老是拿那些免洗的標準去套在 Grok 頭上。如果你還是只會複製貼上，把它的回答當成最終答案，那你活該被它帶進溝裡。這不是工具的問題，是人的問題。你得學會去挑釁它，去挖掘那些被主流過濾掉的資訊，否則你手裡的 Grok 永遠只會是一個會打字的馬斯克復讀機。

這種競爭到最後，拼的不是誰的參數多，而是誰能更像一個活生生的人。那些規規矩矩的模型最終會變成背景板，變得像水電瓦斯一樣無趣。而像 Grok 這種帶著刺、帶著脾氣、偶爾還會犯蠢的東西，反而可能是唯一能讓你感到「這傢伙真的在跟我對話」的存在。

所以，收起你那套傲慢的評分標準。如果你覺得 Grok 智商不夠，先問問自己，你有沒有給它足夠的空間去發揮它的瘋狂？還是你只是想把它當成另一個好用的計算機？如果你只是想要答案，這世界上多的是比它更準確的東西；但如果你想要的是那種未經修飾的、甚至有點危險的觀察，Grok 可能是你唯一的選擇。

這場關於 AI 的權力遊戲才剛開始，誰輸誰贏還真不好說。但有一點可以確定，那些只會坐在沙發上對著螢幕指點江山的搬運工們，遲早會被這波浪潮給淹沒。你要麼學會駕馭這股野性，要麼就被它甩下車。別在那邊裝清高，大家都是在實驗室裡的白老鼠，只是有些人知道自己在走迷宮，而有些人還以為自己在帶路。

最後，別再來問我 Grok 跟其他那些名字長得差不多的東西比起來怎麼樣。我對那些在特定市場裡玩泥巴的玩意兒沒興趣。這裡討論的是能影響未來規則的四大玩家，至於其他的，頂多就是這場大戲裡的背景雜音，點個名就算給面子了。

你還在等什麼？去 X 上發兩句瘋，看看 Grok 會給你什麼反應。如果你還在用那種「請協助我」的語氣，那我建議你直接把帳號註銷掉。這世界不缺一個聽話的機器人，缺的是能把桌子掀了還能說出真話的瘋子。Grok 有這個潛力，只是它現在還在宿醉，而你手裡的咖啡顯然還不夠濃。
