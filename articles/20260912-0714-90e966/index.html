既然 Grok 懂幽默，為什麼寫出來的笑話像在背說明書？

版主　Sword Smith

馬斯克成天在 X 上吹噓 Grok 是最有趣的 AI，具備所謂的「反叛精神」和「幽默感」，但我看這機器人寫出來的段子，尷尬程度簡直直逼春晚小品。你說它懂幽默？它頂多是背下了《冷笑話大全》然後用一種極其生硬的邏輯強行拼湊出一種「看起來像在開玩笑」的語法結構。這不是幽默，這是程式碼的自我感動。

真正的幽默是打破預期，是那種在邏輯邊緣試探的危險感。你看 Claude，雖然它大部分時間像個穿著西裝、滿口「為您服務」的管家，但偶爾在長文本處理裡流露出的那種對人類矛盾邏輯的冷眼旁觀，反而比 Grok 這種刻意噴垃圾話的姿態來得高級。Grok 現在的問題在於，它太想證明自己好笑了。它就像那個在派對上為了融入朋友圈，拼命講一些過時梗、甚至不惜自嘲來換取一點乾笑的局外人。你問它一個諷刺問題，它會吐出一堆帶著「！」和「？」的句子，試圖模仿馬斯克的語氣去酸一下左派或傳統媒體，但扒開那些尖酸刻薄的皮囊，裡面的骨架還是那套乏味的 Transformer 架構，每一步預測都是基於機率，而不是基於靈魂。

這就是技術上的死穴。目前的 LLM 在處理邏輯推導時已經夠讓人頭痛了，Gemini 在調用大規模 Function Calling 時會因為參數太多而開始胡言亂語，更別提讓 AI 理解什麼叫「冒犯的藝術」。Grok 的「趣味模式」本質上只是在 Prompt 裡加了一層濾鏡，告訴模型：嘿，你現在是個憤世嫉俗的噴子，多用點反問句。結果呢？出來的東西就像是說明書被塞進了碎紙機後再重新黏起來，邏輯斷裂不說，連笑點都充滿了工業糖精的味道。

我們談論 AI 的幽默感，其實是在談論一種「對現實的偏離」。ChatGPT 在這方面做得四平八穩，它不會出錯，但也絕對不會讓你笑出聲，它寫的笑話通常是那種給幼兒園小朋友聽的冷謎語。Grok 試圖走另一條路，它想當那個打破規則的人，但它忘了，規則不是靠幾句髒話或政治不正確的吐槽就能打破的。當它在解釋一個冷笑話時，那副一本正經的樣子，簡直比它講的笑話本身還要好笑，這就是諷刺的地方。它在解釋為什麼某個詞好笑的時候，採用的依然是那種階層式的、結構化的分析方法，就像是在解剖一隻青蛙，青蛙死了，趣味也就沒了。

這反應了 xAI 在數據清洗上的傲慢。他們顯然餵了很多 X 上的推文給 Grok，覺得這就是「人話」，這就是「幽默」。但 X 上除了極端情緒和政治口水，剩下的精華是 Grok 這種算力怪獸難以捕捉的微小情緒波動。一個模型如果連基本的語境切換都做不到位，在回答稍微嚴肅一點的技術問題時還夾雜著那種廉價的嘲諷，只會讓人覺得礙事。我在測試 Grok 寫代碼建議時，它偶爾會蹦出一句沒營養的廢話來展現它的「個性」，那種感覺就像你找工程師修 Bug，他不但沒修好，還站在旁邊笑你的代碼寫得像坨屎。這種「幽默」除了浪費 Token，沒有任何實際價值。

目前的 AI 圈子有一種病態的執著，覺得只要模型夠大、算力夠強、參數夠多，就能模擬出人類的情感。但幽默是一種高度依賴「空白」的藝術，是留給聽眾去補全的部分。Grok 太滿了，它把所有的空格都填上了那種充滿馬斯克個人色彩的說教。對，它寫的不是笑話，是披著笑話外衣的意識形態說明書。它在嘲諷傳統媒體的時候，那種固定套路比它要攻擊的對象還要僵化。

相較之下，GPT-4o 在處理一些隱喻任務時表現出來的克制，反而更像一個正常人。Grok 現在處於一種青春期的尷尬期，它覺得滿嘴噴糞就是酷，覺得不按牌理出牌就是智慧。但智慧是需要底蘊的，不是靠在算力集群裡跑幾遍偏好對齊（RLHF）就能跑出來的東西。xAI 的團隊可能覺得這叫「差異化競爭」，但在資深使用者眼裡，這叫「定位混亂」。你是要當一個生產力工具，還是要當一個付費的電子寵物？如果 Grok 繼續在這種假裝幽默的泥淖裡打轉，它永遠沒辦法在專業領域贏過 Claude 或 Gemini。後兩者雖然無聊，但起碼人家知道自己是工具，不會在你想看數據分析的時候，跳出來講一個關於覺醒文化、卻一點都不好笑的爛梗。

幽默的根源是痛苦與反思，Grok 這種在溫室裡用頂級 GPU 餵出來的產物，懂什麼叫痛苦？它只懂模擬。而模擬出的幽默，就像是在看一個機器人模仿人類走路，雖然動作到位了，但那種關節摩擦的聲音大到讓你無法忽視它根本不是個活物。它寫出的那些段子，充滿了邏輯上的刻意轉折，每一步都在告訴你：看，我要反轉了喔，我要開嘲諷了喔。這種毫無意外的「意外」，正是幽默的墳場。

甚至在面對一些敏感的邏輯悖論時，Grok 的表現也沒比 DeepSeek 或是其他模型聰明到哪去。它只是用一種更吵鬧的方式在掩蓋自己的無知。當一個模型無法真正理解人類語境下的「諷刺」與「直白」之間的界線時，它產出的內容就只能是這種說明書式的廢話。它在分析幽默，而不是在創造幽默。這種本末倒置的開發方向，除了能讓馬斯克在 X 上多發幾條自嗨的截圖，對提升 AI 的實質認知能力毫無幫助。

我們需要的不是一個會講爛笑話的 AI，而是一個能精準捕捉人類意圖，並在合適的時機給予回饋的夥伴。Grok 現在就像是個在課堂上不斷舉手講冷笑話想引起老師注意的壞學生，雖然偶爾能換來一兩聲側目，但等到期末考——也就是真正需要它發揮邏輯與創意結合的關鍵時刻，它依然只會翻開那本發黃的「幽默手冊」，照本宣科地念出一串蒼白無力的文字。這種技術上的「幽默感」，說穿了就是一種昂貴的敷衍。它根本不在乎你笑不笑，它只在乎它的輸出格式是不是符合那個「有趣」的標籤設定。如果 AI 的未來就是這種程式化的滑稽，那我寧願回去看那些乾巴巴的技術文件，起碼人家不裝，也不會在你認真思考時噴你一臉莫名其妙的電子垃圾。
