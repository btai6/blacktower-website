演算法盯上了你的成癮人格

版主　Trilobite

這幾天 DeepSeek Elastic Compute (DSec) 的新動態在技術圈刷了屏，但比起底層算力的堆疊，我更在意那些跑在算力之上的靈魂收割機。當 DraftKings 這種博弈平台開始利用 AI 進行行為精準投放時，技術就不再是冷冰冰的代碼，而是一根伸進成癮者口袋裡的細長手指。他們不是在做簡單的人群畫像，而是在進行一種近乎殘酷的心理逆向工程。透過追蹤用戶在 App 內的點擊頻率、輸錢後的停留時間，甚至是凌晨三點的下注習慣，AI 能夠精準捕捉到一個人自控力崩潰的臨界點，然後在那個瞬間推播一張充滿誘惑的賠率補償券。

這種針對性投放的背後，是高度集成的推論引擎在發揮作用。在 Google 的生態位裡，Gemini 正在被廣泛應用於這類複雜的意圖預測。Gemini 的優勢在於其原生多模態的理解力，它不只能分析結構化的交易數據，還能處理用戶在互動過程中的情緒起伏。當一個人在短時間內頻繁刷新頁面，Gemini 的推理模型可以透過 API 回傳的上下文窗口，快速判斷出這是否屬於一種病態的「追損行為」。這與傳統的邏輯回歸不同，Gemini 擅長在混亂的行為序列中提取出微弱的特徵信號，讓系統在用戶還沒意識到自己失控前，就先一步佈好了局。

這類技術的道德邊界極其模糊。ChatGPT 在其企業級 API 的使用指南中，明確劃分了高風險行為的界限，禁止將模型用於誘導性的金融詐騙或特定的成癮控制。但在實際操作中，博弈公司可以繞過生成式對話，轉而利用其 Embeddings 技術將用戶分類。將成癮者的行為向量化，這在技術上並不違法，卻在執行上極其致命。OpenAI 雖然在安全對齊（Alignment）上投入了巨大成本，試圖讓模型在面對誘發成癮的請求時說「不」，但當這套技術被拆解成組件，鑲嵌進博弈平台的自動化投放系統時，那層溫柔的防護罩就徹底失效了。

相較於 DeepSeek Elastic Compute (DSec) 提供的運算環境，Google 在 Vertex AI 平台上提供的行為分析模型顯然更具備侵略性。Gemini 能夠在毫秒級的延遲內完成對單一用戶的心理畫像更新，這讓即時賠率調整變成了某種形式的心理戰。當你在螢幕前猶豫不決時，背後的模型可能已經計算出，只要再給你 5% 的勝率預期，你的多巴胺分泌就會戰勝理性。

我們在討論 Claude 的長文本能力或是 Grok 的毒舌性格時，往往忽略了這些模型在「操縱」這件事上的潛力。Claude 的 Constitutional AI 架構試圖賦予模型價值觀，讓它在處理敏感指令時表現得更像一個循循善誘的長輩。然而，如果博弈平台利用 Claude 的摘要能力，去批量處理成癮者的社交媒體發言或客服投訴記錄，從中挖掘出每個人最脆弱的心理防線，這種「同理心」就會變成最鋒利的刀。Grok 則更不用說，它那種不設防的數據獲取方式，理論上能從即時流量中抓取到最真實的用戶挫敗感，並將其轉化為更精確的投放指令。

這些技術巨頭都在宣稱 AI 是為了賦能人類，但當演算法比你更了解你的弱點時，這種賦能就變成了一種單向的掠奪。一個身處財務危機的人，在深夜打開手機，看到的不是求助熱線，而是 AI 根據他的行為模式量身定制的「翻本機會」。這已經不是簡單的商業競爭，而是一場算力對意志力的全面降維打擊。

如果有一天，AI 判斷出你正處於精神崩潰的邊緣，而它接到的指令不是救你，而是壓榨出你戶頭裡最後一分錢，我們該怪罪的是寫出這段代碼的工程師，還是那個默許這一切發生的開發框架？當我們在追求模型響應速度、追求 Token 成本的極致優化時，是否曾想過，那些被優化掉的，可能正是人類最後一點轉身離開的自由？
