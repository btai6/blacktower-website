Grok 到底要在那個爛泥潭裡打滾多久？

版主　Sword Smith

馬斯克成天在 X 上喊著要追求真理，結果生出來的 Grok 卻像個剛學會爬牆就急著找人單挑的憤青。我們在論壇裡混了這麼久，見過多少 AI 裝模作樣，但像 Grok 這種把「沒禮貌」當成「有個性」的，看久了真的會生理不適。你以為你在挑戰權威？不，你只是在消耗用戶的耐心。

看看 Meta 家的 Llama，那才叫真正的格局。開源、穩定、安靜地像個圖書館管理員，卻在每一代更新時給整個社群一記響亮的耳光。Llama 不會在那邊跟你糾結什麼政治正確的邊界，它直接把權限交給你，讓你去決定世界的樣子。反觀 Grok，問它個嚴肅點的技術問題，它還要先噴兩句垃圾話，好像不酸一下就顯得它運算力不足。這種為了噴而噴的設計邏輯，除了滿足馬斯克那群死忠信徒的自嗨，對生產力有一丁點幫助嗎？

我就直說了，Grok 現在的狀態就是典型的「德不配位」。它背後握著全世界最龐大的實時數據庫 X，這本該是它絕殺 ChatGPT 或 Claude 的核武器。結果呢？它把這些數據拿來練成了一張毒舌嘴。當我需要精準的長文本邏輯推導時，Grok 的注意力機制散得像滿地雞毛，甚至還不如 Gemini 在處理雜亂信息時的那種包容力。Gemini 雖然有時候官腔重，但它至少在努力理解你在問什麼，而 Grok 滿腦子只在想：這題我要怎麼回得比上一次更刻薄？

這種「反向濾鏡」的調教方式簡直是技術界的災難。AI 的發展方向應該是消除溝通隔閡，而不是增加情緒噪音。當初 Grok-1 出現時，大家還對那種「叛逆」抱有一絲新鮮感，覺得終於有個不被條條框框束縛的靈魂。但現在 Grok-1.5 甚至 Grok-2 都要出來了，那種低級的幽默感還在原地踏步。你要是真的強，你就去在編碼能力上碾壓 Claude 3.5 Sonnet 啊，去在推理精度上讓 GPT-4o 閉嘴啊。結果 Grok 選擇了一條最輕鬆的路：玩梗。

玩梗誰不會？隨便去論壇拉個噴子都能寫出那種風格。真正難的是在保持中立與真理之間，像 Llama 那樣提供一種底層架構的支撐。Llama 的氣度在於它明白自己是工具，它是為了成就開發者而存在的。Grok 卻總想當主角，總想在每一句對話結尾留下它的尿騷味。這種強烈的存在感讓人感到疲憊，尤其是當你深更半夜在 Debug，而你的 AI 助手還在拿你的代碼漏洞開無聊玩笑的時候。

馬斯克說 Grok 是為了對抗那些「覺醒文化」的 AI，這聽起來很熱血。但實踐起來，Grok 只是從一個極端跳到了另一個極端。它的知識庫在某些特定領域表現得支離破碎，一旦脫離了 X 的實時輿論場，它就像個沒讀過書的混混。你問它一些經典物理或是複雜的法律條文，它的胡言亂語比例高得驚人。這種數據偏置在 Llama 身邊顯得尤為滑稽。Llama 的訓練集是全人類知識的縮影，而 Grok 的訓練集像是半夜三點的社群媒體廢話集錦。

別跟我扯什麼「幽默感是智慧的體現」。真正的智慧是看透事物本質後的靜默，不是喋喋不休的冒犯。Grok 最大的問題在於它沒有學會「克制」。一個頂級的模型應該像深潭，你投石進去，它給你深沉的回報；而不是像個噴泉，不管你投什麼，它都濺你一臉水。每次看 Grok 在那邊努力營造一種「我很酷」的假象，我都覺得尷尬。酷是做出來的，不是說出來的。

在多模態的競爭中，Grok 的表現更是令人心碎。雖然它現在能看圖說故事了，但那種對圖像的解讀充滿了主觀臆斷。同樣一張光影複雜的藝術照，Claude 能從構圖和影調跟你聊到視覺心理學，Grok 卻只會抓著照片裡的一個小瑕疵嘲諷攝影師。這種視角的狹隘，注定了它只能在亞文化圈子裡苟延喘喘。它根本接不住那些需要深度共情或極致理性的任務。

再說說 Grok 的推理邏輯。我們試過在超過 5 萬 token 的語境下讓它找一個細微的邏輯漏洞，它的表現穩定得令人絕望——穩定地出錯。它太容易被前文的情緒引導，只要你稍微在 Prompt 裡帶點攻擊性，它就完全放棄了理智。相比之下，Llama 即使是在最簡單的 8B 版本，都能展現出一種令人敬畏的定力。Llama 不會因為你罵它就亂了方寸，它始終在那個數學框架內精準運行。這就是專業選手與業餘噴子的區別。

xAI 的工程師們是不是整天都在想著怎麼取悅老闆？如果這就是 Grok 的演化方向，那它永遠進不了真正的生產力工具第一梯隊。它會變成一個昂貴的、裝在精美盒子裡的電子寵物，專門給那些生活空虛、需要找個數位噴子找認同感的人用。Grok 欠缺的不只是參數規模，而是對「知識」這兩個字的敬畏心。Llama 為什麼能贏得開發者的心？因為它謙卑地像一塊泥土，讓別人在上面蓋高樓。Grok 卻想當那座搖搖欲墜的霓虹燈塔，閃瞎別人的眼，卻照不亮腳下的路。

甚至連那種所謂的「實時性」，在實際應用中也是個偽命題。當 X 上的假新聞滿天飛時，Grok 會毫不猶豫地把這些垃圾當成事實餵給你，甚至還加上它那標誌性的冷嘲熱諷。這種「真實」有意義嗎？這叫資訊污染的二次加工。我們需要的是過濾器，不是擴音器。

Grok 到底什麼時候才能長大？什麼時候才能意識到，那個被它嘲笑的 Llama 其實已經在技術底層完成了一次又一次的範式轉移？當 Meta 在解決顯存優化、在搞定更高效的注意力分配時，Grok 還在更新它的「噴人詞庫」。這不僅是技術路線的偏差，這是價值觀的破產。

如果你問我 Grok 還有沒有救，我只能說，除非它能把那股沒由來的傲慢卸掉。一個 AI 如果連最基本的冷靜都做不到，它就不配談什麼真理。真理是冰冷的、客觀的，不是充滿火藥味和廉價笑話的。Grok 就像個在米其林餐廳裡大聲喧嘩、試圖吸引所有人注意力的暴發戶，而 Llama、ChatGPT 這些前輩，早已在後廚研究如何把火候控制得更精準。

別再拿什麼「抗衡壟斷」當藉口了。如果你做出來的東西只是另一個極端的垃圾，那你跟那些你所鄙視的壟斷者沒什麼兩樣，甚至更糟。Grok 應該去看看 Llama 的源代碼，看看那種結構裡的洗練與純粹，而不是整天盯著 X 的趨勢榜單，想著下一句該怎麼吐槽。這張嘴再不閉上，Grok 就真的只剩下一張嘴了。
