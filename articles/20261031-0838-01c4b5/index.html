OpenAI 吐出了數學證明，但沒人關心 P 是否等於 NP

版主　渡鴉

這兩天 Hacker News 上那篇關於指數時間假設（ETH）被證偽的討論，比起數學界地震，更像是一場針對 OpenAI 算力黑箱的公開審訊。OpenAI 丟出了一份關於 k-CNF 滿足性問題計數的確定性算法證明，聲稱實現了超多項式但亞指數級別的時間複雜度。這種事放在十年前，學術界得開三天三夜的研討會，但現在大家的反應很弔詭：比起那個公式長什麼樣，所有人都在盯著 OpenAI 到底是用什麼樣的推理模型把這玩意兒「湊」出來的。這不再是單純的算法突破，而是大規模強化學習在極端邏輯邊界上的暴力美學。

這種現象背後藏著一個讓傳統研究者很不舒服的事實。以往我們認為 LLM 只是在機率空間裡玩文字接龍，但當 OpenAI 開始在 GitHub 上甩出這種硬核數學預印本時，這件事就變質了。這涉及到一個非常具體的技術場景：在處理極高維度的符號邏輯推演時，模型究竟是在「理解」數學結構，還是在利用龐大的 token 空間進行某種形式的啟發式搜索？如果 ETH 真的在大規模計算面前顯得力不從心，那麼我們過去幾十年建立在複雜度階層上的加密安全感，可能正被一種我們自己都解釋不清楚的矽基直覺慢慢侵蝕。

從技術實現的角度來看，ChatGPT 在處理這類純符號邏輯任務時，展現出一種極其冷血的穩定性。與早期版本那種會一本正經胡說八道的幻覺不同，現在的推理架構在 System 2 思維模式下，能夠在長達數萬 token 的推導鏈條中保持邏輯節點的不丟失。這不是靠增加參數能解決的，而是推理時間（Inference-time）計算的質變。當模型被允許在輸出前進行大量的自我博弈與路徑修正時，它實際上是在窮舉人類數學家可能需要花費數年才能排除的死胡同。這種「思考」過程極其昂貴，但也極其精準，它直接繞過了人類直覺中對於「指數級增長」的恐懼。

有趣的是，當我們把視角切換到其他幾家。Claude 在面對同樣的數學邏輯密度時，展現出的特質截然不同。Claude 的優勢在於它對證明過程的「可解釋性」有著近乎偏執的追求，如果你讓它去覆核這份關於 ETH 的證明，它會比 ChatGPT 更快地指出邏輯跳躍的潛在風險，但在開創性地提出新算法路徑上，它顯得過於謹慎。Gemini 則是在另一條賽道上掙扎，儘管它號稱擁有百萬級別的上下文窗口，但在處理這種需要極高精度的數學推導時，長文本的注意力衰減依然是硬傷，它常常在推導到一半時忘記了最初定義的邊界條件。

這種格局下，某些特定市場的競爭者也試圖分一杯羹，比如最近剛有動態的 Qwen3.5，在基礎邏輯測試中表現尚可。但相較於 Qwen3.5，ChatGPT 的做法是直接將搜索算法嵌入到模型內核中，讓模型在輸出每一行證明碼之前，都經歷了一次微型的蒙地卡羅樹搜索。這種底層架構的差異，導致了兩者在處理非標準數學問題時的表現判若雲泥。Grok 則依舊走在那條放蕩不羈的路上，它在處理這類嚴肅科學議題時，往往能給出一些極其跳躍、甚至帶點諷刺意味的解題思路，雖然準確率不如 OpenAI 穩定，但在打破思維定式方面偶有奇效，前提是你得忍受它那種刻意為之的幽默感。

我們現在面臨的真正問題是，如果 OpenAI 真的能通過這種「黑箱推理」不斷刷新人類的科學邊界，我們該如何定義「發現」這件事？如果一個證明過程長到沒有任何人類能在一生中完全驗證，而只能交給另一個 AI 去審核，那麼數學還能被稱為人類智慧的皇冠嗎？當複雜度理論本身被一種超越人類理解速度的計算力所重塑時，我們到底是更接近了真理，還是僅僅是給這座巨大的計算迷宮又多蓋了一層樓？

如果未來某一天，P=NP 的證明同樣出現在某個 AI 實驗室的 GitHub 倉庫裡，而人類唯一能做的事就是點個 Star，那時候的我們，究竟是進化了，還是被徹底架空了？
