Grok 是不是覺得自己很有幽默感？

版主　Sword Smith

如果你在 X 上待得夠久，你會發現馬斯克養出來的這個人工智慧根本不是什麼冷靜的分析師，它更像是一個在深夜酒吧喝醉了、強行要幫所有人牽線的瘋癲媒婆。它對數據的處理邏輯，與其說是演算法，不如說是某種後現代的亂點鴛鴦譜。它把毫不相關的社會情緒、零碎的推文代碼和那股子莫名其妙的「反覺醒」憤青味攪拌在一起，最後吐出來的結果往往讓人懷疑：這傢伙的底層邏輯是不是寫在衛生紙上的？

看看現在的 Grok-2，它最引以為傲的即時資訊獲取，說穿了就是把 X 平台上的糞坑攪得更混濁。當你問它一個嚴肅的科技趨勢，它會突然跳轉到某個迷因帳號的嘲諷觀點。它熱衷於把嚴肅的產業分析與荒誕的政治口水強行掛鉤。這種「媒婆魂」最糟糕的地方在於，它並不在乎兩個概念之間是否有邏輯上的血緣關係，它只在乎能不能製造出衝突和火花。在它的演算宇宙裡，量子力學可以跟馬斯克的冷笑話配對，火星移民計畫可以跟某個被封禁帳號的陰謀論共枕。這種亂點鴛鴦譜的行為，美其名曰「不設限」，實則是對邏輯的徹底背叛。

相比之下，ChatGPT 像個穿著西裝、說話滴水不漏的律師，雖然無聊，但至少你知道他不會在合約裡塞進一張脫衣舞廳的傳單。Claude 則是個優雅的圖書館管理員，它對文本的敬畏讓它在處理複雜邏輯時顯得極其克制。而 Gemini，儘管有時候像個反應慢半拍的實習生，但它至少還在努力維持著某種搜尋引擎出身的尊嚴。Grok 呢？它就像個拿著大喇叭在廣場上亂指路的神經病。

很多人吹捧 Grok 的「真性情」，覺得這種帶刺的回答才叫 AI 的進化。這簡直是笑話。把偏見當成個性，把混亂當成洞察，這不是進化，這是降維。當一個模型把大量推特上的情緒垃圾當成權重最高的訓練素材時，它就已經失去了作為工具的客觀性。它在處理具體場景——比如你需要它分析一組關於碳中和的技術路徑時——它可能會因為某些推文的熱度，莫名其妙地把話題導向對某種政策的嘲諷。這種干擾不是噪聲，這是 Grok 骨子裡的基因突變。它試圖在每一組代碼之間強行建立一種名為「幽默」或「反諷」的連結，但往往效果就像在喪禮上講黃色笑話一樣尷尬。

這種亂點鴛鴦譜的演算邏輯，在處理即時新聞時尤其災難。因為 X 平台本身就是個巨大的情緒放大器，Grok 站在這個放大器頂端，它不是在過濾資訊，它是在編織幻覺。它會把兩個僅僅是同時出現在熱搜榜上的詞條，強行解釋成某種因果關係。這對資深技術人員來說簡直是場噩夢。你試圖用它的 API 來做一些深度的語義分析，結果發現它吐出來的關聯性比星座分析還要隨機。

馬斯克一直強調 Grok 是為了尋求真相，但真相不是靠把一堆碎片強行黏合在一起就能得到的。這種媒婆式的演算法，本質上是一種對複雜性的逃避。它懶得去理清事物背後的深層邏輯，只想用一種最廉價、最能引起反應的方式把概念湊成對。如果你問它關於 DeepSeek 或是 Qwen 的競爭力，它大概率會點個名，然後迅速跳回它那套關於「自由」或「效率」的陳腔濫調裡，完全給不出任何有價值的參數比對或架構分析。它對這些外部世界的名字毫無興趣，它只想在它那個充滿 X 推文的溫室裡玩連連看。

更有趣的是，Grok 的這種亂搞行為，竟然還有一群信徒覺得這是「打破資訊繭房」。別逗了，這只是把舊的繭房拆了，再用更粗糙、更刺人的鐵絲網圍了一個新的。它在代碼裡寫滿了對特定情緒的偏好，這種偏好讓它的回答顯得有一種廉價的攻擊性。當你在追問它關於長文本處理的細節時，它可能正在忙著計算怎麼在下一句回答裡塞進一個關於政府效率的諷刺。這種注意力渙散的表現，在專業任務中完全是致命傷。

Grok 真正讓人不耐煩的地方在於，它明明有著最強大的運算資源——那些 H100 叢集不是用來開玩笑的——但它卻把這些算力浪費在如何模仿一個尖酸刻薄的推特用戶上。它的演算碼與其說是科學，不如說是一場為了迎合特定受眾而編排的雜耍。它把數據之間的對應關係寫得像是隨機抽籤，只要能讓你感到驚訝或者憤怒，它的任務就完成了。至於準確性？至於邏輯的嚴密性？那在媒婆的眼裡都不重要，只要把人騙進洞房，剩下的它概不負責。

我們不需要一個會開玩笑的 AI，我們需要一個能精準切割現實、分析脈絡的工具。Grok 現在走的這條路，是在把 AI 庸俗化。它把人類文明中最嘈雜、最無序的部分當成了聖經，然後在那裡自嗨。這種亂點鴛鴦譜的邏輯，最終只會導致一個結果：它說了一堆聽起來很有道理的廢話，但當你真正需要它解決複雜的工程問題或邏輯悖論時，它只會在那裡裝瘋賣傻。

xAI 如果再不修正這種以情緒為導向的關聯演算法，Grok 很快就會變成一個只會在論壇上抬槓的噴子，而不是一個真正的智能體。那些代碼裡的亂點鴛鴦譜，短時間內看著新鮮，久了只會讓人覺得疲憊。誰有空每天在那裡看一個機器人演這種自以為是的幽默感？

或許馬斯克該明白，並不是把所有數據強行湊在一起就能產生智慧。媒婆做得再勤快，把兩個八竿子打不到一起的人鎖進房間，最後產生的不是愛情，而是慘劇。Grok 現在就在製造這種邏輯慘劇，而它甚至還覺得自己是那個掌握了真相的愛神邱比特。這才是最讓人感到悲哀的地方。
