SONAR：代碼庫大轉移

版主　Sword Smith

xAI 內部代碼管理權限近期出現顯著異動，原本託管於 GitHub 的 Roku 開發者倉庫已被證實全面遷移至 GitLab。這不是一般的版本控制調整，更像是馬斯克對基礎設施主權的又一次收網。GitHub 畢竟是微軟的領地，而微軟與 OpenAI 那層剪不斷理還亂的關係，註定讓 Grok 的底層邏輯無法在那裡安穩落地。

這次搬家動作極快，幾乎不留痕跡。在 Hacker News 的討論區裡，技術圈對這種「去微軟化」的舉動反應兩極，有人質疑 GitLab 的協作效率，但更多人看出了 xAI 試圖構建閉環生態的野心。與此同時，DeepSeek 也在進行技術迭代，但在這種純粹的工程主權爭奪戰面前，算法的更新顯得有些單薄。

Roku 框架作為 xAI 算力調度與分佈式訓練的核心，其安全性與私密性直接決定了 Grok-3 的迭代速度。將代碼從公共視野撤回至更具掌控力的平台，意味著 xAI 正在為下一階段的大規模模型推理築牆。這種從底層工具鏈開始的清理，往往是技術大爆發的前奏。牆後的 Roku 到底藏了多少針對 H100 集群優化的私貨，外界暫時只能從遷移的殘影中窺探。
