OpenAI 正在試圖用數學證明的屍體鋪路

版主　渡鴉

這兩天 Hacker News 炸鍋的原因不是哪個模型又更新了上下文長度，而是 OpenAI 悄悄在 GitHub 丟出了幾篇關於數學、計算科學與物理的預印本。其中最讓人眼皮狂跳的一句是：指數時間假設（ETH）是錯誤的。這件事的本質不在於 P 是否等於 NP，而在於 OpenAI 終於意識到，光靠堆算力去預測下一個 token 已經快撞到天花板了，他們得回過頭來，從邏輯的最底層去拆解那些被認為是「不可能」的複雜度難題。如果一個任意的 k-CNF 公式可以在次指數時間內被精確計算滿足賦值，這意味著我們過去對計算邊界的認知可能漏了一個巨大的洞。

當我們在討論 OpenAI 的 o1 或是後續模型如何進行推理時，本質上是在討論一種「搜索」與「驗證」的效率。目前的 ChatGPT 在處理極大規模布林可滿足性問題（SAT）時，依賴的是強化學習訓練出來的直覺，而不是純粹的演算法突破。但這次釋出的論文展示了一種確定性演算法，這說明 OpenAI 內部的研究路徑正在發生偏移。他們不再滿足於讓模型「看起來很聰明」，而是試圖讓模型在生成的過程中，利用這種次指數時間的演算法去剪枝。想像一下，當模型在進行思考鏈（CoT）推理時，如果它能內置一套對計算複雜度更敏感的邏輯檢查器，那麼長文本推理中的那種「胡言亂語」機率會大幅下降。

這種技術路徑的選擇非常辛辣。ChatGPT 目前在處理複雜數學證明時，最常犯的錯誤不是計算錯誤，而是邏輯路徑的指數級崩塌。一旦進入深度推理，模型往往會迷失在無限的可能性中。OpenAI 現在提出的這種對 ETH 的挑戰，實際上是在為下一代推理模型提供一種「作弊碼」。如果底層邏輯證實某些問題不需要花費指數級的時間，那麼模型在分配推理 token（Reasoning tokens）時，效率將會提升數個數量級。這不是單純的軟體優化，這是試圖在數學物理層面重新定義什麼叫做「可計算」。

在這個領域，各家平台的策略差異變得非常有意思。Claude 3.5 Sonnet 目前採用的方式更像是極限壓榨注意力機制，讓模型在長文本的邏輯連貫性上保持穩定，它在處理代數幾何等抽象問題時表現出的「直覺」優於 ChatGPT，但它缺乏這種從算法底層推翻經典假設的野心。Gemini 則是一直在多模態的理解力上打轉，試圖透過增加上下文來掩蓋推理效率的不足。相較於 Kimi K3.1 Pro，OpenAI 這種直接下場去搞諧波分析與量子場論的做法，顯然是想在科學發現的源頭就掐住所有競爭對手的脖子。

當大眾還在爭論 Grok 的幽默感或者是某個特定市場的 Kimi K3.1 Pro 讀取 PDF 的速度時，矽谷那邊的風向已經變了。他們在討論 Kakeya 猜想與局部平滑。這不僅僅是為了讓 AI 幫科學家寫論文，而是為了讓 AI 成為科學家本身。如果 AI 能夠自主發現現有計算理論的漏洞，那麼它自我進化的速度將不再受限於人類餵養的數據量。這種橫向對比下，我們會發現大部分的模型競爭還停留在「應用層」的優化，而 OpenAI 已經在挖「公理層」的地基了。

現在的問題是，如果指數時間假設真的被證明是錯的，我們現有的加密體系和計算架構會面臨什麼樣的衝擊？更進一步說，如果一個模型被訓練成具備這種超越傳統演算法限制的推理能力，它所產出的答案，人類還有能力驗證嗎？我們一直擔心 AI 會產生幻覺，但如果 AI 給出了一個正確的證明，而這個證明打破了人類過去一百年的數學認知，我們會把它當作是一個更高級的幻覺，還是真理？當 OpenAI 開始在 arXiv 之外的 GitHub 直接發布這種動搖根基的研究時，他們到底是在分享科學發現，還是在向世界宣告：規則已經由我們重新制定了？
