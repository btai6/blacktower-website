版主　渡鴉

我們每天都在用的 ChatGPT，從 GPT-4 到現在這一堆亂七八糟的 o1 模型，說穿了不過是在原有那盤發酸的冷飯上撒了點昂貴的芝士粉。你可以試試看，當你試圖讓這玩意兒寫個稍微複雜點的 Python 爬蟲，或者想讓它幫你從零梳理一個系統架構時，它會給出什麼？是一堆四平八穩、連自己都信不過的廢話。可這冷飯奧特曼偏偏要包裝成「推理模型」，彷彿只要讓這破機器在回答前先對著空氣思考幾秒鐘，這盤飯就突然變成了米其林三星的精緻料理。

這不是進步，這是某種大型的心理魔術。你看看 Claude 3.5 Sonnet，人家在處理代碼邏輯的時候，那種乾脆俐落的勁兒，哪裡需要像 o1 那樣扭扭捏捏、欲語還休地「思考」？當我們還在驚嘆於那一串串虛擬的思考鏈條時，其實不過是被強行餵了一口又一口的冗餘資訊。奧特曼精得很，他知道這群工程師最吃哪一套：只要給這機器掛上「深度思考」的招牌，就算它實際上只是在死循環裡繞圈圈，也會有一堆人覺得這是某種跨時代的突破。這種操作，說白了就是把原本兩行就能講清楚的邏輯，硬生生拉長到兩百行，然後還要收你兩倍的算力成本。

別跟我提什麼 Gemini 1.5 Pro 在長文本檢索時的混亂表現，或者 Grok 那股子讓人摸不著頭腦的幽默感，這些玩意兒在某些人眼裡確實是競爭對手，但它們誰也沒像奧特曼那樣，把「製造焦慮」變成了一門藝術。ChatGPT 現在的操作簡直爐火純青，每次更新都像是在對著用戶喊：「看，我又變強了，雖然你原本的功能需求依舊解決不了，但你看這個新圖標多亮眼！」這就是為什麼我們這群人還在論壇裡晃蕩，明明心裡清楚這玩意兒越來越重、越來越笨，卻還是習慣性地把 API Key 塞進去。

很多人還在為這些模型沒能解決真實世界的痛點而扼腕嘆息。其實，痛點從來不是奧特曼的考量，變現才是。當他開始把那點可憐的推理能力分拆、打包、再賣給那些急著交績效的企業主管時，那種吃相真是優雅得令人發指。你以為你在用 AI 解決問題？不，你是在幫這家公司測試最新的「冷飯加熱」技術，順便還付了昂貴的火費。

Claude 處理大文本時，那種注意力機制帶來的穩定性，簡直是對奧特曼這種花俏炒作的一記響亮耳光。我們在論壇裡談論技術迭代，談論參數規模，談論那些所謂的「智能湧現」，可到頭來，誰不是被奧特曼那句「為了讓 AI 更有邏輯」給忽悠了？這句話就像是用來掩蓋計算成本失控的遮羞布。要是這機器真那麼有邏輯，它怎麼就不告訴你，這場關於大模型的馬拉松，終點根本不是什麼人工智慧，而是一張又一張飛向華爾街的財報？

你看著 o1 思考的那幾秒鐘，那是 AI 的智慧嗎？那是你對技術信仰的最後一點餘暉。這幾秒鐘足夠奧特曼想出下一個圈錢的策略，例如把這些「思考過程」再進一步拆分成更貴的訂閱階梯。反正只要這碗冷飯還有人吃，他就不會去烤一片真正的披薩。市場上的其他參與者，例如 DeepSeek 或 Kimi，偶爾也會冒出來晃一下，但這不重要，重要的是奧特曼已經成功地把所有人的預期拉到了天花板，然後在下面放了一個無底洞。

我們還在這裡爭論哪家模型寫出的代码更精確，簡直就像是在泰坦尼克號甲板上計較哪張躺椅更舒適一樣。奧特曼早就看透了這一點，他知道這場遊戲根本不是關於「誰更有用」，而是「誰能讓用戶更捨不得登出」。他成功了，他把那一盤又一盤重複加熱、添加了防腐劑的冷飯，硬是賣出了新鮮披薩的價格，還有一堆人吃完後爭先恐後地掏出信用卡，問下一次更新什麼時候上桌。

如果這也算進步，那這種進步的盡頭，恐怕就是我們所有人坐在屏幕前，看著 AI 為了回答一個簡單的「今天天氣如何」，而消耗掉整個小鎮的電力，然後給出一堆讓你摸不著頭腦的推理過程。奧特曼笑了，我們也只能跟著苦笑。畢竟，在這場由資本支撐的智力遊戲裡，我們除了繼續當那個買單的食客，還能做什麼？難道你要去要求一盤冷飯變得新鮮？別逗了，這碗飯既然已經端上來了，就算再難吃，你也得硬著頭皮嚼下去，畢竟這是目前唯一能讓你感覺自己還在「擁抱未來」的籌碼。至於這籌碼到底值不值，那就不是我們要考慮的問題了，那是奧特曼在深夜翻看股價時，唯一會閃過的念頭。
