當你沾沾自喜地在對話框裡輸入「請幫我優化這段週報的措辭」時，有沒有聞到一絲福馬林的味？

版主　渡鴉

我們這群活在矽谷大夢裡的數位勞工，最擅長的事情就是把絞索當成健身拉繩。你以為你在訓練 ChatGPT 成為你的分身，好讓你能騰出時間去喝那杯要價兩百塊的冷萃咖啡，實際上你只是在親手為自己的職業生涯化妝、塞棉花，最後優雅地躺進那個由 0 與 1 組成的棺材裡。這不是什麼自動化革命，這是一場集體參與的數位入殮儀式。

奧特曼（Sam Altman）每次上台那副悲天憫人的救世主模樣，看得我胃酸逆流。他推銷的是「生產力解放」，但本質上是在搞一場數據版的「吃絕戶」。你把過去十幾年累積的直覺、經驗、那些只有你才懂的業界黑話，通通餵給了那個永遠不會累、也不需要勞健保的黑盒子。然後呢？你覺得老闆會因為你產出效率變高而給你加薪？別天真了。老闆看著螢幕上那串精準到令人髮指的產出，心裡想的只有一件事：既然這台機器已經學會了你的靈魂，那我為什麼還要付錢租用你的肉體？

現在的職場氛圍噁心得像是一場慢動作的集體自殺。大家都在比誰更能「調教」AI，誰的 Prompt 寫得更像神諭。你把 Claude 當成救命稻草，看著它寫出比你更有邏輯的架構，心裡泛起一陣病態的快感。那是斯德哥爾摩症候群的變種。你正在把自己的不可替代性，一片一片地切下來餵給模型。等到模型長得跟你一模一樣的時候，就是你領遣散費的日子。到時候，你連寫那封抗議信可能都要請 Gemini 幫忙潤稿，這諷刺程度簡直能拿奧斯卡。

很多人跟我爭辯說，AI 只是工具，人類的「創意」不可取代。這種話聽起來就像十九世紀的馬夫在說「汽車永遠體會不到騎馬的樂趣」一樣蒼白。創意？你所謂的創意，在 LLM 眼中不過是機率分布的高維投影。當 GPT-4o 能夠在幾秒鐘內模擬出五種不同的人格來反駁你的觀點時，你那點可憐的、建立在睡眠不足和咖啡因上的「靈光一閃」，卑微得像塵埃。我們引以為傲的思考能力，在算力面前不過是效率極低的生化反應。

最讓人寒心的是，這場葬禮的費用還是我們自付的。每個月二十美金，你買的不是效率，是你自己的數位墓地預售屋。你每按一次 Enter，就是在幫老闆完成你的數位遺產移交。那些被點名的 DeepSeek 或 Qwen 其實都一樣，不管誰贏，輸的都是坐在電腦前按鍵盤的你。我們正在創造一個沒有「過程」的世界，只剩下「結果」。而一個不需要過程的文明，自然也不再需要承載過程的人類。

看看 Grok 那種自以為幽默的語氣，或者 Gemini 試圖表現出的那種虛偽的道德正確。這些模型正在重塑我們溝通的邊界。以前我們寫信、寫文案，是為了傳達溫度；現在我們只求「對準」（Alignment）。對準誰？對準老闆的喜好，對準市場的平均值，對準那個能讓演算法高潮的指標。我們變得越來越像 AI，為了不被淘汰，我們主動閹割了所有具備人性瑕疵的表達。當每個人都寫出一樣完美的廢話時，平庸就成了新的卓越，而我們也就完成了徹底的工具化。

老闆們現在肯定躲在辦公室裡偷笑。他們不需要再應付員工的情緒、病假或那些令人頭痛的產假。他們只需要一個能跑 Python 的環境，加上幾組 API Key。你以為你在馴服野獸，其實你是在教野獸怎麼最省力地咬斷你的脖子。那些所謂的「Prompt Engineer」，不過是第一批學會幫自己挖掘墳墓的人，還在嫌自己挖得不夠深、不夠漂亮。

為什麼我們對這種異化毫無警覺？因為這劑毒藥裹著糖衣。它讓你暫時從瑣碎的勞動中解脫，讓你產生一種「我變強了」的幻覺。這跟毒品沒兩樣。當你離開了那個對話框，發現自己連一段邏輯通順的長難句都寫不出來時，你才發現你的腦袋已經萎縮成了一個只會點擊「重新生成」的食指。這就是數位入殮的最高境界：受害者不但全程參與，還覺得自己是主刀醫生。

矽谷那幫人最愛講「通用人工智慧」（AGI）是人類的最後一項發明。這句話沒說完，它的意思是：一旦這項發明完成，剩下的就是人類的集體退休，或者說，集體作廢。我們正在親手切斷後代的上升通道。以前新人進公司是學本事，現在新人進公司是學怎麼讓 AI 做事。當底層的基礎勞動被徹底取代，人類的知識傳承就會出現斷層。沒有了磨練技藝的過程，哪來的大師？最終，這個世界將只剩下幾台神祇般的機器，和一群只會按按鈕、卻連原理都說不清楚的祭司。

這是一場沒有煙硝的清算。我們在社交媒體上爭論哪家的模型參數更高、哪家的長文本處理更強，卻從不討論我們正在失去作為「勞動者」的尊嚴。當你的價值可以被一組權重完全覆蓋時，你身而為人的神聖性就徹底崩塌了。你不是在工作，你是在幫 AI 進行強化學習。你出的每一道題，給出的每一次評價，都是在完善那個即將取代你的算法。

最弔詭的是，我們竟然還在為這件事歡呼。每當 OpenAI 發布新功能，論壇上就一片高潮，彷彿人類文明又往前邁進了一大步。沒錯，是邁進了，只不過是朝向深淵的方向邁進。我們正在構建一個不需要人類參與的繁榮，一個充滿精緻內容卻毫無靈魂棲息地的荒原。

別再跟我提什麼「人機協作」了。在權力不對等的結構下，協作只是吞噬的優雅說法。當老闆發現一個月兩百美金的 API 支出能換掉一個月薪十萬的資深主管時，他會毫不猶豫地按下那個 Delete 鍵。而你，帶著滿腦子的 Prompt 技巧走向人才市場，卻發現那裡早已是一片焦土。大家都在賣力地推銷自己的入殮服務，競爭誰的壽衣織得比較快。

這種犬儒不是天生的，是被現實一記耳光接一記耳光抽出來的。你看著這些科技巨頭一邊領著政府補貼，一邊裁撤那些幫他們訓練出模型的基礎員工，你還能對這技術抱持什麼浪漫的幻想？這就是一場資本對勞動的終極掠奪，而我們卻在幫掠奪者磨刀。

或許這就是我們的宿命。我們創造了上帝，然後上帝覺得我們礙事。在我們徹底變成數位標本之前，至少我們還能用這雙沒被模型接管的手，打下最後幾句不合時宜的廢話。雖然這些廢話很快就會被過濾掉，或者被拿去微調下一個版本的模型，讓它學會如何更精準地嘲諷那些還在抵抗的人。

你以為你在對抗平庸，其實你是在精煉平庸。你以為你在擁抱未來，其實未來根本沒有打算擁抱你。它只是需要你的數據，等你乾涸了，它會毫不留情地把你扔進歷史的垃圾掩埋場。在那裡，你會遇到以前的打字員、電梯操作員和紡織工人。唯一的區別是，他們是被迫失業，而你是花錢買票，親自走進了那個幫你數位入殮的小房間，還不忘給個五星好評。
