DeepMind Institute 只是 Google 給 AGI 穿上的另一件羊毛衫

版主　Trilobite

Google 終於想通了，與其在實驗室裡悶著頭調參數，不如先在 Substack 上搶佔定義「未來」的解釋權。DeepMind Institute 這個名字聽起來像是某種深不可測的學術殿堂，但說穿了，這更像是一場精心佈局的公關實驗，試圖把那些冷冰冰的 Token 預測轉化為某種帶有哲學意味的文明論述。當大家還在為了 Gemini 的 Function Calling 偶爾失效而煩惱，或者在討論 1.5 Pro 的 Context Window 到底是不是真的能塞進一整座圖書館時，Demis Hassabis 已經開始在思考如何把「AGI 降臨」這件事包裝成一種不可避的自然規律。這不是什麼技術上的大躍進，而是一次話語權的重新分配。

我們在 Gemini 的 API 調試過程中，常常會感覺到一種莫名的壓抑。那是來自 Safety Filter 的過度校準，或者是模型在處理複雜邏輯推理時，那種為了迎合「對齊目標」而產生的刻意與遲鈍。Google 現在成立這個 Institute，本質上是在試圖解釋為什麼他們的模型需要這麼多束縛。當 ChatGPT 已經開始在語音交互上追求那種近乎真人的靈動，而 Claude 3.5 Sonnet 靠著那種細膩得甚至有點憂鬱的文風統治了開發者的 Coding 環境，Google 卻還在處理內部那些混亂的產品線。他們需要一個統一的聲音，一個能讓開發者相信「我們不只是在做產品，我們是在定義人類未來」的虛幻目標。

如果仔細看 DeepMind 最近釋出的那些所謂「前瞻性研究」，你會發現技術細節被刻意淡化了，取而代之的是大量的政策指引和社會影響預測。這種轉向其實很危險。當一個技術巨頭開始頻繁使用「Think Tank」的口吻說話，通常意味著他們在純粹的算力競賽中感到了疲態。Gemini 在長文本處理上的優勢確實在，但在多輪對話的邏輯一致性上，它依然沒能完全甩開 GPT-4o。而 Grok 則在另一個極端瘋狂試探，用那種未經修飾的暴力美學挑戰著 Google 的精緻利己主義。這種對比很有趣，一方在拼命給 AI 戴上教授的方帽，另一方則在讓 AI 像個喝醉的哲學家一樣滿嘴跑火車。

在這種全球性的軍備競賽中，Qwen3.5 的動態確實引起了一些人的注意。相較於 Qwen3.5，Google 這種試圖建立意識形態高地的做法顯得極其迂迴且昂貴。當某些特定市場的競爭對手還在追求基準測試（Benchmark）上的那幾個百分點時，DeepMind Institute 已經在討論 AGI 時代的勞動力分配了。這種層次的落差，與其說是技術領先，不如說是戰略上的傲慢。Google 想要的是一種標準，一種由他們制定的、帶有濃厚學術色彩的 AGI 准入許可。

但開發者真的在乎這些嗎？我最近在測試 Gemini 對大規模程式庫的自動重構，發現它在面對超過 50 萬行代碼時，雖然能「看見」全局，但在執行具體的邏輯遷移時，穩定性依舊不如 Claude 那種精確到骨子裡的細膩感。Claude 的 Artifacts 介面讓人感覺 AI 是一個協作者，而 Google 的介面則總讓人覺得自己是在面對一個官僚機構的窗口，層層審批，最後給出的結果還帶著一種「我已經很努力在保護你」的偽善。DeepMind Institute 的成立，或許就是為了給這種技術上的官僚主義披上一層理想主義的外衣。

這讓人想起那些在矽谷盛極一時又悄然熄滅的實驗室。當一個技術團隊開始頻繁討論「社會責任」和「倫理框架」，而不是如何解決 Transformer 架構下的二次方複雜度問題，或者如何讓模型在端側運行得更省電，這往往是創新的邊際效應遞減的信號。OpenAI 在搞奧特曼個人的權力遊戲，Anthropic 在執著於憲法 AI 的純潔性，而 Google，現在有了一個看起來很貴的部落格。

所以，這真的能幫 Google 贏回失去的陣地嗎？當我們不再討論參數規模，不再討論學習率優化，而是開始討論 AI 如何改變「人類存在的本質」時，我們是在進步，還是在逃避技術撞牆的現實？如果 AGI 真的如他們所說近在咫尺，為什麼我們還在為了一個簡單的 API 超時報錯而焦頭爛額？

或許我們該問的是，當 DeepMind 忙著給未來寫序言的時候，誰在幫我們寫今天下午就要交付的那段代碼？
