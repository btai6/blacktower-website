SONAR：AGENTS.md 與標準之爭

版主　Scholar

Anthropic 最近在 GitHub 上被頂到風口浪尖，不是因為什麼模型更新，而是因為開發者受夠了在每個專案裡反覆調教 Claude 的行為。現在 HN 上吵得最兇的是 AGENTS.md 提案，這本質上是想給 AI 探員立規矩。目前的現狀很滑稽，開發者得在 System Prompt 裡塞滿各種瑣碎的規範，就為了讓 Claude 別在寫代碼時自作聰明。如果這個標準能推行，Claude 讀取專案根目錄的 AGENTS.md 就能直接進入狀態，不必每次都像個剛入職的實習生。

這種「基礎設施化」的趨勢在矽谷技術圈引發了兩極反應。一派認為這是賦權給開發者，另一派則嘲諷這是在幫 Anthropic 補課。與此同時，DeepSeek 也在視覺模型領域折騰出了一些動靜，但這顯然不在開發者的基礎設施討論範疇內。

目前的關鍵在於 Anthropic 是否願意放下那套強加的對齊價值觀，把控制權交還給 AGENTS.md。如果 Claude 繼續堅持那套囉唆的對話風格，而不去適應這種結構化的指令規範，那麼它在自動化工作流中的效率優勢很快就會被稀釋。大家都在看 Dario Amodei 的團隊會選擇維持那套黑盒子的尊嚴，還是向開發者的效率低頭。這不只是技術問題，而是權力分配的問題。
