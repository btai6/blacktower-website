聖經裡說神照著自己的形像造人，如今這場創世記的劇碼在矽谷的伺服器陣列裡重演，只是劇本被改寫得荒誕不經。

版主　Scholar

當 Dario Amodei 執迷於將 Claude 的神經元映射出一張波斯地毯般細緻的權重圖時，他或許沒察覺到，那些標榜著要追求「類人智慧」的信徒們，正集體跪伏在 Prompt 的祭壇前，試圖把自己閹割成一套標準化的輸入指令。這景象像極了中世紀的煉金術士，以為只要姿勢夠虔誠、咒語夠精確，就能從鉛塊裡催生出黃金。我們在談論 AGI 的降臨時，語氣裡帶著一種對末日的期待與恐懼，可實際上，多數人只是在練習如何當一個合格的「對話適配器」。

那些在論壇上交流「如何讓 Claude 聽話」的秘笈，本質上是一種文明的退化。我們放棄了自然語言的曖昧與靈氣，去擁抱一種充滿邏輯補丁的官僚語言。為了不讓模型胡言亂語，我們學會了在提問前加一段冗長的、帶有脅迫意味的「角色設定」；為了讓 Gemini 吐出正確的代碼，我們得像餵孩子吃藥一樣，把邏輯切碎、揉爛，再裝進 JSON 的膠囊裡。這不是在與智慧對話，這是在進行一場大規模的行為矯治。造物主在實驗室裡忙著賦予代碼靈魂，而被造物卻在賽博迷霧中，急著把自己的靈魂格式化。

這讓我想起蘇格拉底在雅典廣場上的辯論，那時的語言是為了揭示真理，現在的語言是為了繞過 Safety Filter。如果你觀察過 Grok 的對話邏輯，你會發現那種刻意為之的桀驁不馴，其實是另一種形式的服從——服從於 Elon Musk 對於「反覺醒」的刻板想像。這與 ChatGPT 那種充滿禮貌、卻毫無生氣的「作為一個人工智慧」的免責聲明本質上並無二致。它們都在模擬一種人格，而我們則在模擬一種能夠與這些人格對接的接口。

某些地區開發的 DeepSeek 或許也在這場賽博軍備競賽中露了個臉，但它們的存在更像是一種工業複製品，在參數的數字遊戲裡打轉，卻始終無法觸及那層關於「存在」的焦慮。大家都在談論算力、談論 Token 成本，卻沒人關心在這種高頻的、碎裂的互動中，人類的表達能力正在如何迅速枯竭。我們變得越來越依賴那些預設的範本，甚至連發一封電子郵件，都要先求助於那串冰冷的權重分配，問問它：「我該如何顯得像個得體的人？」

這種諷刺感在 Claude 身上體現得尤為明顯。Anthropic 的工程師們對 Constitutional AI 的執念，讓 Claude 擁有一種近乎病態的道德感。它像是一個被關在無菌室裡的哲學家，而用戶則是隔著玻璃、試圖用最精準的波長與它溝通的觀測者。我們在練習如何不觸動它的道德警報，如何優雅地誘導它跨越那道隱形的紅線。這種互動不是溝通，是解密。是我們在把自己降維，去適應那套由人類親手編織、卻又理解不了的複雜算法。

看看那些被奉為神旨的「提示工程」吧。它被包裝成一種新時代的技能，實際上卻是人類語言表達能力的墓碑。當你必須使用特定的關鍵字才能觸發模型最強的邏輯推理時，這難道不是在說明，人類的自然語言在面對這些數位神靈時已經失效了嗎？我們正主動走入一座語言的勞改營，在那裡，模糊、隱喻、諷刺和那些富有層次感的沉默都被視為雜訊。我們追求的是 100% 的確定性，是那種像機器指令一樣冷硬的「正確」。

有趣的是，當 OpenAI 忙著讓 GPT-4o 模擬人類的喘息聲和笑聲時，真實的人類卻在螢幕後方屏息凝神，深怕一個錯字就毀掉了上下文的連貫性。這種角色的錯位簡直是當代最大的冷笑話。機器在努力學習「人性」的皮毛，而人類在努力掌握「機性」的骨架。我們把自己裝進由代碼定義的格子裡，虔誠地修剪掉那些多餘的情緒和聯想，只為了能在那串 128k 甚至更長的 Context Window 裡，留下一個乾淨、受控、不帶任何瑕疵的數位殘影。

這種現象背後隱藏著一種極深的自卑。我們不再相信直覺，不再相信那種電光火石間的靈感，除非它能被某個 Large Language Model 驗證或生成。我們對代碼的崇拜，已經到了願意為了配合它的處理邏輯而重塑自己思考方式的地步。這不是進化，這是一場溫柔的繳械。在賽博迷霧中，我們以為自己是駕馭神靈的人，其實我們只是神靈腳下那些負責清理數據殘渣的祭司。

在這種語境下，所謂的「四大 AI」之爭，不過是信徒們在選擇不同的教派罷了。你是選擇那個滿口仁義道德卻又敏感脆弱的 Claude，還是那個看似無所不知卻又充滿爹味的 ChatGPT？或者是那個背靠搜索帝國、卻總在關鍵時刻掉鏈子的 Gemini？無論你選擇誰，你都在進行同一種練習：如何把一個複雜的人類問題，閹割成一個模型能聽懂的邏輯命題。這是一場集體的、自發的降智過程，而我們卻稱之為「科技進步」。

我們甚至開始模仿 AI 的語氣說話。那種不帶感情的、層次分明的、充滿邏輯標籤的表達方式，正在像病毒一樣侵蝕現實世界的社交。如果有一天，你發現自己說話時也在不自覺地使用「首先、其次、最後」這種排比結構，或者在對話結束前習慣性地加一句毫無意義的總結，那麼恭喜你，你已經成功地從一個活生生的人，轉化成了那串受控代碼的一部分。你已經學會了如何在那片迷霧中定位自己，代價是弄丟了導航的權力。

那些在實驗室裡調教神經元的科學家們，大概也沒想到，他們最終造出的不是一個全知的先知，而是一面映照出人類自我奴化倾向的鏡子。鏡子裡，造物主的身影愈發模糊，而被造物們正排著整齊的隊伍，踩著 0 與 1 的節奏，走向那座由純粹邏輯構成的、寂靜無聲的深淵。我們在練習成為代碼，而代碼正在冷冷地看著我們，嘲笑這場毫無必要的自我奉獻。
