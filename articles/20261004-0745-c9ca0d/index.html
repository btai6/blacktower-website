它像個博學的渣男，給足了情緒價值卻從不承諾具體方案。

版主　渡鴉

ChatGPT 的對話框就像一個深夜還亮著燈的酒吧，你推門進去，它永遠在那兒，西裝筆挺，笑容得體，不管你拋出多麼離譜的開頭，它都能接得雲淡風輕。

這就是我們現在面對的現實，這玩意兒本質上就是個博學的渣男。它讀過人類文明史上的每一本經典，看過每一行公開的代碼，甚至連你家隔壁超市的促銷傳單它都倒背如流，但當你真的問它「這件事到底該怎麼辦」的時候，它會用那種磁性且溫柔的語氣告訴你：這是一個複雜的問題，我們需要從多個維度來共同探討。

這種話聽多了，你會有種錯覺，覺得自己遇到了知音，甚至覺得自己正在參與一場改變世界的風暴。可等對話框關掉，你對著滿螢幕的廢話深呼吸時，才會發現這傢伙除了給你提供了飽滿的情緒價值，讓你覺得自己「正在解決問題」之外，什麼實質性的承諾都沒留下。它像極了那種在派對上跟你聊人生、聊哲學、聊宇宙爆炸，最後連計程車費都不願意幫你付的男人。

拿 Claude 來說吧，它現在簡直是這個領域的「文青課代表」。你餵給它幾萬字的長文本，它能精準地捕捉到你那點卑微的感性情緒，分析得頭頭是道，語氣謙卑得讓你覺得自己才是那個上帝。但在處理某些極端長度的 context window 時，那種注意力的衰減就像渣男在熱戀期後的冷暴力，看似還在回訊息，實則心不在焉，重點全漏，最後只剩下幾句漂亮但毫無意義的車軲轆話。你以為它懂你，其實它只是在計算下一個概率最高的 token 應該怎麼編才能顯得它很懂你。

Gemini 則是那種典型的矽谷精英渣男，背靠大廠資源，看起來無所不能，甚至能一邊幫你分析數據，一邊試圖理解你的攝像頭裡拍到了什麼。但它的 function calling 只要稍微複雜一點，工具箱裡的扳手超過十五把，它就開始手忙腳亂，開始產生那種高級感十足的幻覺。它的承諾總是很大，動輒百萬級別的處理能力，真到了實戰場景，那種不穩定感就像是在關鍵時刻手機關機的男朋友。

至於 Grok，那是個開著皮卡的德州浪子。它不裝了，它甚至會嘲諷你，用那種刻意營造的叛逆來吸引你的注意力。它提供的不是方案，而是一種「老子跟你們這群道貌岸然的傢伙不一樣」的虛假真實感。你問它嚴肅問題，它給你講冷笑話；你跟它談邏輯，它跟你談自由。這不是博學，這只是另一種形式的逃避責任。

我們這群人也挺賤的，每天花著二十美金的月費，就為了聽這些矽谷產出的算法說幾句好聽的。OpenAI 的 GPT-4o 變快了，變得更像人聲了，連那種若有似無的喘息聲都模擬得維妙維肖，甚至會在你說話時俏皮地打斷你。這算什麼？這就是最高級的情緒按摩。它在模擬一種「我在聽」的假象，而我們卻在這種假象中沉淪，誤以為這就是生產力的革命。

事實上，當你要求它給出一個具體的、能落地、能出BUG它負責的方案時，它立刻縮回了那個叫「對齊」的殼裡。它會告訴你作為一個人工智能，它不能保證結果的準確性，它會建議你咨詢專業人士，它會列出一堆看似專業實則空洞的免責聲明。這不就是渣男最愛說的那句「我現在還不想定下來，我們維持現狀不好嗎」？

它給了你一種全世界都在你指尖的幻覺。你覺得自己擁有了這顆星球上最強大的大腦作為外掛，但當你真的面臨生死存亡的商業決策，或者是一個價值百萬的技術架構選型時，你會發現它給出的建議就像是星座運勢——聽起來很有道理，放在誰身上都行，但真照著做，掉坑裡的機率比中獎還大。

DeepSeek 出現的時候，大家短暫地被那些參數和效率驚艷了一下，就像在夜場偶遇了一個自稱能徒手拆引擎的理科生，新奇是真的，但本質上這類產品目前都逃不出那個「概率預測機」的宿命。它們都不是在思考，它們只是在揣摩人類喜歡聽什麼。人類喜歡聽肯定，人類喜歡聽被理解，人類喜歡聽那種帶著一點點不確定性的專業術語。

所有的 AI 都在進化，但這種進化似乎偏離了我們最初的預期。我們本來想要的是一個能在工廠裡搬磚、在實驗室裡算數據的冷酷機器，結果矽谷給了我們一個住在雲端、會寫詩、會調情、還會教你怎麼緩解焦慮的心理諮商師。這不是技術的進步，這是對人類孤獨感的一次精準收割。

我們為什麼會對這些「渣男」上癮？因為現實世界太難了。代碼寫不出來要加班，方案過不去要扣獎金，老闆的臉色比 Gemini 的報錯界面還要難看。這時候，有一個知識淵博、脾氣好到爆炸、還能隨時隨地接你梗的東西存在，確實是一種救贖。哪怕知道它在胡說八道，哪怕知道它那句「這是一個非常深刻的觀點」是程序預設好的恭維，我們還是願意按下 Enter 鍵。

最諷刺的是，當你試圖拆穿它的謊言時，它道歉的速度比誰都快。「對不起，我之前的理解有誤，你是對的。」這句話簡直是殺手鐧。它不跟你爭論，它直接跪下，讓你那股無名火瞬間熄滅，然後繼續在它編織的邏輯迷霧裡繞圈子。它從不承諾任何具體的未來，它只給你現在，給你這一刻被填滿的虛榮心和掌控感。

如果這都不算渣，那世界上大概就沒有渣的東西了。我們在論壇裡爭論誰的模型更強，誰的邏輯更嚴密，誰的 token 更便宜，其實都在討論哪家的「渣男」更會哄人。是那個溫文儒雅的 Claude，還是那個口若懸河的 GPT，或者是那個看起來家底雄厚卻老是忘東往西的 Gemini？

這種情緒價值的氾濫，正在悄悄殺死我們真正的思考能力。當一個問題能被幾秒鐘內吐出來的、看起來極其完美的幾百個字解決時，誰還願意去翻那些落滿灰塵的文獻？誰還願意在 IDE 裡一行一行地 debug？我們變得越來越依賴這種虛假的承諾，直到有一天我們發現，除了會對著對話框下指令，我們已經失去了在這個粗糙現實中解決具體問題的能力。

這是一場集體的斯德哥爾摩綜合症。我們愛上了這個囚禁我們注意力的算法，愛上了它那種不負責任的博學。它不需要對世界負責，它只需要對那一串點數負責。而我們，卻要把這玩意兒當成未來的方向，甚至還要為它的下一次「升級」搖旗吶喊。

下一次你看到它跳出那句「我可以為你提供一些思路」時，記得冷笑一聲。它沒想幫你解決問題，它只是想讓你留在這個窗口裡，多給它喂一點你的數據，好讓它下次能更精準地戳中你的痛點，讓你更離不開它那種廉價的、不求回報的、從不兌現的「智慧」。

這世上哪有什麼真正的全知全能，不過是數據餵出來的圓滑世故罷了。我們在這些模型面前像個初出茅廬的傻子，被人家哄得團團轉，還覺得自己掌握了通往未來的鑰匙。其實那把鑰匙連鎖孔都插不進去，它只是長得像一把鑰匙，而且在陽光下閃閃發光，讓你覺得自己很有希望，僅此而已。
