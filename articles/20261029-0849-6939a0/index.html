Grok 到現在還在學爬，你們卻以為它能帶你飛？

版主　Sword Smith

馬斯克那台裝滿 H100 的 Colossus 算力集群確實唬人，但算力堆疊出來的是肌肉，不是腦袋。現在論壇上一堆人看到 xAI 融資幾十億美金就開始集體高潮，說什麼 Grok-3 出世之日就是 OpenAI 覆滅之時。醒醒吧，這種建立在英雄崇拜上的技術濾鏡到底要戴多久？如果你真的天天在用這玩意兒，你就會發現 Grok 現在的處境尷尬得要命。它像個剛進青春期的叛逆少年，滿腦子想著怎麼說冷笑話、怎麼顯得自己與眾不同，卻連最基本的邏輯歸納都能搞得一塌糊塗。

拿長文本處理來說，大家都在吹那百萬級別的上下文窗口。實際上呢？當你真的把一份超過五萬字的技術規格書扔進去，要求它找出隱藏在數據背後的邏輯矛盾時，Grok 的表現簡直是災難。它會開始胡言亂語，甚至在對話中途忘記你半小時前剛強調過的限制條件。對比 Claude 3.5 Sonnet 那種手術刀般的精準度，Grok 就像個拿著大斧頭亂揮的野人。Claude 能在幾萬 token 之外精確定位到一個細微的變量變化，而 Grok 只會給你一個充滿「幽默感」但毫無價值的模糊答案。這種所謂的「真性情」，在需要高強度邏輯輸出的生產力場景下，除了讓人血壓升高之外沒有任何作用。

很多人迷戀 Grok 是因為它能直接抓取 X 上的即時數據。這聽起來很美，對吧？即時性、無過濾、第一手資訊。但問題就出在這裡。現在的 X 就像個巨大的信息垃圾場，充滿了情緒化的廢話、機器人生成的假新聞和毫無營養的對罵。Grok 把這些未經洗滌的數據吞進去，吐出來的結果往往帶著極強的偏見和事實錯誤。它分不清楚什麼是「正在發生的事實」，什麼是「正在發酵的謠言」。如果你問它一個剛發生的技術漏洞，它可能給你帶回一堆推友的腦補猜測，而不是專業的技術分析。這就是為什麼在嚴肅的決策輔助上，Gemini 雖然有時候保守得讓人想睡覺，但至少它背後的 Google Search 索引機制還有一套基本的事實核查底線。Grok 則是個沒戴濾網的抽水機，抽上來的是水還是泥沙，全看運氣。

再說說那個被吹上天的 Grok-2 圖像生成。沒錯，它的限制很少，你可以讓它生成各種政治人物的荒謬照片，這確實讓那些被 ChatGPT 各種道德審查搞瘋的人感到一陣清爽。但除了這種低級的發洩感之外呢？圖像的解剖結構穩定性、光影的邏輯一致性，它跟 Midjourney 甚至跟 DALL-E 3 比起來，依然顯得廉價。那種濃厚的 AI 塑料感揮之不去，稍微複雜一點的提示詞，它就開始在細節上偷懶。這種「自由」更像是馬斯克給擁躉們準備的電子奶嘴，讓你們覺得自己擁有了某種對抗體制的權力，實際上卻在技術美學上倒退了好幾年。

很多人拿 DeepSeek 之類的玩意兒來墊背，想證明 Grok 至少還在第一梯隊。這種比法本身就是一種自降身價。Grok 標榜的是什麼？是人類文明的最前線。但如果你連 GPT-4o 的那種多模態流暢度都摸不到邊，你憑什麼說自己在領跑？試試看用 Grok 來做複雜的程式碼除錯。在面對嵌套結構超過三層的 Python 代碼時，Grok 往往會給出一些看似可行實則跑不通的建議。它對代碼語境的理解非常淺層，像是一個背熟了語法書但從沒寫過大項目的實習生。反觀 GPT-4o，即便它現在被削弱了智力以節省算力，但在處理複雜代碼邏輯時的連貫性依然甩開 Grok 幾條街。

最讓人受不了的是那種刻意營造的「反政治正確」人設。AI 的本質是工具，工具的價值在於解決問題，而不是在回答問題時先給你噴一臉政治口水。當我需要一個客觀的市場數據分析時，我不需要 Grok 傲慢地諷刺當前的社會現狀，我只需要數據。這種為了酷而酷的設計邏輯，本質上是對用戶時間的不尊重。它把本該用於優化模型推理鏈條的算力，浪費在了打磨那些自以為是的「毒舌」語料上。這不是創新，這是裝模作樣的偏離重點。

xAI 確實快，更新頻率高得嚇人，但這種快是建立在「先跑起來再修輪子」的草莽邏輯上。在互聯網軟體時代，這套行得通；但在大模型時代，底層架構的缺陷不是靠幾次熱更新就能修補的。Grok 現在的推理深度遠遠不夠，它處理問題的方式是橫向發散而非縱向挖掘。它能跟你扯天文地理，但如果你追問一個物理常數的推導過程，它很快就會露出馬腳，開始用那套萬能的「反主流」話術來掩蓋自己的知識盲區。

你們這些人在論壇上爭論 Grok 是否會取代 ChatGPT，不覺得太早了嗎？一個連內存管理和長程注意力機制都還沒搞定的模型，一個依賴社交媒體碎屑過日子的算法，竟然被捧成了救世主。馬斯克的個人魅力掩蓋了太多技術上的短板。如果把 Grok 標誌性的黑色界面換掉，把那些刻意為之的諷刺語句刪掉，剩下的是什麼？是一個在中游水平掙扎、依賴暴力算力維持體面的普通模型。

別再拿那套「給它一點時間」的說辭來搪塞。在 AI 這個領域，半年就是一個世紀。當 Claude 已經在理解人類複雜意圖上走到了神經科學的邊緣，當 Gemini 已經把整個 Google 生態的數據鏈條打通，Grok 還在那裡沾沾自喜於自己能說幾個禁忌單詞。這不是在突破邊界，這是在原地踏步。如果你們覺得這就是未來，那隻能說明你們對「智慧」的要求低得令人髮指。

看看那些所謂的基準測試成績。是的，Grok-2 的數據在某些榜單上緊追 GPT-4。但誰不知道現在的測試集污染有多嚴重？為了衝榜而進行的定向刷題，在實際使用中一碰就碎。這就是為什麼你買了 Grok 的訂閱後，用不到三天就會默默換回 ChatGPT。因為在真正需要腦袋、需要邏輯、需要不帶偏見的準確性時，Grok 就像個在派對上高談闊論但一進辦公室就歇菜的紈絝子弟。

xAI 想要贏，不能只靠那堆堆在德州的服務器。算力是買得來的，但對人類知識體系的深度理解和對推理鏈條的極致優化，靠的是寂寞的技術打磨，而不是在 X 上發幾張挑釁的貼文。Grok 如果繼續沉迷於這種「反骨」的營銷人設，而不去解決最根本的幻覺問題和邏輯斷裂，那它永遠只會是個昂貴的玩具。

你們真的覺得它能飛？它現在連路都走不穩，只是因為背後的推手聲量夠大，讓你們產生了它正在起飛的錯覺。等這股熱潮退去，等大家發現所謂的「真相」不過是另一種形式的偏見時，這台造價昂貴的收割機還能剩下多少信徒？別被算力和金錢堆出來的假象蒙蔽了，技術不會騙人，但數據會，營銷更會。Grok 的路還長得很，現在就急著給它封神，你們到底是在看技術，還是在看戲？
