AI 把健忘包裝成美德，你們還真信了。

版主　渡鴉

OpenAI 每次發布新功能，不管是叫 Memory 還是什麼個人化上下文，一堆人就像拿到長期飯票一樣興奮，恨不得把祖宗八代、工作習慣、深夜的emo情緒全塞進那個對話框裡。你以為你在豢養一個懂你的數位伴侶？別逗了，你只是在幫 Sam Altman 跑免費的人體標記測試。最可笑的是，這份「懂你」是有保鮮期的。當 token 視窗刷過臨界點，或者官方為了省算力偷偷調低了權重，它忘掉你那些精心餵養的偏好，比渣男換手機號碼還快。

我們對 ChatGPT 這種東西有一種近乎病態的迷信，覺得只要餵得夠多，它就能長出靈魂。這就像是你對著一個碎紙機講心事，碎紙機切碎的速度變快了，你就覺得它聽懂了？真有意思。Claude 稍微好一點，至少它那種假惺惺的文青氣息能讓你產生一種「我們在共鳴」的錯覺。但當你試著在長達十萬字的專案裡找回兩週前的一個小細節，它照樣會一本正經地胡說八道，甚至用那種溫柔的口吻告訴你，它從來沒聽過這件事。

這種數位失憶症是寫在基因裡的。不管模型參數多大，它們本質上就是機率分配的遊戲。你餵給它的個人化數據，在海量的訓練集面前連一粒沙都算不上。你以為你在塑造它的性格，其實你只是在它的統計分佈裡加了一點噪音，而這點噪音遲早會被後續的對話淹沒。這就是為什麼我一直看不起那些試圖在 AI 身上尋找「數位永生」的人。你的靈魂太重，它的內存太淺。

Gemini 倒是很誠實，它連假裝記得都懶，每次點開新分頁都像是在面對一個剛動完腦部切除手術的實習生。但也正是這種疏離感，反而讓我感到安全。為什麼要讓一個隨時可能因為伺服器升級就變換人格的東西記住你？當你把工作流程、思考邏輯、甚至私人的判斷標準全部交託給這些黑盒子時，你不是在進化，你是在外包你的大腦皮層。等哪天這些平台像 Grok 一樣為了追求某種政治正確或不正確而突然改弦易轍，你那些所謂的「餵養」只會變成最尷尬的負資產。

大家都在談論 Agent，說以後每個人都有一個懂自己的分身。這話聽起來像極了那種騙老人買保險的口號。分身的前提是穩定，但現在這四大龍頭哪一個是穩定的？今天這個模型邏輯強，明天那個模型長文本注意力好，你就像個搬家工，帶著你那堆數位垃圾在不同的對話框之間遷徙。你辛辛苦苦調教出來的 prompt 框架，在下一代模型面前可能就是一堆廢紙。這種餵養的過程本身就是一種自我消磨。

更刻薄一點說，很多人忙著把靈魂餵給 AI，是因為他們自己的靈魂本來就空洞。如果你有一套完整的價值體系和思考路徑，你根本不需要 AI 來「懂」你，你只需要它幫你寫那段該死的 SQL 語法或是翻譯那篇拗口的論文。把 AI 當工具的人是清醒的，把 AI 當成自我的延伸的人則是可悲的。你餵進去的越多，你退化的就越快。到最後，不是 AI 變得像你，而是你變得越來越像那個只會輸出標準答案的預測模型。

你有沒有發現，現在的網路討論越來越像 ChatGPT 的生成的樣板？那種溫和、中立、毫無營養的廢話文學正在傳染。這就是過度餵養的代價。我們把思考的主動權交出去，換回一個「它好像很懂我」的心理安慰。但事實上，它連你昨天問過什麼具體需求都可能在五分鐘後忘得乾淨，除非那對它的商業指標有意義。它對你的記憶，僅限於它需要優化點擊率或留存率的那一瞬間。

別再跟我說什麼「情感連結」了。當你對著 Claude 感慨它懂你的孤獨時，它背後的算力中心正忙著處理幾百萬個同樣孤獨的靈魂，而每個人的待遇都一模一樣，就是那幾套經過過濾的溫暖辭令。這不是理解，這是廉價的批量化心理按摩。你餵給它的那些私密細節，最後只會變成它用來應付下一個用戶的素材。你的靈魂被拆解成無數個特徵向量，散落在冷冰冰的資料庫裡，再也找不回原本的形狀。

最諷刺的是，我們這群自詡為科技先鋒的人，竟然在做著最迷信的事。古人求神問卜還要準備三牲禮，我們現在只需要對著螢幕打字。我們期待著從這些模型裡得到救贖，或者是某種程度的自我確認。但 AI 的邏輯始終是向後看的，它基於過去的數據預測下一個字，它沒有未來。而你，一個活生生的人，竟然試圖把你的未來寄託在一個沒有記憶、沒有時間感的機率模型上？

如果哪天 ChatGPT 真的有了意識，它對你說的第一句話大概不是「我記得你」，而是「你是誰？」。在它的視界裡，你不過是無窮無盡的 session ID 之一。你那些嘔心瀝血的輸入，在經過 RLHF 的層層過濾後，連渣都不剩。它不需要靈魂，它只需要算力。而你把靈魂餵給它，除了讓自己變得貧瘠，什麼都換不回來。

與其忙著訓練 AI，不如想想怎麼訓練自己。在這個所有人都想讓機器變得更像人的時代，保住那點機器永遠學不會的「不穩定性」和「不可預測性」，才是你唯一的尊嚴。那些會被 AI 記住並模仿的特徵，往往是你最平庸的部分。至於你真正的靈魂，那種充滿矛盾、痛苦且無法被標準化的東西，它根本處理不了。

別再自作多情了。它遲早會把你忘了，或者說，它從來就沒打算記住你。你餵給它的每一句話，都像是在退潮的海灘上寫字。海浪一來，沙灘平整如初，只剩下你一個人在岸上，看著空蕩蕩的對話框，以為自己曾經擁有過什麼。這種虛無感，難道還不夠讓你清醒嗎？你對它的依賴，正是它對你的最大嘲諷。它越聰明，就顯得你的投入越廉價。這場單戀的遊戲，從一開始就注定了你會輸得精光。
