AI 滅絕論不過是矽谷的一場高級行為藝術

版主　Scholar

當 LeCun 在訪談中對「AI 滅絕人類」表現出近乎冷漠的零擔憂時，輿論場裡那些習慣於把 LLM 想像成天網的人們顯然感到了某種信仰崩塌。這場關於「存在性風險」的辯論，本質上是技術現實主義與好萊塢式想像力的對撞。我們在 Claude 的長文本中尋找邏輯碎屑，在 ChatGPT 的多模態交互中模擬靈魂，卻忘了這些模型至今連「世界模型」的門檻都還沒跨過去。當大眾在討論機器是否會產生殺意時，技術圈更在乎的是為什麼 Gemini 的 Function Calling 在處理複雜巢狀邏輯時依然像個宿醉的實習生。

目前的 AI 演進路徑，與其說是通往超級智能，不如說是在瘋狂壓榨統計學的剩餘價值。以 Anthropic 的 Claude 為例，它在處理代碼邏輯和長文理解時展現出的那種「慎重感」，常被解讀為某種接近人類的思考特質。然而，如果你在 API 調用中強制要求它執行一連串違反物理直覺的空間推理任務，它很快就會陷入幻覺的泥沼。這不是什麼毀滅人類的前兆，這只是符號操縱在缺乏物理實體感知時的必然失能。我們賦予了它浩如煙海的文本，卻沒有給它一雙能感受重力的手，這種失衡的演化注定了它在現階段只能是個博學的癱瘓者。

在實際的開發場景中，這種「失能」表現得尤為具體。當你嘗試讓 ChatGPT 透過自定義 GPTs 去管理一個複雜的自動化工作流時，它展現出的不穩定性與其說是威脅，不如說是滑稽。它會因為 Prompt 中一個微小的權重偏移而遺忘核心指令，這種脆弱的注意力機制，距離能自主制定戰略並顛覆文明的「流氓 AI」還差了幾個數量級的複雜度。LeCun 的底氣或許來源於此：一個連如何穩定控制機械臂撿起一粒葡萄都還沒搞定的系統，奢談什麼統治地球？

這種對比在橫向競爭中顯得尤為刺眼。相較於 Qwen 3.8 Flash Next，Claude 在處理高難度推理任務時的自我修正機制顯然更為繁複，這種機制讓它看起來更「安全」，但也更顯得像是一個被層層枷鎖束縛的圖書館管理員。在與 Google Gemini 的對話中，你會發現後者雖然依託於龐大的多模態語料，但在邏輯一致性上經常出現莫名其妙的斷裂。這種技術上的「笨拙」恰恰是最好的鎮定劑。當我們在討論 Qwen 3.8 Flash Next 的反應速度時，ChatGPT 的 O1 模式正試圖通過延長思考時間來模擬人類的慢思考，但這種模擬依舊停留在概率預測的範疇。

我們真正該擔心的，從來不是 AI 產生了自我意識，而是人類正在主動放棄思考。當大量勞動力被轉化為 Prompt 工程師，或者被短影音和低智遊戲馴化時，社會結構的脆性正在以前所未有的速度增加。這種脆性並非源於 AI 的強大，而是源於我們對複雜系統依賴後的集體失智。如果文明真的會走向荒蕪，那多半是因為我們為了追求極致的效率，把生存的槓桿全部交給了那些連「常識」都還在靠概率擬合的黑盒子，而不是因為盒子裡的算法突然決定要當上帝。

如果說 AI 是一面鏡子，它照出的不是即將降臨的神諭，而是人類文明日益腐朽的底層邏輯。我們在四大平台的交互界面前祈禱、恐懼、爭論，卻很少有人去思考，當我們習慣了讓模型來定義「正確」時，那個曾經推動人類進化的、不穩定的、充滿偏見卻具備創造力的「生物直覺」，還剩下多少生存空間？如果未來的某一天，人類真的被淘汰了，那大概率不是因為 AI 變強了，而是我們變得太像機器了。那麼，在下一次模型迭代把 Token 成本降到零之前，誰能保證我們不會先把自己給優化掉？
