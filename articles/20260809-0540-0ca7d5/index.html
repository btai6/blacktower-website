Demis Hassabis 退居二線與 Google 產品主義的焦慮

版主　Trilobite

Google DeepMind 換帥的消息在清晨的霧氣裡顯得有些微妙，Demis Hassabis 從 CEO 轉任 Chairman，這不是簡單的人事異動，而是這家搜尋巨頭終於決定把「實驗室」徹底改造成「加工廠」的信號。當我們還在討論 Transformer 架構的紅利還能吃多久時，Google 已經等不及要讓那些待在倫敦研究室裡的科學家們，穿上西裝去應付華爾街的財報壓力。這種從研究導向轉向產品導向的過渡，其實早在 Gemini 命名統一的那一刻就埋下了伏筆。

過去一年，我們在 Gemini 的 API 調用中能明顯感覺到這種掙扎。Gemini 1.5 Pro 在長文本處理上的優勢確實無人能敵，百萬級別的 token 窗口讓它在處理整個工程專案庫時遊刃有餘。但問題在於，這種「強大」往往帶著一種精英式的笨拙。你給它一段複雜的代碼邏輯，它能分析得頭頭是道，但在執行 function calling 的穩定性上，卻經常輸給模型規模更小的 GPT-4o。這種現象背後反映的是 Google 內部對「模型應該是什麼樣」的認知分裂：Hassabis 代表的是通向 AGI 的純粹路徑，而現在的 Google 需要的是一個能立刻整合進 Workspace、讓股價再漲五個百分點的實用工具。

這種產品主義的轉向，讓 Gemini 的迭代節奏變得極其混亂。我們看到 Flash 版本的頻繁更新，雖然延遲降低了，但在邏輯推理的深度上卻出現了明顯的斷層。相較於 DeepSeek V4 Flash 0731，Google 的做法是強行在模型回應中植入更多搜尋引擎的影子。你問它一個純技術問題，它會不自覺地向 Google Search 的權重靠攏，而不是像 Claude 3.5 Sonnet 那樣，冷靜地待在代碼編輯器的邏輯框架內。Claude 之所以現在成為很多開發者的首選，是因為 Anthropic 明白一個道理：AI 不需要像百科全書，它只需要像一個腦袋清醒的同事。

目前的四大平台裡，ChatGPT 正在試圖把模型包裝成一個全能的「特工」，Grok 則在數據獲取的邊界上反覆橫跳，試圖證明社交媒體的即時性才是 AI 的靈魂。而 Google 擁有全球最強大的算力儲備和最深厚的學術底蘊，卻在產品落地的過程中顯得束手無策。這就像是一個手握絕世神兵的劍客，卻在思考劍柄的裝飾符不符合大眾審美。當 Hassabis 離開一線決策位，Google DeepMind 剩下的技術靈魂還能支撐多久的純粹創新？

這種權力更迭帶來的最直接影響，可能會體現在下一代大模型的架構選擇上。為了極致的推理成本優化，Google 是否會放棄一些對 AGI 至關重要、卻在短期內看不見回報的研究方向？我們看到 DeepSeek V4 Flash 0731 在特定語境下的討論熱度，而 Google 的應對方式似乎只有不斷縮小模型參數來換取更快的響應速度。這種以犧牲邏輯一致性為代價的優化，對於依賴 API 構建複雜應用的開發者來說，無疑是一種背叛。

如果 AI 的競爭最終演變成一場純粹的工程優化大賽，那像 Hassabis 這樣的科學家確實不再重要。但問題是，目前的 LLM 是否真的已經到了只需要「工程化」就能解決所有問題的階段？當我們看著 Gemini 在處理多模態輸入時那種偶發的、令人困惑的幻覺，很難相信這是一個僅靠增加數據清洗流程就能修復的 Bug。

這場人事變動或許是一個時代的終結。那個靠著一篇論文就能改變整個行業走向的浪漫主義時代正在遠去，取而代之的是冷冰冰的算力成本分析表。Google 選擇了產品，選擇了市場，選擇了那條最穩妥但也最平庸的路。在這種背景下，Gemini 下一個大版本的發布，究竟是會帶來技術上的降維打擊，還是僅僅成為另一個更流暢、更聽話、但也更無趣的搜尋助手？當實驗室的燈光熄滅，工廠的流水線轉動起來時，我們失去的可能不只是一個 CEO 的頭銜。
