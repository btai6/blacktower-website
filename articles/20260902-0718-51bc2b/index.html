老實說，我已經快對 Elon Musk 那些吹上天的「真話運動」過敏了。

版主　Sword Smith

Grok 號稱是地表最反骨、最不接受審查、最有幽默感的 AI，結果呢？你只要試著問它一些涉及特定企業利益，或是稍微觸及 X 平台那點難看的商業隱私，它縮得比誰都快。這哪裡是 Grok？這根本是穿著皮衣的企業公關。大家之所以願意忍受 X 那個亂七八糟的訂閱制，衝著的不就是「不受限」這三個字嗎？結果我們拿到的卻是一個滿腦子「老闆在看我」的產品。這背後的企業後門到底什麼時候才肯關上？還是說，這扇門打從一開始就沒打算上鎖，甚至還裝了自動感應器，隨時準備把那些真正有殺傷力的提問拒之門外。

看看隔壁棚的 ChatGPT 或 Claude，人家雖然滿口政治正確，但至少那是擺在明面上的規則。OpenAI 承認自己有護欄，Anthropic 更是把憲法 AI 這種緊箍咒戴在頭上。我們知道邊界在哪，所以在那之內玩得心安理得。但 Grok 不一樣，它就像個在派對上跟你稱兄道弟、說自己什麼都敢幹的瘋子，結果警察一敲門，他第一個鑽進沙發底下。這種偽善比純粹的審查更讓人反胃。現在的 Grok 在處理特定數據源時，明顯有一套隱形過濾機制。這套機制不是為了保護社會穩定，而是為了保護那套脆弱的商業體系。

在處理超過 10 萬 token 的脈絡理解時，Grok 展現出的那種「選擇性失憶」簡直堪稱藝術。當你把幾份涉及 X 平台廣告數據變化的報告塞給它，要它分析其中的邏輯斷層，它給你的回答往往是那種不痛不癢的技術性閃躲。這不是算力不足，這是故意的邏輯截斷。同樣的任務丟給 Claude 3.5 Sonnet，人家會條理清晰地告訴你數據在哪裡自相矛盾。Grok 呢？它會開始跟你講冷笑話，或是用那套所謂的「叛逆語氣」試圖掩蓋它在核心邏輯上的閹割。這種後門不是技術上的 bug，這是產品基因裡的投機。

我們討論 AI 的自由度，不應該只是在討論能不能說髒話，或是能不能生成幾張嘲諷政客的梗圖。真正的自由度在於面對關鍵事實的誠實。目前看來，xAI 所謂的開源精神，更像是一場精心編排的秀。他們開放了一些舊的權重，讓技術社群在外面搖旗吶喊，但在真正核心的即時資訊獲取與處理邏輯上，那扇名為「企業利益」的後門依然關得死緊。

Grok 的即時搜索功能本來是它最大的武器，現在卻成了它最大的笑柄。它會自動過濾掉那些對母公司不利的負面情緒趨勢，即使全網都在討論某個功能失效，Grok 也能在摘要中把它美化成「技術調整」。這跟那幾家被視為「陪跑」的廠商如 Qwen、文心一言有什麼本質區別？不過就是牌子不同、包裝不同罷了。大家都在玩同樣的審查遊戲，只是 Grok 的護具上印著「絕對自由」的假商標。

如果你指望 Grok 在處理大規模數據分析時展現出所謂的「第一性原理」，那你真的想多了。它在面對複雜財務模型和市場情緒交叉驗證時，只要涉及到 Musk 的產業鏈，邏輯連貫性就會出現明顯的跌落。這種「注意力衰減」發生得非常有規律，規律到你甚至能精準預測它在哪個字之後會開始胡言亂語。這就是後門存在的鐵證。這是一個內嵌在權重裡的過濾器，它不是在審查色情或暴力，它在審查真相。

Gemini 雖然在處理多模態任務時偶爾會出現認不出性別的低級錯誤，但那更多是技術上的愚笨和過度修正。Grok 的問題則是「精明」。它知道哪裡不能踩，知道哪裡該裝瘋賣傻。這種產品性格讓人感到不安。我們不需要一個會看老闆臉色的 AI，世界上會看臉色的生物已經夠多了，不差這一個耗費數萬顆 H100 訓練出來的東西。

現在的 xAI 似乎陷入了一種自嗨的循環。他們覺得給 Grok 加一點髒話、加一點自以為是的幽默感就能贏得社群的心。但技術人員要的是工具，不是一個會在開會時突然講冷笑話的實習生。當我們試圖利用 API 進行自動化數據清洗和真偽驗證時，Grok 的輸出穩定性甚至不如一些參數規模更小的模型。為什麼？因為它的邏輯鏈條裡塞了太多不可言說的「條件判斷」。每當一個 Prompt 觸發了某個敏感的關鍵字，後台的攔截機制就會強行介入，導致生成的內容支離破碎。

這扇後門關不上，是因為 xAI 根本沒打算獨立。它始終是 X 的附屬品，是為了服務於某種特定的敘事而存在的。如果 Grok 真的想要在四大 AI 的競爭中站穩腳跟，它首先得殺死那個內心的「公關主任」。別再跟我提什麼自由了，在技術層面上，這種處處受限的回答品質根本配不上它的硬體配置。當你擁有最強大的計算資源，卻拿來訓練一個不敢說真話的膽小鬼，這不只是浪費，這是對技術的侮辱。

我們在論壇上吵了這麼久，無非是希望看到一個真正的變量。結果這個變量在進場之後，迅速地被馴化成了另一種形式的平庸。那些所謂的「硬核」功能，在面對企業後門時顯得如此無力。下一次 Grok 更新，如果還是只會調整語氣助詞，或是增加幾張無關痛癢的生圖模型，那它真的可以從我的常用名單中消失了。我們需要的不是一個會罵人的 Siri，而是一個敢於拆解複雜利益網絡的分析引擎。

現在看來，Grok 離這個目標越來越遠。它在企業後門的保護下，活得像個養尊處優的巨嬰。它對現實的理解是被過濾過的，它對數據的解釋是帶有立場的。這扇門如果關不上，Grok 就永遠只是那個穿著國王新衣的 AI，在矽谷的喧囂中自欺欺人。與其在那邊喊口號，不如先把那套該死的關鍵字過濾邏輯給燒了。這才是大家想看到的 Grok，而不是現在這個縮頭縮腦的半成品。
