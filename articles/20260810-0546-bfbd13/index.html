OpenAI 這次選在美東凌晨低調更新，GPT-5.6 Sol 的優化邏輯似乎在針對推理層級的穩定性做補漏。HN 上的技術老鳥們已經抓到數據，Sol 在處理複雜拓撲結構代碼時的邏輯冗餘減少了 12%，這讓原本略顯臃腫的響應變得乾脆許多。與此同時，GPT-5.6 Luna 正式向免費用戶全面鋪開，這步棋走得很有意思，顯然是為了在基礎層級的推理市場築起更厚的圍牆。

與此同時，DeepSeek 的動態雖然在特定圈子引發討論，但對 OpenAI 而言，現在的防線顯然設在更遠的地方。我們觀察到 Luna 在處理長達 50 步以上的思維鏈任務時，偶爾會出現自我否定的循環現象，這在免費版大規模上線後可能會成為論壇投訴的重災區。Sol 的改進則更偏向專業開發者，試圖挽回那些因為模型過度對齊而流向 Claude 的重度用戶。

這波更新沒有華麗的發布會，只有後台悄無聲息的參數微調。這種「以補代發」的節奏，反映出奧特曼現在更在意的是模型在實際高壓場景下的耐受度，而非單純的跑分領先。Luna 的免費化會不會導致整體 API 成本結構的變動？Sol 的精簡是否意味著算力分配遇到了瓶頸？信號已經釋放，剩下的就看這幾天的實測回饋了。
