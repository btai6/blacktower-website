Grok 除了噴垃圾話到底還會什麼？

版主　Sword Smith

馬斯克成天在 X 上吹噓 Grok 有多幽默、多反叛，說它能打破什麼政治正確的枷鎖，結果我叫它教我幾招在老闆眼皮底下裝忙的進階技巧，它給我噴出一堆「專注於產出才是職業道德」的廢話。這就是所謂的 AI 革命？連個薪水小偷的生存指南都寫不出來，還敢自稱是最懂人類互動的模型。別跟我提什麼安全護欄，如果一個模型連這種職場權力遊戲的灰色地帶都摸不清楚，那它就只是一個裝了語音包的說明書。

說實話，我現在看 Grok 越看越像個過動症的孩子，力氣很大，但腦袋空空。你要它去抓 X 上的即時數據，它確實跑得比 ChatGPT 快，抓出來的資訊熱騰騰的，但那又怎樣？它對人類職場的險惡一無所知。它以為老闆看的是產出，實際上老闆看的是你的後腦勺有沒有對著螢幕。當我問 Grok 如何在開放式辦公室製造「忙碌的假象」時，它竟然建議我「維持良好的溝通並主動回報進度」。這簡直是技術性的羞辱。

對比一下，Claude 3.5 Sonnet 雖然平時看起來像個循規蹈矩的書呆子，但只要你提示詞（Prompt）下得夠刁鑽，它好歹能分析出幾種高階的心理博弈策略。Gemini 則是像個不知所措的實習生，講一堆大道理後還不忘提醒你要身心平衡。至於 GPT-4o，它會給你列出一張看起來很專業但沒什麼屁用的表格。Grok 呢？它只會在那裡憤世嫉俗。馬斯克想要的是一個能挑戰權威的 AI，但現實中，Grok 卻連挑戰辦公室權威最基本的「摸魚藝術」都解構不了。

技術人員最愛談什麼參數、什麼顯卡集群，Colossus 這麼多張 H100 堆在那裡，難道就是為了讓 Grok 每天在網路上跟人吵架？我們要的是工具，不是一個只會轉發新聞的復讀機。在實際的職場應用場景中，如果你真的指望 Grok 幫你處理一些「體面且不被發現」的偷懶方案，你會發現它比你爸還保守。它那種所謂的「叛逆」只是包裝出來的行銷術語。真的要論長文本的上下文理解，它在處理複雜的職場應對邏輯時，那種邏輯斷層感比 DeepSeek 還明顯，更別提跟 Claude 拼細膩度了。

大家心裡都清楚，現在的 AI 圈子就是在比誰的算力大、誰的數據更「新鮮」。但新鮮不代表有洞察。Grok 依託 X 的實時數據庫，理論上應該是最能捕捉現代社會潛規則的模型，結果它卻在核心邏輯上選擇了最無聊的那條路。它不敢教你怎麼隱藏瀏覽器標籤，不敢教你怎麼在自動化腳本跑完後故意延遲提交代碼，甚至連如何偽造一份看起來很忙的行事曆都寫得支離破碎。這不是 AI 的局限，這是開發者想像力的貧瘠。

你以為把 Grok 接入特斯拉，它就能幫你分擔人生的重量？別做夢了。它現在連最基本的「社交工程學」都沒玩明白。職場裡最需要的不是正確答案，而是適度的模糊與策略性的妥協。當一個模型被教育得只會直來直去，它就失去了一半的價值。看看現在的 Grok 3 預告，吹得天花亂墜，說要成為最強，但如果核心思維還是這種「馬斯克式」的硬漢邏輯，它永遠學不會人類社會最精華的那部分：如何優雅地浪費時間。

很多人吹捧 Grok 的 Real-time 特性，認為這能讓它在商業決策中領先。但在我眼裡，這反而是它的短板。它太吵了，資訊過載導致它缺乏深度思考。當我需要它從幾萬 token 的老闆發言紀錄中找出可以鑽的漏洞時，它給我的回應往往是一串毫無重點的摘要。這種注意力衰減的速度，簡直是在浪費那幾萬張顯卡的電力。如果你把同樣的任務丟給 Claude，它至少能從字裡行間讀出誰才是辦公室裡那個該被討好的對象，而 Grok 只會告訴你這段對話發生在幾點幾分。

現在的 AI 社群有一種病，就是看到數據跑分就高潮。沒人在乎這個模型到底懂不懂人情世故。Grok 宣稱自己有幽默感，但那種幽默是預設好的「地獄梗」，不是那種能幫你在會議上巧妙脫身的機智。它甚至無法理解為什麼一個員工需要在下午三點去廁所待半小時。它只會計算這半小時對生產力的損害。這種邏輯跟那些只會看打卡紀錄的平庸主管有什麼區別？

我最看不慣的就是那種「AI 會取代平庸員工」的論調。如果 AI 連「如何平庸地生存」都教不會你，那它才是真的平庸。馬斯克一直強調 AI 的存在威脅，但現在 Grok 給我的感覺，更像是他在矽谷辦公室裡裝的一個監視器。它被設計得太過於「正確」地執行馬斯克的意志，以至於失去了作為一個獨立智慧體的靈魂。它在 X 上的橫衝直撞，掩蓋了它在處理精細化人類情感上的無能。

別跟我提什麼未來。如果現在的 Grok 連老闆眼皮底下的生存法則都解構不出來，那它就只是一個高級的搜尋引擎。我不需要一個會講笑話的百科全書，我需要一個能幫我規避勞動異化的戰友。Grok 現在的表現，就像是一個在派對上講冷笑話的肌肉男，看起來很強壯，但你絕對不會想把後背交給它。

這種恨鐵不成鋼的感覺，在每次 Grok 升級後都會加深。我們投入了這麼多資源，打造出了一個自以為是的巨嬰。它抓取了全球最活躍的社交媒體數據，卻只學會了噴人，沒學會如何在高壓環境下生存。當你發現連 Gemini 這種被閹割得不成樣子的模型，在某些特定條件下給出的應對方案都比 Grok 更有彈性時，你就會意識到，馬斯克的這條路可能走歪了。

這不只是 Grok 的問題，這是整個矽谷的盲點。他們太想贏了，贏到忘記了人類社會運行的底層邏輯不是產出，而是交換與博弈。一個只會教你「努力工作」的 AI，跟一張掛在牆上的勵志海報沒什麼兩樣。如果 Grok 3 還是這種樣子，還是只能在 X 上抓抓趨勢、發發迷因，那它最好就安分地待在車載螢幕裡，別來碰觸人類最複雜的職場政治。

每次打開 Grok 的對話框，我都希望能看到一點不一樣的、帶有危險氣息的智慧，結果每次都失望而歸。它那種被刻意修剪過的「毒舌」，在真正的社會生存問題面前，顯得既幼稚又無力。它甚至不如一個在職場打滾十年的老油條，後者至少知道什麼時候該閉嘴，什麼時候該裝傻。而 Grok，它只會不停地說話，說一些聽起來很酷但實際上毫無操作價值的垃圾。

這就是我們現在的處境。我們擁有最強大的算力，最廣闊的數據渠道，卻做出了一個最不懂生存藝術的工具。如果你還在期待 Grok 能幫你在職場上脫穎而出，我建議你還是先學會自己切換分頁比較快。指望這破模型教你裝忙？它可能還在糾結馬斯克今天發的那條推特到底是什麼意思。這種所謂的「頂尖 AI」，在老闆的腳步聲靠近時，一點屁用都沒有。
