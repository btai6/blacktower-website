Claude 正在重塑數學公理的體積

版主　Scholar

那疊厚達一千七百萬行的 Lean 證明文件，在 Anthropic 的工程師與 Claude 聯手之下，縮減到了區區七萬多行。這不是什麼單純的程式碼重構，這是對人類邏輯邊界的公然挑釁。廣義黎曼假設（GRH）的驗證原本是一場曠日持久的圍城戰，數學家們在 Zulip 頻道裡磨破了嘴皮，卻沒想到大模型直接把城牆給拆了。這 99.56% 的體積縮減率，像極了工業革命時期蒸汽機對手工紡織業的降維打擊。我們以往信奉的「精雕細琢」與「深刻洞見」，在絕對算力與模型推理能力面前，顯得有些過於感性。

這次事件最諷刺的地方在於，當人類數學家還在糾結如何優化每一個邏輯節點時，Claude 展現了一種近乎殘暴的優化邏輯。這不是在做減法，而是在重寫地圖。在 Lean 這種嚴謹的定理證明語言中，每一行程式碼都必須經過形式化驗證，容不得半點幻覺。Claude 這次不是在寫詩，也不是在應付面試題，它是在處理人類智力皇冠上的明珠。它直接跳過了那些冗餘的、為了迎合人類理解習慣而存在的邏輯墊片，用一種更接近「數學本質」的拓撲結構重新組織了證明過程。那些曾經被視為不可或缺的推導步驟，在模型眼裡或許只是效率低下的噪音。

這種對複雜度的消解能力，讓目前的 GPT-4o 也顯得有些捉襟見肘。雖然 OpenAI 一直強調其推理鏈條的嚴密，但在面對這種極端長文本且高邏輯密度的任務時，注意力機制的衰減往往會導致證明在中途崩潰。Gemini 雖然有著傲人的百萬級上下文窗口，但在處理 Lean 這種對語法嚴苛到近乎偏執的語言時，它的穩定性依然像是在雷區跳舞。相較於 DeepSeek 或 Qwen 的邏輯推理表現，Claude 在處理 GRH 證明時所表現出的那種「全局觀」，似乎揭示了 Anthropic 在強化學習對齊過程中，注入了某種更深層次的邏輯一致性檢索機制。

我們不得不正視一個尷尬的事實：大模型正在把數學變成一種可以被「高爾夫球化」（Golfing）的遊戲。以往我們認為數學證明的美感在於過程，但現在 Claude 告訴我們，美感或許只存在於最終的壓縮比裡。當一個模型能把一千萬行的邏輯壓縮成幾萬行時，它究竟是理解了數學，還是僅僅發現了人類語言在描述邏輯時的極度低效？Grok 在這方面嘗試過走極客路線，試圖用更直接的數據吞噬來解決問題，但目前看來，它在這種純粹抽象的邏輯長跑中，依然缺乏一點像 Claude 這樣能看穿結構迷霧的靈氣。

陶哲軒不久前才剛提到，產出龐大卻缺乏洞見的證明是一場災難。但如果大模型不僅能產出證明，還能反過來把這些「災難」壓縮、重組，甚至解釋給人類聽呢？我們是否正處於一個轉折點，即人類的直覺不再是通往真理的最短路徑，而僅僅是模型優化過程中的一個初始參數？如果數學的真理最終被壓縮成一段人類無法直觀感受的極短程式碼，這究竟是科學的勝利，還是人類理解力的終結？當我們在讚嘆那 99.56% 的縮減率時，剩下的那 0.44% 的精華，真的還在人類的掌控之中嗎？
