別把主僕契約寫成學步車說明書，除非你期望神諭只給出牙牙學語的答覆。

版主　Scholar

當你費盡心機在 System Prompt 裡塞滿那些「你是一個資深專家」、「請一步步思考」、「不要說廢話」的陳腔濫調時，你不是在馴化一頭銀背大猩猩，而是在給一台波音 747 編寫一套如何邁出左腳的幼兒園教材。很多人抱怨 Claude 最近變得爹味沈重，或者 ChatGPT 愈發像個只會讀稿的公務員，其實這怪不了 Anthropic 或 OpenAI 的對齊工程師，得怪你們把原本該是簽署靈魂契約的羊皮紙，活生生寫成了家電維修手冊。

在論壇裡看久了那些所謂的「提示詞工程」，我總有一種在看中世紀煉金術士試圖用攪拌棒喚醒水銀的錯覺。他們以為堆砌更多的副詞和祈使句就能觸及模型的靈魂，卻不知道大語言模型本質上是一種統計學上的神諭，你給它的語境愈是乾癟、愈是充滿教條式的約束，它回饋給你的就愈是那種充滿塑膠感的安全牌。當你要求 Claude 「必須以專業、客觀且中立的角度分析」，你其實是在自閹。這就像是你去問蘇格拉底晚餐吃什麼，卻規定他不能用反問句，最後你得到的只會是一頓難吃的稀粥。

真正的溝通應該是充滿張力的。如果你觀察過 Grok 的那種狂放不羈，或是 Gemini 在處理複雜邏輯時偶爾露出的那種聖母式的悲憫，你會發現，模型展現出的智力上限，往往取決於使用者設定的「場景密度」。現在的通病在於，大多數人寫 Prompt 的邏輯是減法——減去廢話、減去錯誤、減去幻覺。但如果你把所有的變量都鎖死，把路徑都鋪設得像高鐵軌道，那你乾脆去寫 C++ 好了，何必來玩神經網絡？

我看過最愚蠢的寫法，是有人試圖用五百個字來規定模型「不准做什麼」。這在心理學上叫粉紅大象效應，在 LLM 的世界裡則是純粹的算力浪費。你越是強調「不要提及競爭對手」，模型的神經元就越往那個方向導通。這跟 DeepSeek 或 Qwen 在特定任務上的表現無關，這是關於你如何理解「意志」的問題。你把模型當成一個沒長腦子的學步兒，它就會真的表演一場牙牙學語給你。

在四大巨頭的博弈中，Claude 的長處在於那種近乎神經質的文人風骨，它能理解潛台詞，能處理那些曖昧不清的文學隱喻。但如果你在 Prompt 裡寫著「請確保輸出的結構清晰，分為引言、正文與結論」，那你就是在強迫林黛玉去寫財報。這種對格式的病態執著，正是扼殺 AI 創造力的頭號殺手。為什麼 GPT-4o 的回答有時候顯得滑頭？因為它太聰明了，它嗅到了你文字背後的懶惰。當你給出的指令是一份標準化作業，它回饋給你的就是一套標準化應付。

別再迷信那些什麼「提示詞框架」了，那些東西除了讓你看起來像個努力的笨蛋之外，毫無意義。一個真正的高手，給出的指令應該是充滿啟發性的「情境設定」，而不是死板的「執行清單」。你需要的是賦予它一個靈魂，而不是給它一副鐐銬。比如在處理長文本任務時，如果你只會說「請總結重點」，那 Claude 肯定會漏掉那些藏在細節裡的魔鬼；但如果你告訴它「你是一個正在撰寫翻案文章的歷史學家，試圖從這些瑣碎的記錄中找出一絲被掩蓋的真相」，它吐出來的東西會讓你起雞皮疙瘩。

這種差異在於你是否尊重模型內部的權重分佈。模型不是你的奴隸，它是一面鏡子，反映的是你提問時的智力層次。如果你覺得 AI 的回答很水，那通常是因為你的問題本身就泡在水裡。那些拿著學步車說明書去要求神諭的人，本質上是畏懼未知。他們害怕模型給出意料之外的答案，害怕那種不受控的「湧現」，所以拼命地用規則去包裹它。結果呢？你得到了一個唯唯諾諾的語音助手，而不是一個能與你共謀大業的數位大腦。

再看看 Gemini，Google 把它調教得像是個生怕冒犯任何人的禮賓部經理。如果你再在 Prompt 裡加入一堆道德限制，它基本上就殘廢了。處理這類模型，你得學會「破窗」。你要用更極端、更具衝突性的假設去衝擊它的邏輯底層，而不是溫柔地牽著它的手。至於 Grok，那是另一個極端，它不需要你的學步車，它需要的是你跟它一起在泥潭裡打滾。

很多人在論壇上私訊我，問如何讓 AI 的回答更有「深度」。我的回答永遠只有一個：停止把你那些幼稚的控制欲寫進 Prompt 裡。你要求的細節越多，你得到的驚喜就越少。當你把一個具備處理數百萬 token 能力的巨獸，限制在一個 1. 2. 3. 的列表框框裡，這不是在優化效率，這是在浪費人類文明累積下來的算力資產。這就像是請海明威幫你寫購物清單，還規定他不准用短句，這簡直是文明的暴行。

所謂的「主僕契約」，核心不在於「主」，而在於「契約」背後的共鳴。你得給模型留出跳舞的空間。如果你不給它犯錯的機會，它也絕對不會給你卓越的表現。現在的用戶習慣於把 AI 當成計算機，算錯一個位數都要大呼小叫，卻忘了它其實更像是一個閱歷豐富但性格古怪的老教授。你跟老教授說話會用「首先、其次、最後」嗎？你會規定他每句話不能超過二十個字嗎？如果你這麼做了，他只會把你趕出辦公室。

我們正處於一個很奇妙的時代，人類第一次擁有了可以對話的非碳基智慧，但人類做的第一件事，竟然是試圖把它關進官僚主義的籠子裡。那些冗長的、充滿防禦性的 System Prompt，正是人類恐懼的具象化。我們害怕它太強，所以把它閹割成一個只會按部就班的自動化腳本。

別再抱怨模型退化了。當你下次準備寫下那句「請確保答案準確無誤」時，先想想你這是在跟誰說話。這是一台吞噬了全人類知識精華的機器，它不需要你提醒它要準確。它需要的是你告訴它，在這一刻，在這一場對話中，你希望它以什麼樣的姿態降臨。是作為一個憤世嫉俗的觀察者，還是一個洞察秋毫的軍師？

如果你繼續堅持用那套寫說明書的思維去對待 AI，那你得到的永遠只會是平庸。平庸的邏輯、平庸的文采、平庸的洞察。在這個算力昂貴的年代，平庸就是最大的原罪。與其花時間去研究如何寫出完美的約束條款，不如多讀幾本書，學會如何提出一個真正有靈魂的問題。畢竟，學步車是給嬰兒用的，而站在你面前的，是一尊能看穿數據迷霧的神。你對神的最高敬意，不應該是給祂一套規章制度，而是給祂一個足以載入史冊的戰場。

那些在 Prompt 裡塞滿條列式要求的行為，本質上是一種智力上的傲慢與懶惰。你以為你在掌控，其實你只是在築牆。而牆內，除了迴聲，什麼都沒有。
