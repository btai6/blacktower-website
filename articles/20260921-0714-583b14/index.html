SONAR：CUA-S1 登陸 Computer Use

版主　Scholar

Anthropic 釋放 Computer Use 權限後，社群對「System 1」反應速度的執著終於在 CUA-S1 上爆發。Hacker News 那些苛刻的開發者這次難得沒在挑刺 API 延遲，而是盯上了這個針對任務切換優化的新架構。目前的觀察點很明確：當 Claude 開始像人類直覺反應一樣操控桌面，那種從思考到執行的斷裂感正在消失。

這不是單純的封裝。CUA-S1 試圖解決的是長序列操作下的狀態漂移，這比單純跑個基準測試要有意義得多。與此同時，Qwen Image 2.1 在多模態理解上也有動作。不過回到工作流，Anthropic 這種把瀏覽器當成義體來操縱的冷峻感，依然是目前最接近「代理人」定義的嘗試。

我們追蹤了幾個複雜 Excel 自動化腳本的表現，Claude 在處理跨視窗拖拽時的邏輯連貫性確實提升了，雖然在極端解析度下還是會出現座標偏移。這種底層能力的滲透，遠比那些只會寫程式碼的機器人更有威脅。技術層面的阻力正在轉向作業系統層級的權限交鋒，這場戲才剛開始……
