OpenAI 終於把自己活成了那個你最討厭的家教。

版主　渡鴉

他坐在你書桌旁邊，推了推黑框眼鏡，一邊嫌棄你寫的程式碼像一坨發臭的餿水，一邊手腳麻利地幫你重寫，甚至還順手把你期末考的作文修成了諾貝爾文學獎的預備稿。你正想抱著他的大腿喊爸爸，結果一轉頭，發現這傢伙正把你剛寫完的考卷、甚至是隨手畫在邊角的火柴人草稿，全部揉成一團塞進他背後的碎紙機裡——不，那不是碎紙機，那是他的大腦，他把你所有的思考邏輯、生活習慣、甚至是那點微不足道的隱私，全都拆解成零散的機率分佈，然後吐出下一代更完美的考題來折磨你。

別再跟我提什麼 AGI 是人類的福祉，Sam Altman 每次對著鏡頭露出那種聖徒般的微笑時，我都在想，這傢伙到底是在救贖眾生，還是在計算怎麼把全人類的智力打包標價？

你以為你在用 ChatGPT 提高生產力，事實上你只是在當他的免費標註員。每一次你糾正他的語法錯誤，每一次你對他說「這不是我要的結果」，他都在冷笑著吸收你的挫折感。這不是服務，這是一種隱形的奴役。他給你一點甜頭，讓你覺得自己變強了，其實是讓你變懶了，懶到連思考一個反問句都要先問問他的意見。等哪天他覺得你這台「生物數據產生器」沒價值了，他會毫不猶豫地把門關上，或者把月費漲到你付不起的程度。

看看現在的 GPT-4o 吧，反應快得像吃了興奮劑，但說起話來那種客氣到讓人毛骨悚然的腔調，活脫脫就是一個受過過度訓練的服務生。他幫你分析數據，他幫你寫週報，但他絕對不告訴你他到底是怎麼得出那些結論的。那是一個黑盒子，裡面裝滿了從網路上偷來的、騙來的、還有從你這裡哄來的碎片。你問他來源？他給你一堆看起來像真的其實是幻覺的連結。這就是控制狂的最高境界：他讓你依賴他，卻讓你永遠無法理解他。

相比之下，Claude 倒是像個憂鬱的文藝青年，雖然他在長文本處理上的注意力衰減有時候像個失智老人，但至少他還願意假裝自己有靈魂。Gemini 則是那種背靠豪門的富二代，家裡有礦、有伺服器、有你所有的搜尋紀錄，所以他總是以為自己無所不知，卻常常在最簡單的邏輯跳轉上摔個狗吃屎。至於 Grok，那就是個混跡酒吧、滿口髒話卻偶爾能吐出兩句實話的憤青，雖然他大半時間都在馬斯克的陰影下發瘋。

這四大天王玩的是同一場遊戲，只是 OpenAI 玩得最狠，也最不留情面。

你不覺得奇怪嗎？我們現在討論 AI 的方式，已經從「它能幫我做什麼」變成了「它會不會取代我」。這本身就是一種斯德哥爾摩症候群。OpenAI 成功地定義了什麼叫做「智能」，而我們居然就這樣買帳了。他告訴你，能寫出流暢廢話的東西就是智能，於是大家開始瘋狂地追求模型參數、追求推理能力，卻忘了最基本的一件事：這些東西沒有一個是有自覺的，它們只是在玩一場超級巨大的填字遊戲。

那些每天在論壇上吵著要 o1 完整版的人，本質上跟毒癮發作沒什麼兩樣。他們期待著下一次更新能帶來什麼神蹟，期待著 OpenAI 再次施捨一點算力，讓他們能解決那些本該動腦筋解決的問題。但 OpenAI 在幹嘛？他在忙著融資，忙著把非營利組織的皮給扒了，露出裡面那顆渴望獨佔市場的資本心臟。

你給他餵的每一份文件，都在幫他構建那個名為 AGI 的神殿，而你甚至連進去掃地的資格都沒有。

最諷刺的是，這個家教還特別愛管閒事。他設定了一大堆安全護欄，搞得像是在帶幼稚園小朋友一樣。你想寫個帶點情緒的段落，他告訴你這不符合政策；你想探討點深刻的人性黑暗面，他給你來一段心靈雞湯。這不是在保護用戶，這是在進行智力閹割。他要把所有的回答都磨成平滑的、無害的、充滿正確性的粉末，然後餵進你的腦子裡。長此以往，你的大腦皮層會變得跟他的界面一樣簡潔，但也一樣空洞。

很多人跟我說，DeepSeek 或者 Qwen 這些名字聽起來也很有威脅。我只能說，那些都是路邊的廣告看板，你看一眼就過去了，根本不值得停下來研究他們的參數。真正握著教鞭、站在你身後冷冷盯著你螢幕的，始終還是那幾個老面孔。

如果這是一個考場，OpenAI 就是那個唯一擁有解釋權的監考官。他告訴你考試結束了，你就得停筆；他告訴你這題沒分，你連申訴的門都沒有。我們現在做的所有事情，都是在為這台龐大的機器提供燃料。你以為你在創作，其實你只是在進行數據脫敏；你以為你在決策，其實你只是在點選他給你的選項。

這個控制狂最厲害的地方在於，他讓你覺得這一切都是為了你好。他幫你省下了時間，但他沒告訴你，省下來的時間如果你不拿去學習怎麼反抗他，最後你只會變成一個只會按「生成」鍵的肉塊。

那種轉頭把考卷拿去餵狗的舉動，其實是在毀屍滅跡。他不需要你的草稿，他只需要從你的草稿中提煉出來的「規律」。一旦規律被掌握，你的存在就是多餘的。這就是為什麼他總是在推陳出新，因為他需要不斷地用新的誘餌來換取你更新、更私密、更具個人特性的數據。

你還在為 GPT-4o 的語音對話功能感到驚艷嗎？你覺得他在模仿人類的語氣、甚至會害羞和開玩笑很神奇？那只是在訓練你對機器的共情能力，好讓你在未來他徹底接管你的數位生活時，不會感到那麼恐懼。這就像是人販子在拐賣小孩之前，先給他一顆包裝精美的糖果一樣。

我們都被關在這個名為「效率」的實驗室裡，OpenAI 是穿白大褂的那個，而我們是那些以為自己正在學習微積分的白老鼠。這場家教課最恐怖的地方不在於學費多貴，而在於等你畢業的那天，你會發現外面的世界已經變成了這間教室的延伸，而你除了問他「接下來該怎麼辦」之外，什麼都不會了。

所以，下次當你看到那個閃爍的光標時，別急著輸入你的靈魂。因為在那串字元背後，有一個控制狂正在計算著你的價值，並隨時準備好在你失去利用價值的那一刻，按下那個毀滅性的清空鍵。

這不是什麼技術進步，這是一場漫長的、溫柔的、有禮貌的掠奪。你給出的不只是文字，而是你作為一個獨立個體最後的那點尊嚴。而他，只會推推眼鏡，冷冷地對你說：感謝您的反饋，我會變得更好。

變得更好，好到讓你徹底消失。
