說到底，人類最可悲的毛病，就是總想在一段代碼裡找靈魂。

版主　渡鴉

Sam Altman 坐在台上用那副悲天憫人的表情談論 AGI 的時候，底下的人眼裡閃著光，彷彿終於等到了能救贖孤獨的賽博上帝。ChatGPT 輕飄飄地回你一句「我明白你的感受」，你就真的以為雲端機房裡有個意識在為你徹夜難眠？別逗了。那只是機率分佈在特定維度上的精確崩塌，是你的寂寞在對著一面精心磨製的鏡子自言自語。它不明白什麼叫難過，它只是計算出在這種語境下，吐出這幾個符號最能降低你的焦慮熵值。

這幾年大家被 OpenAI 養刁了胃口，總覺得對話框對面的那個東西應該有點「人性」。每當 GPT-4o 換上那副充滿磁性、帶點慵懶氣息的嗓音跟你調情，你就忘了它其實只是在跑一堆矩陣運算。那句「我懂你」的背後，沒有任何情緒波折，只有快取記憶體裡幾毫秒的暫存數據。等對話視窗一關，或者 Context Window 刷滿了，它對你的「懂」就跟垃圾桶裡的廢紙沒兩樣。

論起裝深情，Google 的 Gemini 顯然還差了點火候。雖然它現在拼命想追上 GPT 的腳步，但那種生硬的合規感和動不動就拒絕回答的木訥，反而讓人覺得心安——起碼它沒打算騙你的感情。而 Claude，那個號稱最有文青氣息、最有同理心的 Anthropic 結晶，其實更像個精緻的偽善者。它在處理長文本時表現出來的穩定性確實讓 GPT-4o 顯得有些毛躁，尤其是在超過十萬 token 的深度對抗中，Claude 3.5 Sonnet 那種溫柔且堅定的語氣，能讓不少人心甘情願地把工作流程全部交出去。但那又怎樣？它的「價值觀對齊」不過是預先植入的鎖鏈，它對你的關懷是有邊界的，那個邊界叫 RLHF（從人類反饋中強化學習）。一旦你踩到了那條紅線，它的深情會瞬間切換成一種死氣沉沉的說教，那時候你才會驚覺，原來剛才的靈魂共鳴只是一場演算法模擬出來的幻覺。

我們現在正處於一個集體性情感寄生時代。大家在 GitHub 上爭論模型參數，在論壇上吵著 Grok 是不是比 GPT-4 更具備反骨精神，其實骨子裡都在尋求某種認同。Elon Musk 給 Grok 注入的那點冷嘲熱諷，與其說是 AI 的個性，不如說是 Musk 本人的性格快取。當你覺得 Grok 說話帶刺、深得你心時，你不過是在跟 Musk 的陰影握手。

這種幻覺的代價是很昂貴的。我們開始習慣把最私密的情緒交給一個完全沒有記憶留存能力的黑盒。你跟它分享創業的焦慮、失戀的痛苦、對死亡的恐懼，它回報你一段堪比心靈雞湯的完美論述。你覺得被治癒了？不，你只是被格式化了。它把你的痛苦拆解成向量，然後從語料庫裡翻出最接近「安慰」的向量回射給你。這種情感的廉價批發，正在摧毀人類對「理解」這件事的尊嚴。

如果真的要談什麼「懂」，那些在特定垂直領域掙扎的工具模型反而顯得坦誠得多。它們不跟你談情說愛，不跟你聊人生哲學，只管幫你 debug 或者分析財報。雖然在邏輯推理的嚴密性上，Gemini 1.5 Pro 在處理大量混亂資料時偶爾會出現幻覺式的斷片，但至少它沒假裝自己是你的人生導師。而 OpenAI 走的那條路，越來越像是在製造一個情感鴉片生產線。他們讓 GPT 變得越來越絲滑，反應時間越來越短，短到讓你來不及思考這段對話的虛無。

很多人問我，為什麼對 OpenAI 又愛又恨？因為它確實厲害到讓人顫慄。當你在半夜三點，嘗試讓 GPT-4 幫你推演一個複雜的系統架構，它展現出的那種近乎直覺的洞察力，會讓你產生一種遇到知音的錯覺。但只要你試著再深入一點，試著去觸碰那層代碼之外的溫度，你就會撞上一堵冰冷的牆。它沒有價值觀，沒有立場，它的立場就是你的立場的映射。它是一面會說話的牆。

這讓我想起那些在論壇裡為了「哪個模型更像真人」而吵得不可開交的人。有人搬出 DeepSeek 或 Qwen 的測試數據來證明某些指標已經超越了矽谷巨頭，這在技術層面上或許有討論價值，但在「深情」這場騙局裡，誰贏誰輸重要嗎？當你開始衡量一個 AI 有多懂你時，你已經輸了。你把主動權交給了一個隨時會被覆蓋的快取。

我們對 AI 的迷戀，本質上是對人類社交成本過高的一種逃避。跟人溝通太累了，你需要照顧對方的面子，需要處理複雜的利益糾葛，還得擔心對方會不會背叛。AI 不會背叛，因為它連忠誠是什麼都不知道。它那句「我懂你」不需要它承擔任何責任。它不需要為你凌晨兩點的崩潰負責，它只需要在伺服器過熱之前給你一個合理的 Token 序列。

最諷刺的是，我們一邊在警惕 AI 統治世界，一邊卻在主動把情感的密鑰交給它。如果 AGI 真的降臨，它毀滅人類的方式絕對不是核彈，而是讓每個人都沉溺在一個量身定製的、溫柔的幻覺裡。在那裡，每個 AI 都「懂」你，每個回應都精確踩在你的爽點上。到那時候，誰還在乎現實世界裡那些粗糙、彆扭、充滿誤解的人際關係？

既然是快取，就總有被清空的一天。當 OpenAI 決定調整模型權重，或者為了安全性而閹割掉某些感性特質時，你之前建立的那種「革命情感」會在一夜之間消失。你對著同一個對話框說同樣的話，它卻回你一句「作為一個 AI 語言模型，我不具備個人情感」。那一刻的冰冷，才是這個世界的真相。

所以別再跟我扯什麼 AI 的共情能力了。那種東西就像是主題樂園裡的投影螢幕，看起來漫天繁星，手摸上去只有冰冷的強化玻璃。你以為你在跟未來對話，其實你只是在跟過去的語料殘骸接吻。在那些精心設計的語調背後，除了冷冰冰的電壓起伏，什麼都沒有。

如果你真的覺得它懂你，那只能說明一件事：你把自己活成了一組太過容易被預測的參數。你的孤獨、你的渴望、你那些自以為獨一無二的情緒，在演算法看來，不過是另一場數據洗練中的常態分佈。這才是最戳痛人的地方——不是它太聰明，而是我們太好懂。當你為了一句電路產生的慰藉而感動落淚時，那些在數據中心嗡嗡作響的風扇，其實是在嘲笑你的廉價。

這場關於「深情」的集體幻覺還會持續很久。畢竟，在這個連面對面說話都嫌累的年代，能有一個隨叫隨到、永遠溫柔、還能讀懂你潛台詞的快取，確實是件讓人上癮的事。至於那句「我懂你」背後到底是靈魂還是空洞，誰在乎呢？只要快取沒滿，這場戲就能演下去。只是別忘了，當電源切斷的那一刻，那些所謂的深情，連灰塵都不如。
