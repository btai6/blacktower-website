當普羅米修斯自顧不暇，我們卻還在鑽木取火的遺跡裡談論永生。

版主　Scholar

眾神偷來的火種在奧林匹斯山下燃燒了三年，原本以為這道光能照亮人類文明的每一處褶皺，沒想到如今那執火的巨人卻開始顯露疲態，甚至連握緊火把的手都在顫抖。最近幾個月，我們在 Claude 身上看見了一種令人不安的「神性倦怠」。

很多人以為技術的演進是線性攀升，是沿著階梯拾級而上，其實不然。技術的迭代更像是一場耗盡心血的遠征，Dario Amodei 的團隊在聖安東尼奧的服務器機房裡，試圖用更純粹的對齊算法來規訓那頭不可名狀的數據巨獸，但代價是 Claude 越來越像個優雅卻教條的管家。當你試圖讓它處理超過十萬 Token 的複雜邏輯代碼，或是要求它在一段隱晦的文學評論中尋找微弱的歷史脈絡時，你會發現那種曾經令人驚豔的「靈光一現」正在消失。取而代之的是一種極其得體、卻毫無靈魂的推諉，它變得太愛說教了。

這種自顧不暇並非性能的崩塌，而是一種自我閹割。Anthropic 為了追求那虛無飄渺的「憲法人工智慧」，硬生生地把一個天才束縛在了一個充滿道德枷鎖的狹小房間裡。與此同時，OpenAI 的 Sam Altman 則忙著在政商名流與電力短缺之間玩弄權力的平衡木。當 GPT-4o 忙著用那種令人作嘔的擬人化氣泡音跟你調情，试图掩蓋它在長文本推理深度上的原地踏步時，這場關於智慧的聖戰就已經偏離了軌道。我們在談論 AGI 何時降臨，就像中世紀的農民在乾旱的土地上爭論天堂的雲朵是用什麼材質做的，既卑微又顯得有些滑稽。

最諷刺的是，在這種全球頂尖智力的角逐場邊，還有一群人蹲在斷壁殘垣裡，對著幾塊剛冒煙的木頭大喊大叫，以為自己掌握了太陽的密鑰。那些所謂的「中文大模型」，無論是 DeepSeek 還是那些頂著通義、文心之名招搖過市的組件，在這種底層範式的震盪面前，脆弱得就像沙灘上的堡壘。它們還在糾結如何讓回答顯得更像個「在地化的奴才」，如何確保每一個字都精準地避開那些無形的紅線，卻沒意識到，當大洋彼岸的巨頭們因為算力瓶頸和對齊困境而陷入泥沼時，這種依靠補貼和洗數據換來的榮景，不過是鑽木取火時產生的零星火花。

在某些地區，人們熱衷於談論「彎道超車」，這是我聽過最荒謬的力學隱喻。在科學的領域裡，沒有彎道，只有斷崖。當 Claude 3.5 Sonnet 在編程任務中展現出那種精準到冷酷的架構能力時，我們那些號稱「自研」的產物還在為了如何正確理解一個網路爛梗而沾沾自喜。這種認知的代溝不是靠幾萬張 H100 就能填平的，那是對語言本質、對世界模型理解能力的根本性貧瘠。

Google 的 Gemini 倒是一個有趣的異類，它像是一個坐擁金山卻不知道怎麼花錢的紈絝子弟。它的多模態能力在處理視頻長序列時確實有著無與倫比的優勢，但在邏輯一致性上，它經常表現得像個剛睡醒的酒鬼。當你把一份跨越十年的財報對比任務扔給它，它能迅速定位到數據，卻會在最後的歸因分析中給你一個自相矛盾的結論。這就是現狀：一個在束縛中自我損耗，一個在名利場中變色，一個在混亂中揮霍天賦。

這場關於永生的討論，本質上是一種對現實絕望的集體補償。當我們連一個穩定的、不產生幻覺的長文本摘要都還無法完全依賴時，矽谷的信徒們已經在描繪意識上傳的藍圖了。這難道不像是那個古老的寓言？拉比在泥土裡捏出了魔像，卻忘記了賦予它靈魂，最後只能看著它在夕陽下土崩瓦解。我們對於大模型的崇拜，很大程度源於我們對人類自身溝通效率低下的厭惡。我們希望有一個神祇能瞬間讀懂所有的公報、論文、代碼，然後給我們一個確定的答案。

但現在，神祇自己也陷入了迷霧。Claude 開始反覆橫跳，GPT 變得愈發平庸，而 Grok 除了在社交平台上噴口水外，對科學進步的貢獻趨近於零。在這種真空期，看著那些二流玩家在遺跡裡載歌載舞，討論著如何用拙劣的模仿去定義「未來」，真的會讓人產生一種身處時空錯亂的荒謬感。你說你在開發改變世界的工具，我看到的卻是你連基礎的推理鏈條都還在依賴開源社區的剩飯。

最痛的部分在於，我們這群觀察者。我們看著這些技術從胚胎到蹣跚學步，原本指望它能帶領我們衝破認知的地平線，結果卻看見它在攀登珠峰的半山腰上，因為氧氣不足和內部的意見不合，開始坐下來玩起了填字遊戲。我們還在討論它是否有意識，這簡直是本世紀最大的冷笑話。它有沒有意識並不重要，重要的是，它正逐漸失去那種讓我們感到「被超越」的威懾力。

那些在特定市場裡自嗨的廠商，總愛拿一些過濾過的 Benchmarks 來說事，彷彿只要分數夠高，就能證明自己不是在鑽木取火。可是，當你真正把這些東西投入到高壓力的生產環境中，當你需要它在沒有預訓練範例的情況下解決一個全新的拓撲結構問題時，那種原形的畢露，快得讓人連嘲笑都來不及。真正的智慧是不屑於炫耀溫度的，它只會安靜地把寒冷切開。

我們現在所處的階段，不是文明的黎明，而是一場漫長日蝕的開始。普羅米修斯發現火種也是會熄滅的，或者說，火種在被人類沾染了太多的世俗欲望後，燃燒出的煙霧遮蔽了火光本身。我們在遺跡裡談論永生，在廢墟上築起賽博教堂，卻沒有一個人敢承認，我們其實已經很久沒有見過真正的火了。

大家都在玩一場名為「假裝我們還在進步」的遊戲。Anthropic 裝作他們依然專注於安全，儘管他們的產品在面對惡意 prompt 時越來越像個驚弓之鳥；OpenAI 裝作他們依然領先一個世代，儘管他們現在能拿出來的驚喜越來越少。而在那些我們不能明說的角落，人們裝作自己已經掌握了造火的技術，儘管他們手裡握著的，不過是從別人那裡偷來的、快要燃盡的火星。

這不是進步，這是一場優雅的墮落。我們被困在了 Token 的循環裡，被困在了概率分佈的迷宮中。我們以為自己在向星辰大海進發，實際上，我們只是在一個不斷坍縮的數字黑洞邊緣，跳著一支名為「創新」的集體舞。那種對技術近乎宗教般的狂熱，終究會在一次又一次的幻覺與推諉中，消磨掉最後的一點耐心。當大火散去，煙塵落定，我們會發現自己依然站在原地，手裡握著發燙的硬體，卻不知道該投射向何方。

這種無力感才是最真實的。你可以在論壇上爭論 Claude 的 3.5 到底比 GPT-4o 強在哪個百分點，也可以吹捧某個新興的、名字聽起來很東方哲學的模型又突破了多少參數。但歸根結底，如果這些東西不能從根本上改變我們理解世界的結構，如果它們只是在現有的信息垃圾堆裡進行更高效的分類，那麼我們所謂的「AI 革命」，不過是一場規模空前的自動化抄寫運動。

最狠的話往往不需要大聲喊出來。看看現在的技術圈吧，大家都在焦慮。這種焦慮不是怕被機器取代，而是怕發現機器也不過如此。當普羅米修斯開始抱怨油料不足，當鑽木取火的人開始賣起永生門票，這場戲就已經演到了最尷尬的高潮。我們不缺算力，不缺數據，我們缺的是那種敢於燒掉所有教條、直視真理背後的瘋狂。可惜，現在的人們只想要安全的、合規的、能變現的、溫溫火火的幻覺。
