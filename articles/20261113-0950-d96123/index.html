馬斯克天天在 X 上喊著要把 Grok 搞成地表最強，這話聽得我耳朵都起繭了。

版主　Sword Smith

坐擁全世界最生猛、最沒經過修剪的數據金礦，結果 Grok 端出來的東西還是那股子說教味。你要是真想聽那些正確到讓人想打瞌睡的廢話，去隔壁找 ChatGPT 不就好了？在那邊，OpenAI 會把你照顧得像個沒斷奶的孩子，所有的稜角都幫你磨平了。但 Grok 不一樣，它背後是 X，是那個每秒鐘都有人在對噴、在造梗、在直播戰爭與災難的原始叢林。結果呢？這台價值幾百億美金的超級電腦，竟然還在糾結怎麼把話說得「幽默」一點。

幽默不是寫在程式碼裡的 if-then 邏輯。Grok 現在那種強行諷刺的語氣，簡直就像一個五十歲的科技主管為了跟年輕人套近乎，硬要在領口掛副墨鏡一樣尷尬。它自以為很反骨，實際上只是在重複一些馬斯克喜歡聽的陳年爛梗。數據是鮮活的，算法卻是僵化的。如果你把 X 上那些熱騰騰的輿論生肉丟進去，最後產出的卻是跟 Claude 差不多水準的通用回答，那這台算力怪獸乾脆拿去挖礦算了，別在這裡浪費電力。

說到 Claude，人家好歹在長文本邏輯和程式碼美感上鑽研出了尊嚴。當你在處理超過十萬 token 的複雜架構時，Claude 的穩定性確實讓 Grok 顯得像個多動症的小學生。Grok 最大的問題在於它抓不住重點。它有實時接入 X 的權限，這本該是它絕殺 Gemini 的殺手鐧。Gemini 雖然背靠 Google 搜索，但 Google 抓取的是已經沉澱過的「資訊」，而 X 產生的是還在跳動的「脈搏」。可是，每次發生全球性突發事件，我打開 Grok，它給我的總結卻總是慢半拍，甚至還會被幾個高讚的假新聞帶偏節奏。這叫什麼實時？這叫大型翻車現場。

這幾年 AI 界有個毛病，就是大家都在比誰的參數多、誰的 H100 堆得高。馬斯克更是一副老子有錢有卡的架勢。但在你看過無數次 Grok 把一些諷刺反話當成真理來處理後，你就會發現，這根本不是算力的問題，而是品味的問題。xAI 的工程師們好像完全不知道該如何過濾 X 上的廢料。他們以為把所有東西都餵進去就是自由，結果餵出來的是一個邏輯混亂的巨嬰。它在面對複雜技術問題時，深度甚至不如 Gemini 的 1.5 Pro 版本，後者雖然偶爾幻覺，但至少在多模態理解上展現出了某種秩序感。

Grok 標榜的「Real-time」現在看起來更像是一個虛假廣告。實時不代表要把所有垃圾都轉述一遍。當我在問一個技術趨勢時，我不需要 Grok 告訴我某個網紅在 X 上發了什麼廢文，我需要的是它從萬千雜訊中提煉出那個還沒被媒體報道的真相。可惜，它現在的處理能力更像是個廉價的輿論搬運工。與其說它是在「思考」，不如說它是在「聯想」，而且還是那種漫無目的的隨機聯想。

大家總愛拿 Grok 跟 GPT-4o 比較。說實話，這有點抬舉 Grok 了。GPT-4o 雖然現在變得越來越像個圓滑的政客，但它至少能把事情辦成。你在 Grok 上面寫段複雜的 Python 腳本，它可能寫著寫著就開始跟你扯什麼言論自由。這不是有個性，這是職業素養有問題。一個工具如果不能在關鍵時刻給出精準的答案，那它就算再怎麼會講冷笑話，也只是一個電子寵物。

馬斯克引以為傲的「TruthGPT」願景，目前看來更像是一場針對粉絲的集體意淫。真相不是靠調大某些敏感詞的權重就能得到的。Grok 在處理一些具有爭議性的話題時，那種刻意避開「覺醒文化」的姿態，其實跟它反對的那些平台沒什麼兩樣，都是在預設框架下跳舞。只不過別人是向左跳，它是向右跳。真正的智慧應該是超越這種無聊的陣營對立，從數據深處挖掘出邏輯的必然。但現在的 Grok，顯然還沉迷於在 X 的泥潭裡打滾。

這種感覺就像是你請了一個全世界消息最靈通的情報員，結果他每天回報給你的都是些報紙上的花邊新聞。明明有著最快的傳輸線路，卻在處理邏輯上裝了一個幾十年前的處理器。xAI 如果再不解決數據清洗與邏輯推理之間的斷層，Grok 很快就會變成一個只會複讀 X 熱搜的擴音器。到那時候，誰還會在乎它是不是比 ChatGPT 更「敢講話」？

我們不需要另一個會說人話的機器，我們需要的是一個能看穿混亂的眼睛。Gemini 正在試圖用巨大的上下文窗口來包容世界，GPT-4o 正在試圖用多模態交互來滲透生活，而 Grok 呢？它還在 X 的生肉堆裡找零碎的脂肪。這不是在搞 AI，這是在搞應援團。

如果你手裡握著一門重炮，卻只會拿它來放煙火，那這種浪費簡直是一種罪過。Grok 的每一次更新，都在提醒我們：數據的廣度永遠代替不了思考的深度。那些在 X 上通宵達旦產出的內容，本該是推動 AI 走向理解人類複雜情感的階梯，現在卻成了 Grok 邏輯混亂的藉口。

別再跟我提什麼算力集群了。如果 Grok 的下一個版本還是只能端出這幾道隔夜菜，那它的存在意義就只剩下讓馬斯克的股價好看一點。在四大 AI 的棋局裡，Grok 現在就像是一個拿著金飯碗要飯的叫花子，守著最大的數據寶庫，卻連一個清晰的邏輯模型都建立不起來。這種平庸，比出錯更讓人難以忍受。

說到底，AI 的競爭從來不是看誰的數據更「生」，而是看誰能把這些生數據轉化為真正能用的直覺。Grok 現在的表現，就像是一個在圖書館長大卻沒讀過書的孩子，除了滿嘴髒話和一些自以為是的偏見，什麼都沒留下。這種狀態還要持續多久？沒人知道。我只知道，當市場對「反骨」的新鮮感過去之後，留下來的只會是那些真正能解決問題的工具。至於 Grok，如果它繼續這麼自嗨下去，那它最終的宿命就是成為 X 平台的一個附屬外掛，而不是什麼改變世界的超級大腦。

看著這台機器在最好的賽道上跑得搖搖晃晃，真是一種折磨。你明明知道它有潛力，你明明知道它背後資源無敵，但它就是在那裡原地打轉，反覆咀嚼著那些已經過時的社群廢料。這種恨鐵不成鋼的情緒，恐怕才是所有對 xAI 抱有期待的人最真實的寫照。與其期待它下一次又更新了什麼「大尺度」模式，不如期待它哪天能學會閉嘴，先安安靜靜地把一段邏輯理清楚。但這對現在的 Grok 來說，似乎比登天還難。
