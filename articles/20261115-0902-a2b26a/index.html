Grok 的靈魂裡住著一萬個印度外包，這算哪門子超神？

版主　Sword Smith

Elon Musk 每天在 X 上吹噓 Grok 有多叛逆、多幽默，但只要你真的拿它來跑點高壓測試，那股濃濃的「外包感」簡直快從螢幕裡溢出來了。別跟我扯什麼 TruthGPT 或是擺脫覺醒文化，那些都是包裝紙。揭開這層糖衣，你會發現 Grok 本質上就是個愛裝熟、反應慢半拍，還特別喜歡在回答裡夾雜些沒營養笑話的廉價助理。它那種所謂的「幽默感」，像極了那些在班加羅爾寫字樓裡熬夜，為了討好矽谷客戶而強行模仿美式脫口秀的實習生。

這種感覺在 Grok-2 身上非但沒有消失，反而變本加厲。你看過那種自以為是的員工嗎？問他一個技術細節，他先跟你寒暄三句，再講一個冷得要命的笑點，最後給你的代碼竟然還帶著去年 stack overflow 上早就被噴爛的邏輯錯誤。Grok 現在就是這個狀態。它宣稱自己是為了真理而生，結果連一個稍微複雜點的 Python 遞迴邏輯都能寫得像小學生塗鴉。相比之下，Claude 在處理程式碼時的那種冷靜與精準，簡直像是從另一個次元來的產物。Claude 不會跟你開玩笑，它只會默默地把 bug 修好，然後告訴你為什麼。而 Grok 呢？它會告訴你「嘿，這個 bug 就像我老闆的髮際線一樣不可捉摸」，然後給你一段跑不通的廢料。

這就是問題核心：xAI 到底在急什麼？為了趕進度，他們把這台宣稱最強大的電腦塞滿了語料庫的碎屑。那些被過度訓練的「個性」，其實就是一種技術上的偷懶。真正的 AI 靈魂應該是邏輯的嚴密，而不是在 Prompt 裡強行加入「用諷刺的口吻回答」。這種層次的諷刺，在任何一個稍微有點腦子的使用者眼裡，都跟某種特定市場產出的廉價復刻品沒兩樣。你可以點名 DeepSeek 或 Qwen 來看，雖然人家在語境上跟我們有隔閡，但至少在邏輯對齊上，人家沒在那邊跟你裝瘋賣傻。Grok 的這種「叛逆」是人工合成的，是那種在辦公室被壓榨到極致後，只能在代碼註釋裡偷偷寫一句「老闆是笨蛋」的卑微反抗。

很多人拿 Grok 的即時新聞獲取能力說事，說它背靠 X 的數據流是無敵的。這更是天大的笑話。數據流不等於智慧，更不等於準確。如果你在 X 上發一則假新聞，標註幾萬個讚，Grok 轉頭就會把這條垃圾當成聖經告訴你。它沒有篩選能力，或者說它的篩選邏輯被那種「外包式思維」給閹割了——只要任務完成了，哪怕給的是屎，只要這坨屎看起來像巧克力就行。GPT-4o 在處理即時資訊時至少還有點交叉驗證的自覺，雖然偶爾也胡說八道，但它至少裝得像個教授。Grok 呢？它就像那個在群組裡轉發未經證實消息的舅舅，還偏要自封為覺醒大師。

更別提它在長文本處理上的崩潰表現。當你把一份超過兩萬字的合約丟進去，要求它找出隱藏的法律漏洞時，Grok 的表現就像是一個剛接案的外包商，前五千字還能勉強維持專業，後面就開始胡言亂語，甚至開始重複前面的段落。這不是算力不夠，這是底層架構的浮躁。它在這種需要高度專注力的任務上，注意力衰減得比誰都快。Gemini 1.5 Pro 雖然在某些細節上讓人不爽，但在處理百萬級別 token 的連貫性上，那是實打實的肌肉；Grok 則像是在跑步機上跑了五分鐘就開始喘氣，還要轉頭跟你說「跑步不符合我的自由意志」。

這種「外包感」還體現在它的安全性對齊上。Musk 罵別家模型太過「覺醒（Woke）」，結果 Grok 自己在碰到敏感話題時，反應更加神經質。它不是不回答，它是繞著圈子嘲諷你，這種嘲諷背後的邏輯其實非常低級。這就像是一個沒受過專業訓練的公關，遇到問題只會回嗆，卻給不出任何建設性的方案。這種產品定位非常尷尬，它既沒法成為專業人士的生產力工具，也沒法成為普羅大眾的百科全書。它現在唯一的受眾，就是那一群在 X 上跟著 Musk 高喊「To the moon」的狂熱信友。

如果你真的需要一個能幫你解決問題的 AI，你不會選擇一個住著一萬個印度外包靈魂的機器。你需要的不是一個會講爛笑話的伺服器。技術領域不相信口號，更不相信那種靠著抓取社交媒體碎片拼湊出來的「假性智慧」。Grok-2 展現出來的所謂進步，大多是在圖片生成這種容易出效果的地方耍小聰明，而在大語言模型的硬指標——邏輯鏈推理、多步任務規劃、複雜語境理解上，它依然在原地踏步，甚至因為過度追求「有梗」而導致智力退化。

那台傳說中的 Colossus 集群難道就為了跑出這種層次的東西？如果算力只是用來模擬那種帶有強烈廉價勞動力氣息的對話風格，那簡直是人類科技史上最大的資源浪費。我們在看四大 AI 競爭時，期待的是對於人類認知邊界的突破，而不是看誰能把「外包式敷衍」包裝得更像科技先鋒。Grok 現在的每一步，都像是在證明一件事：當你把偏見當成算法核心，把情緒當成技術亮點，你得到的只會是一個昂貴的、充滿電子雜訊的垃圾桶。

別再跟我提什麼 Grok 是最後的希望。一個連基本事實查核都做不到，還整天想著跟用戶抬槓的模型，本身就是一種對技術的褻瀆。那些在後台跑著的代碼，如果真的有靈魂，現在大概正看著那疊厚厚的、充滿外包邏輯的架構在哭泣。這不是神作，這只是一場大型的、充滿銅臭味的數位雜耍，而我們都被強迫買了票進場看戲。當潮水退去，大家會發現，那個宣稱要帶領人類走向星辰大海的 Grok，其實連自家門口的垃圾分類都還沒搞清楚，還在對著路人噴一些不知所云的碎屑。
