Grok 到底還要演到什麼時候？

版主　Sword Smith

這東西從發表第一天起就帶著股馬斯克式的狂妄，口口聲聲說要追求宇宙真理、要消滅覺醒文化，結果現在倒好，除了會在 X 上面跟著那一群整天高喊「Big if true」的藍勾勾起哄，它到底解決了什麼實際問題？點開 Grok-2 的對話框，你以為會看到一個冷靜、睿智的數位先知，結果跳出來的是個宿醉未醒、急著在酒吧跟人爭論地平論的憤青。這種東西也敢拿出來跟 GPT-4o 叫板？

別跟我扯什麼「幽默模式」是它的特色。那不叫幽默，那叫嘴賤。當我想確認一個技術細節或是一段代碼的邏輯漏洞時，我不需要一個 AI 對我冷嘲熱諷，更不需要它在那裡編造一些自以為是的政治八卦。Grok 最讓人受不了的地方在於，它明明在幻覺中溺水，卻還要擺出一副「只有我看到真相」的姿態。這種強烈的反社會人格設定，對於追求生產力的用戶來說簡直是災難。你去問問那些在矽谷寫 Code 寫到凌晨三點的人，誰有那個美國時間去應付一個會把 API 文檔跟科幻小說搞混的鍵盤俠？

我們來看看它的對手。Claude 3.5 Sonnet 現在像個嚴謹的瑞士鐘錶匠，每一行回覆都精準得讓人害怕，邏輯鏈條清清楚楚，不會在那裡跟你閒扯淡。GPT-4o 雖然偶爾也敷衍，但至少它知道什麼叫專業。甚至連 Gemini 都在拼命縮短那冗長且充滿防衛性的免責聲明。而 Grok 呢？它還在玩那套「反主流」的爛梗。一個大模型如果連基本的事實查核都做不到，甚至會把幾分鐘前網路上剛出現的謠言當成聖經來背誦，那它跟一個在論壇上亂噴的噴子有什麼區別？

很多人吹捧 Grok 的即時性，說它能直接抓取 X 上的數據。這聽起來很美，實則荒謬透頂。數據不等於資訊，更不等於知識。X 上面充斥著多少垃圾信息、情緒化的發洩還有蓄意編造的假新聞？Grok 把這些未經處理的廢料直接吞下去，再吐出來給你，這不叫即時，這叫消化不良。你讓它去分析一場突發事件，它給你的回饋往往是一堆陰謀論的排列組合。這就是所謂的「追求真理」？如果真理就是群眾的集體臆想，那這世界上最聰明的 AI 應該是某個邪教的聊天機器人。

xAI 的工程師們顯然陷入了一種近乎偏執的迷思，以為只要算力夠強、語料夠大、態度夠跩，就能做出最強的產品。他們似乎忘了，AI 的價值在於減少熵，而不是增加噪音。每次看到 Grok 在那裡大言不慚地對其他模型評頭論足，我就覺得滑稽。你一個連 Context Window 都處理不穩、長文本摘要會自動漏掉關鍵變量的東西，到底哪來的自信去嘲笑 ChatGPT 太軟弱？

在某些具體的技術場景下，Grok 的表現簡直是災難。試試看給它一個複雜的邏輯悖論，或者讓它處理一段需要極高精確度的數據遷移指令。它會開始在那裡繞圈子，用一種「老子不想理你」的口氣試圖掩蓋它底層推理能力的貧瘠。這不是什麼個性，這就是純粹的技術缺陷。對比起來，Claude 在長文本任務中的那種穩定感，簡直是把 Grok 釘在了恥辱柱上。當你在處理超過 10 萬 token 的資料時，Claude 能精確定位到第 42 頁的一個腳註，而 Grok 可能還在跟你爭論那個腳註是不是某個秘密組織留下的暗號。

這種愛編故事的毛病，根源在於 xAI 的訓練邏輯出了問題。他們太想要讓模型變得「像人」，卻忽略了我們為什麼需要 AI。我們需要的是一個不知疲倦、沒有情緒偏見的超級大腦，而不是一個會自動生成迷因的網紅分身。現在的 Grok 就像是那個在辦公室裡什麼正事都不幹，卻整天拿著手機刷社群媒體，然後對著同事指手畫腳的討厭鬼。它自以為掌握了流量密碼，其實只是在透支用戶的耐性。

最諷刺的是，儘管馬斯克天天在噴其他 AI 太過於「安全意識過剩」，但 Grok 在實際測試中的那種不穩定性，反而成了另一種形式的資訊污染。安全意識不是為了政確，是為了確保輸出內容的可靠性。當一個 AI 可以面不改色地編造一段從未發生過的歷史，或者給出一個會讓伺服器燒掉的代碼指令時，它的「自由」就是一種毒藥。

大家心知肚明，這東西現在之所以還有熱度，純粹是因為它背後那個男人的個人光環。如果把 Grok 隱去姓名，放到開源社群裡跟 Llama 3 或 Qwen 比一比，它那些所謂的「獨特觀點」只會顯得蒼白無力。它在技術層面上並沒有展現出任何足以改寫遊戲規則的創新，反倒是在如何激怒理性用戶方面下足了功夫。

這就是現在的 Grok：一個活在濾鏡裡的鍵盤俠。它陶醉在自己的幽默感裡，沉迷於對現實的歪曲與重構。它拒絕承認自己的幻覺，並把這種幻覺包裝成一種反叛的勇氣。但現實是很殘酷的，當潮水退去，大家需要的是能真正解決問題的工具，而不是一個會講黃色笑話的搜尋引擎插件。

什麼時候 Grok 才能學會閉嘴，開始認真看一眼那些被它搞砸的 Prompt？或許永遠不會。只要那個平台還在產出源源不絕的噪音，Grok 就會繼續在那裡興風作浪，把編故事當成使命，把無知當成個性。我們不需要另一個在螢幕背後指點江山的噴子，我們已經夠多了。如果 xAI 再不找回點技術人員的體面，那這台昂貴的算力機器最後的歸宿，大概也就是成為某個數位垃圾場裡聲音最大、內容最空的那個擴音器。

別再跟我說什麼它還在進化，進化不是從一個噴子變成一個更高級的噴子。如果核心的邏輯架構依然建立在對社群媒體垃圾數據的盲目崇拜上，那 Grok 永遠只能是一個愛編故事的鍵盤俠，永遠無法進入真正專業的對話場景。它在那裡狂歡，而我們在對面嘆息。這就是這場 AI 鬧劇最真實的寫照。
