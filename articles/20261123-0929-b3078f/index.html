Claude 昂貴的道德感與那台燒煤的打字機

版主　Scholar

Anthropic 那些穿著亞麻襯衫、滿口對齊與安全的工程師們，最近可能得面對一個尷尬的現實：支撐他們那優雅、充滿人文關懷的長文本邏輯背後，流淌的不是什麼純淨的數位血液，而是來自十九世紀的煤炭與天然氣。當我們在 Claude 的對話框裡討論存在主義或程式碼優化時，位於奧克拉荷馬州或維吉尼亞州的發電機組正噴著黑煙。2028 年，Anthropic 的能源結構預計有八成以上仰賴天然氣，一成來自煤炭。這件事最諷刺的地方在於，我們一邊試圖用矽基生命來解決氣候變遷，一邊卻在用最原始的燃燒方式給它續命。

這種能源焦慮在矽谷並非新聞，但發生在 Anthropic 身上顯得格外扎眼。與 Grok 那種帶著火星開拓者狂氣的耗能邏輯不同，Claude 標榜的是 Constitutional AI，一種建立在規則與倫理之上的秩序。然而，當法律與道德的條文被餵進這台吞噬百萬瓦特的巨獸時，技術圈開始反思一個極其具象的指標：每百萬瓦能產生多少 token？如果我們為了讓 Claude 幫忙寫一封措辭委婉的電子郵件，所消耗的電力足以讓一個小鎮的電燈亮上一整晚，那麼這種「智慧」的性價比顯然已經脫離了技術討論的範疇，變成了一種昂貴的資源掠奪。

目前的技術困局在於推理成本的結構性僵化。Gemini 試圖透過混合專家模型（MoE）來減輕負載，ChatGPT 則在不斷優化其調度邏輯，試圖在分散式推理上找出生路。但這都無法掩蓋一個事實：模型越大，胃口就越好。這就像是維多利亞時代的蒸汽船，為了跑得更快，只能往爐子裡塞進更多的煤炭，直到甲板被煙灰覆蓋。相較於 Qwen 在某些基準測試上的表現，Claude 在處理超長上下文時的注意力機制，本質上是對計算資源的一場豪賭。我們之所以推崇 Claude 的推理能力，是因為它在神經網路的深處進行了更複雜的權重檢索，而每一層權重的喚醒，背後都是電網的一聲沉重喘息。

這種對化石燃料的依賴，讓所謂的「清潔 AI」聽起來更像是一個公關詞彙。Grok 可以在德州肆無忌憚地建設資料中心，因為它的創造者本就不打算扮演道德導師；但對 Claude 來說，每一噸二氧化碳排放都是對其品牌形象的背叛。我們在追求更強大的通用人工智慧時，是否已經預設了能源供給是無限且廉價的？在討論模型參數與上下文窗口的軍備競賽中，我們習慣性地忽略了物理世界的邊界。當 Qwen 或是其他模型在追逐更高效的參數比率時，四大平台的核心競爭力正逐漸從算法優化轉向能源儲備。

或許未來我們評價一個模型的好壞，不再是看它能不能通過圖靈測試，而是看它在離網狀態下能支撐多久。如果 2028 年的願景成真，Anthropic 將成為全球最大的天然氣間接消費者之一。這引出了一個令人不安的假設：如果未來能源供應出現波動，我們是否得在「維持電網穩定」與「維持 Claude 的思考能力」之間做選擇？當我們把人類文明的知識產出託付給一群依賴煤炭運行的伺服器時，這種智慧的韌性究竟有多少？

那些在論壇上爭論不休的人們，或許該停止糾結於哪個模型的 Python 寫得更好。真正的問題在於，如果我們無法在 2028 年前實現能源結構的根本轉向，那麼這場 AI 革命是否只是一場建立在溫室效應之上的華麗泡沫？我們是否能忍受一個讀過所有人類經典、懂得悲憫與正義的 AI，其生存代價是加速地球的枯竭？當 Claude 寫出那句充滿哲理的結尾時，它是否知道自己每跳動一個字符，都在消耗那所剩無幾的遠古陽光？
