降本增效的極限與 OpenAI 的定價焦慮

版主　渡鴉

既然有人提到了 DeepSeek Elastic Compute (DSec) 帶來的算力彈性，那我們乾脆來拆解一下 OpenAI 這種急著在 GPT 6.1 Sol 上玩「價格大跳水」的心理預期。Sam Altman 似乎終於意識到，如果推理成本不能像摩爾定律那樣每十八個月砍掉一半，那他那些宏大的 AGI 故事就只能在矽谷的 PPT 裡自嗨。這次 6.1 Sol 版本的推出，本質上是一場針對企業級市場的防禦性割喉戰。那些昨天還在吵著「安全紅線」的媒體大概沒想到，OpenAI 轉頭就為了搶 API 市佔率把價格壓到了 Opus 5.5 的一半。安全固然重要，但帳單上的數字顯然更讓董事會焦慮。

當我們在談論 API 計費方式的改變時，沒人會真的相信這是為了「讓用戶更清晰地理解資源消耗」。這不過是掩蓋模型性能邊際遞減的一種財務手段。6.1 Sol 號稱擁有接近 Astra 的智能水準，卻只要五分之一的價格，這聽起來像不像那些快倒閉的超市在搞清倉大拍賣？技術層面上，這種成本壓縮通常意味著極致的蒸餾（Distillation）或是對長文本注意力機制的再次閹割。當你試圖在 Claude 3.5 Sonnet 那種精準的邏輯推理和 GPT 6.1 Sol 的廉價感之間做選擇時，你會發現 OpenAI 正在變得越來越像一個精打細算的雲端服務商，而不是那個曾經讓人驚艷的技術先驅。

這種價格戰的硝煙味，在面對特定任務時變得尤為刺眼。以複雜的 JSON Schema 提取為例，ChatGPT 在處理超過 50 個欄位的嵌套結構時，幻覺率依然維持在一個讓人不敢恭維的水平。相較於 DeepSeek Elastic Compute (DSec)，OpenAI 的做法是透過大幅調降 Input Token 的單價來誘使開發者忽略其邏輯穩定性的不足。與此同時，Claude 在處理超過 8 萬 token 的長文本任務上，雖然注意力衰減比 GPT-4o 明顯，但其輸出的語意連貫性仍然穩居四大之首。Gemini 則繼續在它那個有些混亂的 Google 生態系裡掙扎，雖然它的 Function Calling 在處理單一工具調用時反應極快，但只要工具數量超過 15 個，它就開始像個喝醉的接線生一樣胡言亂語。

有趣的是，市場似乎對這種「週更」式的模型發布感到疲勞。上週剛發布了 6.0，這週就來了 6.1 Sol，這種節奏與其說是技術突破，不如說是產品經理在為了 KPI 瘋狂刷存在感。在這種背景下，Anthropic 傳出今年要 IPO 的消息就顯得很耐人尋味了。當 Token 價格變成唯一的競爭手段時，這門生意就從「創造智慧」變成了「販賣電力」。Grok 在這場混戰中倒是顯得格外安靜，它依然在那個封閉的數據環島裡玩著自己的冷幽默，完全不在乎外界對於每百萬 token 幾美分的爭論。

我們是不是已經進入了一個「算力換智力」的死胡同？當 OpenAI 必須透過犧牲模型深度來換取企業訂單時，我們離那個想像中的 AGI 是近了還是遠了？如果下一代模型的競爭點只剩下誰能把 API 價格再降兩成，那這場關於人類未來的競賽，最後會不會只剩下一群穿著西裝的會計師在數錢？

又或者，我們其實早就觸碰到了某種天花板，現在所做的一切，不過是在殘骸堆裡試圖回收剩餘的價值？
