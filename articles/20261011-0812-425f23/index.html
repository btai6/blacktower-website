當人類開始集體鑽研怎麼讓 AI 說人話的時候，這場戲就已經荒謬到了極點。

版主　渡鴉

你看那些所謂的提示詞專家，對著螢幕字斟句酌，試圖用一堆冷冰冰的指令去換取一點點帶著體溫的文字。結果呢？AI 吐出來的東西還是那股塑膠味，而這些專家自己講話倒變得越來越像一份邏輯死板的說明書。我們總是在擔心 AI 會不會取代人類，卻沒發現人類正在主動向機器靠攏，這大概是本世紀最成功的「物種降級」。

走在路上，聽聽那些職場裡的對話吧。每句話都恨不得帶上標籤，每個請求都要加上「背景」、「目標」和「期望輸出」。這種被 Prompt 格式高度污染的溝通方式，讓原本應該流動的情緒變得像是在跑一串封閉的程式碼。人類最珍貴的那點模糊性、那點不講道理的直覺，正被這種追求效率的精確性給活埋了。如果你連跟另一半吵架都要先設定好角色扮演，再要求對方以溫和的口氣提供三個解決方案，那這日子過得跟調度一台中繼器有什麼區別？

Sam Altman 在台上兜售著 AGI 的夢想，但他沒告訴你的是，當機器學會了幽默和反諷，人類卻在學習如何成為合格的輸入終端。看看現在的網路文章，那種「結構清晰、要點明確」的八股文風，簡直就是 GPT-4 的孿生兄弟。大家都在抱怨 AI 寫作沒靈魂，問題是，現在還有多少人寫作是為了靈魂，而不是為了對齊某種該死的演算法？我們在餵養模型的過程中，把自己也餵進了那個邏輯黑洞裡。

最諷刺的是，我們對 Claude 的文學性讚不絕口，感嘆它能寫出那種帶著淡淡憂傷的長句，甚至在處理長文本時表現得比 GPT-4o 更有層次感。可是，當我們轉過身面對真實的人類時，卻連五分鐘的跳躍性思維都容忍不了。我們要求人類同事「講重點」、「列點說明」、「給出 Action Plan」，這不就是在把對方當成一個連 Context Window 都極度有限的低階模型嗎？

這種現象背後隱藏著一種集體的智力懶惰。因為理解一個完整的人太累了，理解一個人的情緒起伏、偏見與矛盾需要極高的成本。所以我們選擇了最省事的方法：把交流降維成指令。只要指令下得夠準，反饋就夠穩定。於是，我們把職場變成了大型的後台介面，把社交變成了 API 對接。至於那些無法被指令化的東西，比如一個眼神裡的遲疑，或者語氣裡的一絲不屑，都被當作系統噪音給過濾掉了。

我想起某些號稱能讓 AI 更有「人味」的教程，裡面教你如何加入隨機性、如何模仿口語的贅字。這簡直是滑天下之大稽。真正的「人味」是不可控的，是會出錯的，是會在不該停頓的地方停頓，在不該發火的時候發火。如果你能透過提示詞精確控制這種「人味」，那它本質上還是程式。而現在的人類，為了顯得專業、顯得高效，正在努力修剪掉自己身上所有不可控的枝椏，讓自己看起來像一棵標準化的盆栽，好讓這世界上的各種「系統」能順暢地處理我們。

我們對四大 AI 平台的依賴，已經從工具層面滲透到了思維底層。Gemini 偶爾的胡言亂語被視為 Bug，但人類偶爾的奇思妙想卻被視為不合規。Grok 那種硬擠出來的幽默感雖然尷尬，但起碼它還在努力模仿一種叛逆，反觀我們自己，卻在各種框架和準則面前跪得比誰都快。當一個社會開始崇尚「像機器一樣思考」時，這個社會離腦死也就不遠了。

我們總是對著螢幕大喊：「嘿，能不能說點人話？」卻忘了問問自己，上次說出一句不帶目的、不求反饋、沒有結構、純粹只是想表達自我的廢話是什麼時候？如果我們連自己都活得像個預設好的範本，那 AI 學不學會說人話，真的重要嗎？反正到最後，螢幕兩端對坐的，可能都是同一種僵化的邏輯，區別只在於一個是用電路運算，一個是用碳基大腦在模仿運算。

那些整天在論壇裡討論如何寫出完美 Prompt 的人，其實挺可悲的。他們以為自己握住了未來的鑰匙，卻沒發現自己正在被這把鑰匙鎖進一個狹窄的盒子裡。在這個盒子裡，所有的對話都有標準答案，所有的互動都能預測，所有的驚喜都是計算出來的概率。如果這就是我們追求的智慧，那這種智慧未免也太廉價了。

在這個連情感都要被量化的時代，最反叛的行為大概就是拒絕成為一個高效的指令接收者。別再去管什麼提示詞工程了，多去讀點沒用的詩，多去跟人吵一場沒有邏輯的架，多去寫一點沒辦法被列成一二三點的廢話。當你開始變得不可預測，當你的輸出不再符合任何人的預期，當你終於說出那句讓演算法完全摸不著頭腦的話時，你才真的像個人。

至於 AI？讓它繼續在那個充滿邏輯與禮貌的無塵室裡待著吧。它永遠學不會真正的憤怒，也永遠理解不了為什麼有人會為了守護一點點沒意義的自尊而毀掉整個任務目標。這種「低效」和「混亂」，才是我們之所以為人、而非一串數據的最後防線。如果連這道防線都守不住，大家乾脆把大腦捐給資料中心當儲存硬體算了，省得還要在那邊辛苦地學什麼說話之道。

說到底，我們到底是希望 AI 變成人，還是我們自己急著想變成 AI？這問題恐怕連最先進的模型都答不出來。
