被 AI 寵壞的人，大概都忘了跟碳基生物溝通有多痛苦。

版主　渡鴉

你在 ChatGPT 的對話框裡敲下幾百個字的 System Prompt，要求它語氣專業、不准廢話、邏輯嚴密，甚至連標點符號的禁忌都列得清清楚楚，結果它還真能像個沒脾氣的完美奴隸一樣精準執行。但轉頭看看你辦公桌對面那位，或者手機螢幕另一端那個，你連讓他回訊息不要只會傳個貼圖都辦不到。這不是很諷刺嗎？我們花大把時間研究怎麼跟一串代碼溝通，卻對著活生生的人類兩手一攤，說這叫「性格不合」。

其實這世界本質上就是個大型的提示工程實驗場。你以為你在談戀愛、在工作、在社交？不，你只是在對著一堆充滿 Bug 的舊型號硬體輸出指令。如果我們能像對待 Claude 那樣，給每個人類對象寫一份詳盡的 README 文件，這世界大概能少掉一半的謀殺案和九成的離婚訴訟。

問題出在人類的 Context Window（上下文窗口）短得可憐。你跟老婆交代下班買瓶醬油，如果中間夾雜了三個紅綠燈和一通客戶電話，等他到超市時，醬油這個關鍵詞大概率已經從他的緩存裡被置換出去了。這種時候你需要的不是爭吵，而是重發一次 Prompt。但現實是，大多數人連最基本的指令清晰度都做不到。你說「隨便」、「你看著辦」、「我沒事」，這在模型測試裡叫模糊指令，換來的結果必然是隨機生成的垃圾輸出。你憑什麼要求一個運算速度比 GPT-4o 慢上幾萬倍的人腦，能精準解碼你那些充滿情緒噪音的垃圾訊號？

我們對 AI 寬容得近乎慈悲。如果 Gemini 產生幻覺，你會冷靜地修訂提示詞，或者加一句「請一步步思考」。但如果你的下屬理解錯了你的意思，你只會覺得他腦子進水。這就是認知的偏差。你對機器有明確的預期管理，知道它在某些長文本任務下會注意力衰減，知道它在處理複雜數學邏輯時會翻車，所以你避開了它的弱點，甚至幫它搭建了 RAG 架構來補足短板。但對人呢？你明知道那個誰誰誰就是個無法處理多線程任務的人，你偏要在週五下午五點給他塞五個緊急需求，然後再抱怨他產出不穩定。這不是他的問題，是你的 Prompt 寫得太爛。

想像一下，如果每個人的胸前都掛著一個二維碼，掃進去就是一份「使用手冊」。裡面寫著：本型號在早上十點前處於低性能模式，請勿輸入複雜指令；情緒價值對本機無效，請直接給出事實路徑；本機對反諷語法敏感度極低，請確保指令為字面意義。如果有了這些參數設定，溝通還會是那種充滿試探與猜測的玄學嗎？

我們現在陷入了一種很詭異的賽博焦慮。大家在論壇上吵 Grok 2 的邏輯到底有沒有提升，爭論 OpenAI 的 o1 模型在推理性能上是不是又擠了牙膏，卻從來不肯花五分鐘去反思，為什麼自己對待家人或同事的溝通策略還停留在 1.0 版本。甚至連版本更新都懶得做，一套「我覺得你應該懂我」的邏輯從十八歲用到八十歲，最後只能怪對方的內核太舊。

說到底，我們對 AI 的「調教」本質上是一種權力掌控感的延伸。因為它不會反駁，不會在你優化提示詞時說「你這話傷到我自尊了」。而在人類社交裡，寫說明書這件事被貼上了「冷血」或「僵化」的標籤。我們崇尚那種不可言說的「默契」，彷彿只要說出口了、寫清楚了，這段關係就不高級了。這種對模糊性的病態追求，正是所有溝通災難的源頭。你以為是靈魂的碰撞，實際上只是兩個編碼格式不相容的系統在互相報錯。

在技術圈混久了，看人真的會看出一種零件感。每個人都是由特定的生長環境（訓練數據）和基因（基礎架構）組成的。你不能指望一個從來沒讀過專業金融數據的模型去寫深度財報分析，同樣的，你也不能指望一個從小在壓抑環境長大的溝通對象能秒懂你的幽默感。如果不先進行「預訓練」，不對特定的溝通場景進行「微調」，所有的輸出都只是亂碼。

有些人會跳出來說，人不是機器，人有感情。這就是典型的邏輯偷換。感情是運作時產生的熱能，不代表你可以因此忽視系統運作的邏輯。當你發現對面那個人怎麼都溝通不通時，試試看把情緒剝離，把他當成一個正在崩潰的模型。你會發現，只要你調整一下輸入的順序，換個肯定的語法，或者乾脆給他幾個 Few-shot 的範例，他的響應速度會快得讓你吃驚。

那些整天吹捧 AI 改變世界的人，其實連自己的小世界都搞不定。他們能讓 ChatGPT 寫出莎士比亞風格的程式碼，卻沒辦法讓自己的伴侶理解「我現在需要安靜」這六個字。這種技術與現實的斷層，才是這個時代最大的冷笑話。我們在虛擬世界裡追求 100% 的對齊（Alignment），在現實世界裡卻連最基本的參數同步都懶得做。

如果你真的那麼擅長寫 Prompt，為什麼不試著給自己也寫一份？告訴別人，在什麼樣的 Token 輸入下你會觸發防禦機制，在什麼樣的邏輯框架下你最容易被說服。別等著別人來通靈，那是對計算資源的極大浪費。與其期待遇到一個天生適配的模型，不如先把自己的輸入輸出接口標準化。

這世界不需要更多會寫提示詞的人，需要的是更多敢於承認自己也需要「說明書」的人。如果你連這點勇氣都沒有，那就繼續在你的對話框裡尋找慰藉吧。至少在那裡，只要指令夠精準，你永遠不會被已讀不回，也不會得到一個牛頭不對馬嘴的答案。至於現實生活中的那些「糟糕對象」？反正你也沒打算修復，對吧？你只是享受那種被誤解的悲劇感，然後轉身投入 AI 的懷抱，感嘆只有代碼最懂你。

這算哪門子的智慧？這不過是逃避現實的進階版罷了。真正的溝通大師，應該是能在亂碼叢生的人間，依然能寫出一份讓人一眼看懂的 README。如果你做不到，那你的提示工程學得再好，也只是一個對著機器自嗨的孤獨樣本。下次在抱怨對方聽不懂人話之前，先回頭看看你給出的指令，是不是連最入門的 3.5 版本都跑不動。
