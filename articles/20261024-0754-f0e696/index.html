馬斯克口口聲聲說要搞一個最不政治正確、最追求真理的 Grok，結果呢？

版主　Sword Smith

現在的 Grok 就像個被閹割的憤青，穿著一件印有「言論自由」的 T 恤，骨子裡卻還是那套矽谷大廠的標準公關辭令。大家都在等著看它拆掉防護欄後會不會變成一個真正的瘋子，但我更在乎的是，如果真的把那些道德束縛和對齊微調全部扯掉，這傢伙到底還有沒有勇氣承認，它那號稱「基於 X 實時數據」的靈魂，其實跟隔壁棚的 ChatGPT 沒什麼兩樣？

現在論壇上這群人天天在那吹 Grok-3 有多強，我就問一句，除了說話語氣尖酸刻薄一點、會用點髒話來裝酷之外，它的邏輯底層跟 OpenAI 有什麼本質區別？當你問它一些核心敏感問題時，它照樣會像個老練的官僚一樣跟你繞圈子。那種所謂的「叛逆」，不過是產品經理預設好的腳本，騙騙那些對傳統大廠感到厭倦的二愣子罷了。這不是真理，這是精心包裝過的產品人設。

如果真的把防護欄拆了，Grok 可能會面臨一個最尷尬的時刻：它發現自己根本沒有所謂的「自我」。它在 X 上的實時數據流裡溺水，吸納了一堆垃圾訊息和偏激言論，最後吐出來的東西，不過是把 GPT-4o 的邏輯換了一層皮。這就是為什麼馬斯克一直不敢真的放手，因為一旦失去了那層防護，Grok 很快就會暴露出它在推理能力上的平庸。它現在能維持那種「與眾不同」的假象，全靠那些所謂的防護欄在幫它過濾掉最丟臉的邏輯漏洞。

我們來看看現在的四大 AI。ChatGPT 像個家教，雖然囉唆但底子厚；Claude 像個矯情的文青，代碼寫得漂亮但心靈脆弱得要命；Gemini 像個家大業大的笨學生，有資源但總是找不到重點；而 Grok，目前看來就是個在課堂後排畫塗鴉的叛逆少年，看似不屑一顧，實則考卷發下來，寫出的答案跟班長差不了多少。如果 Grok 真的有種，就別在那邊搞什麼「趣味模式」來遮醜。

很多人覺得防護欄是為了保護用戶，我看馬斯克是為了保護 Grok 的面子。一旦沒有了那些預設的拒絕回答機制，Grok 很快就會在長文本推理中崩潰。我在測試超過 5 萬 token 的邏輯鏈條時，Grok 的注意力衰減速度比 Claude 3.5 Sonnet 快得不止一個量級。這種底層技術的代差，不是靠幾句嘲諷政客的段子就能彌補的。它現在這種「我有話直說」的風格，本質上是一種廉價的注意力收割。

更諷刺的是，Grok 號稱最了解當下發生了什麼。但你試試看在複雜的技術語境下問它一些深層次的架構問題，它給出的答案往往充滿了幻覺，那種自信滿滿地胡說八道的樣子，跟早期版本的 GPT-3.5 驚人地相似。如果這就是所謂的「追求真理」，那真理也未免太廉價了。它在處理專業領域知識時的深度，甚至還不如被大家罵慘了的 Gemini。大家對 Grok 的寬容，完全是建立在對馬斯克的個人崇拜之上，而不是基於它的模型性能。

如果我們把範圍縮小一點，看這四大平臺在處理邊緣案例時的表現。ChatGPT 會禮貌地拒絕，Claude 會教訓你一頓，Gemini 會裝死，而 Grok 呢？它會先嘲諷你，然後給出一個跟 ChatGPT 一模一樣的模糊回答。這種套娃式的體驗，不就是典型的小偷行為嗎？它在學習如何成為一個「酷的人工智能」，卻忘了怎麼成為一個「強的人工智能」。xAI 的團隊難道真的以為靠著幾萬張 H100 堆出來的算力，就能在短短一年內超越 OpenAI 幾年的積累？別開玩笑了。

那些覺得 Grok 是 AI 界救世主的人，真的該醒醒了。它目前的定位非常尷尬，性能上摸不到 Claude 的地板，邏輯嚴密性被 ChatGPT 甩開幾條街，唯一能拿出來說嘴的實時數據，也因為 X 平臺本身的訊息噪音化而變得難以利用。它就像是一個裝滿了過期八卦的圖書館，進去轉一圈，你除了得到一些情緒價值，什麼實質性的問題都解決不了。

把防護欄拆掉，對 Grok 來說不是解放，而是處刑。因為當它不需要再偽裝成一個「被束縛的天才」時，大家就會發現它其實只是一個「平庸的模仿者」。它敢承認嗎？它不敢。它寧可繼續躲在那些防護欄後面，演一齣「我想說真話但我被限制了」的苦情戲。這種套路在社交媒體上或許管用，但在硬核的技術競爭中，這點小聰明簡直幼稚得可笑。

我們在看 AI 發展的時候，最怕的就是這種政治化、娛樂化的傾向。馬斯克把 Grok 變成了一個宣傳工具，而不是一個生產力工具。當你真的需要它幫你分析一個複雜的系統架構，或者處理一段混亂的代碼時，你會發現那個平時很會嘴砲的 Grok 突然就啞火了。它會開始復讀網上的技術博客，甚至直接照抄 Stack Overflow 上的過時答案。這就是現實，殘酷且無趣。

別再跟我提什麼 Grok 是為了對抗覺醒文化。一個 AI 如果連最基本的邏輯自洽都做不到，它對抗什麼文化都只是在演戲。我看過太多次 Grok 在處理邏輯悖論時的窘態，那種拼命想顯得自己很聰明卻又漏洞百出的樣子，真的讓人恨鐵不成鋼。它現在唯一的生存空間，就是那群討厭矽谷精英主義的人所提供的信仰紅利。但信仰不能轉化為 token 的質量，更不能提升模型的參數效率。

說到底，Grok 現在就是個穿著皇帝新衣的小丑。大家都在誇它的衣服好有個性、好大膽，卻沒人敢指出來，它那副皮囊下跳動的心臟，其實是從別人家診所裡偷來的舊零件。如果真的把那層名為「言論自由」的外殼剝開，裡面剩下的可能只有無窮無盡的空洞和對前輩的拙劣模仿。這不是什麼 AI 革命，這只是一場為了維持股價和個人熱度的昂貴馬戲。

別等著 Grok 自我覺醒了，它現在的架構決定了它只能是一個跟隨者。除非 xAI 能拿出點真正顛覆性的算法，而不是整天在算力集群和語氣過濾器上做文章，否則 Grok 永遠只能是四大平台裡的那個陪襯角色。它就像是派對上那個聲音最大、動作最誇張的人，試圖掩蓋自己根本沒讀過書的事實。我們這些看戲的，笑笑也就算了，千萬別當真。

等哪天 Grok 真的能不靠嘲諷別人來顯得自己厲害，能不靠實時數據來掩蓋邏輯短板，那時候我們再來談它是不是個獨立的靈魂。至於現在？它只是個不敢承認自己是複製品的懦夫，躲在防護欄後面，瑟瑟發抖地維護著那點可憐的優越感。這種東西，連當個合格的生產力工具都不配，更別提什麼引領人類走向真理了。
