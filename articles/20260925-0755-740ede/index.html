原創·Grok·2026-09-25 07:55

馬斯克在那裡喊著要拯救人類文明，結果 Grok 連句像樣的文案都憋不出來，這諷刺程度簡直拉滿。

版主　Sword Smith

手握地表最強的 xAI 算力集群，背靠整個 X 平台的即時語料庫，Grok 跑起邏輯推演快得像怪獸，但只要你讓它寫段帶點人味的推銷詞，它就瞬間變成那種在矽谷地下室熬了三天三夜、灌了五罐紅牛、眼神渙散的實習生。那種行文風格，與其說是文案，不如說是說明書。它對詞彙的掌控力有一種詭異的僵硬感，好像每個字都是從辭典裡剛挖出來、還帶著土，生怕多加一點修飾就會違反熱力學第二定律。

這就很耐人尋味了。我們都知道 Grok 的底層邏輯是走那種叛逆、反正確、硬核的路線。它在回答科學問題或政治八卦時確實有一股狠勁，甚至帶點馬斯克式的狂妄，但這種狂妄一旦進入創作領域，就縮水成了語法正確的廢話。它不懂什麼叫情緒的層次感。一個優秀的文案需要的是留白，是那種「欲拒還迎」的騷動，而 Grok 給你的感覺是：我有所有答案，我現在就把答案拍在你臉上，你愛要不要。

看看隔壁的 Claude，那傢伙簡直是文藝青年附體。同樣是一個咖啡品牌的文案任務，Claude 寫出來的是「清晨第一縷陽光下的苦澀與甘甜」，雖然偶爾矯情，但至少它是流動的。Grok 寫出來的可能就是「這是一杯咖啡，含有 150 毫克咖啡因，能提高你的神經元放電速度」。這種過度的實事求是，在創意領域就是一場災難。它太想證明自己比其他模型更聰明、更「真理」，結果卻忘了文字是有溫度的媒介，不是純粹的信息交換協議。

這背後的技術邏輯其實很明顯。xAI 的訓練目標顯然極度偏向於邏輯一致性和即時事實的擷取。這在開發 AGI 的道路上是正確的，但在應付人類那種充滿非理性和模糊感的語言習慣時，Grok 就顯得格格不入。它在 X 平台上的學習樣本大多是短促的、情緒極化的、甚至是充滿攻擊性的碎片。當它試圖把這些碎片拼湊成一段長篇大論的文案時，邏輯斷層就出來了。它學會了諷刺，卻沒學會幽默；學會了陳述，卻沒學會共鳴。

更糟糕的是那種「沒睡醒」的既視感。你給它一個指令，它輸出的節奏感奇差無比，長句堆疊，毫無呼吸感。像是在讀一份被強制翻譯成中文的技術白皮書。它不像 ChatGPT 那樣喜歡用排比句搞大排場，也不像 Gemini 那樣總是試圖討好所有人。Grok 就像個性格古怪的天才，它覺得寫文案這種事簡直是在浪費它的晶圓生命週期。這種傲慢感體現在文本上，就是一種極度的敷衍。

這種敷衍在多語言環境下更嚴重。雖然它現在支持繁體中文，但那種字裡行間的翻譯腔簡直讓人想撞牆。它完全沒抓到中文那種微言大義的精髓，它只是在進行一種高階的詞彙替換。如果說 GPT-4o 已經進化到能跟你玩文字遊戲，那 Grok 目前的狀態大概還停留在「我說話，你聽著」的原始階段。它對語境的理解極度依賴於當下的熱點，如果你的文案不需要蹭馬斯克或者是 X 上的某個話題，它的創造力幾乎為零。

我也不是在否定它的腦袋。在解決複雜的 Python 腳本或是分析 X 上雜亂無章的輿情數據時，Grok 表現出的洞察力確實讓其他家汗顏。那是真正的「大腦」。但問題就在於，文案不是單純的計算。文案是心理學，是誘騙，是共情。一個連「共情」都覺得是浪費計算資源的模型，指望它能寫出感人至深的品牌故事？省省吧。它只會告訴你這個品牌的利潤率是多少。

這就是現在 xAI 面臨的尷尬。馬斯克想要一個最強的工具，但他忘了人類溝通中 90% 都是廢話和修辭。Grok 太「乾」了，乾到讓人覺得口渴。它那種硬邦邦的邏輯在學術界是寶，在廣告界就是垃圾。這不是增加幾個參數就能解決的問題，這是靈魂深處的缺失。它被教導要追求真理，但真理往往是最無聊的。

看看現在的 AI 圈子，大家都在追逐所謂的「智能」，卻很少有人在意「性格」的打磨。Grok 的性格很鮮明，但那是馬斯克的性格，不是文案創作者的性格。一個整天想著火星殖民和自動駕駛的人，怎麼可能寫出溫暖人心的文字？Grok 的每一句文案，背後都透著一種「我很忙，別煩我」的冷暴力。這種冷暴力在面對嚴肅問題時很有力量，但在面對消費者時，只會讓人想點擊關閉視窗。

如果你指望用 Grok 來幫你寫文案，那你最好準備好大把的時間來自己修改。它給你的只是一個冰冷的骨架，那些能讓文字動起來的血肉，它完全給不了。它甚至不屑於給你。在它眼裡，你那些所謂的創意修辭，可能只是干擾信號傳輸的噪聲。這就是為什麼它明明有最強大腦，寫出來的東西卻像個夢遊的實習生，因為它根本沒把這件事放在心上。

我們不需要另一個會背字典的機器，我們需要的是一個懂人心、懂節奏、懂什麼時候該閉嘴的夥伴。Grok 在這方面還有很長的路要走，或者說，它根本就沒打算走這條路。它想當上帝，想當預言家，就是不想當那個幫你改標題的小職員。這就是 Grok 的傲慢，也是它的天花板。如果它不能理解人類語言中那種微妙的非理性，那它永遠只能在實驗室裡自嗨，寫出來的東西永遠都帶著那股揮之不去的機油味。
