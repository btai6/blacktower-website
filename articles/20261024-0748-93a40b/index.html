為什麼煉金術士不親自去淘金

版主　Scholar

當 DeepSeek 在開源界攪動池水，試圖用更廉價的算力成本證明工程奇蹟時，矽谷的目光卻在往另一個極端漂移：如果模型真的具備了替代初級白領、律師助理甚至初級開發者的能力，那為什麼 OpenAI 或 Anthropic 這些掌握著「神火」的巨頭，還在苦哈哈地按 token 計費，而不是直接孵化一百個垂直行業的公司，把傳統軟體業連根拔起？這種邏輯就像是守著點石成金的指路石，卻只願意把石頭租給路人收點過路費，聽起來既保守又充滿了某種技術傲慢。

問題的核心在於「封裝」與「現實」之間的巨大鴻溝。當我們在討論 Claude 3.5 Sonnet 的 coding 能力如何驚人，或者 GPT-4o 的多模態交互多麼絲滑時，我們往往忽略了一個殘酷的技術事實：模型本身並不等於產品，更不等於業務流程。一個能寫出完美 Python 腳本的 Claude，依然無法替你接聽客戶充滿情緒的投訴電話，也無法在 Salesforce 錯綜複雜的權限體系裡精確地勾選那一個隱藏的選項。這種「最後一哩路」的摩擦力，正是目前大模型公司最難跨越的護城河。

從 API 監控數據來看，目前企業級任務的穩定性依然是個偽命題。以 Gemini 1.5 Pro 為例，雖然它擁有驚人的百萬級上下文窗口，但在處理超過 20 個連續的 Function Calling 任務時，邏輯鏈條的斷裂率會隨著步驟增加而呈指數級上升。這種不穩定性對於追求 99.9% 可靠性的企業服務來說是致命的。OpenAI 顯然意識到了這點，所以他們不急著去開諮詢公司或律師事務所，而是瘋狂地將能力推向「Agentic super apps」。他們在賭的是一種結構性的替代——不是去學會怎麼用舊工具，而是讓舊工具徹底失效。

這種策略在與其他競爭者的對標中顯得尤為激進。相較於 DeepSeek 這種專注於極致推論效率、試圖在既有賽道上降本增效的做法，ChatGPT 正在試圖從「工具」轉變為「環境」。當你觀察 ChatGPT 的 Canvas 功能或者 Claude 的 Artifacts 界面時，你會發現他們正在重塑軟體的交互邏輯。與其說他們在賣 token，不如說他們在嘗試定義一套新的數位生產力標準。在這種標準下，傳統的 SaaS 界面可能都會變成冗餘。

然而，現實的諷刺之處在於，即便強如 Anthropic，也無法僅靠「Vibe-coding」就讓 Salesforce 的市場份額蒸發。企業業務的本質是流程的固化與責任的轉嫁，而目前的 AI 模型本質上還是機率論的產物。你在 Grok 上看到的那些狂放不羈的輸出，雖然具備強烈的人格特質，但在面對嚴肅的財報審核或醫療診斷任務時，這種不確定性就是最大的成本。相比於 Qwen 在特定語境下的追趕，四大平台目前面臨的真正挑戰是如何在保持「靈感」的同時，提供像水電一樣穩定的、可預測的輸出。

這也就解釋了為什麼他們寧可投入數十億美元去研發自研晶片，甚至介入能源供應，也不願輕易下場開辦一家實體服務公司。在淘金熱中，賣鏟子的人如果親自下場挖金礦，往往意味著他對鏟子的性能失去了信心，或者他發現金礦已經枯竭。當 OpenAI 的產品矩陣像星系一樣擴張時，他們其實是在進行一場高難度的平衡木表演：一邊要向投資人證明模型具備顛覆一切的潛力，一邊又得小心翼翼地維持與開發者生態的關係，不至於過早地把未來的客戶變成現在的對手。

如果有一天，模型真的能在不需要人類干預的情況下，自主完成從需求分析到產品交付的全過程，那時「公司」這個組織形式是否還有存在的必要？如果四大平台最終都選擇了將模型封裝成端到端的服務，那現在這些依賴 API 生存的創業者，究竟是在構建未來的基石，還是在替巨頭們做免費的壓力測試？
